# OCC 剧情任务前端原型

基地已按用户修正改为可以直接控制角色的自由探索场景。WASD或方向键移动，E交互；也可点击地面行走、点击人物走近后交谈。桌柜与人物有碰撞，南门连接学院路线。任务与人物页用于查阅，新的交谈需要在场景里靠近人物触发。

## 运行

在本目录执行 `npm start`，打开 http://127.0.0.1:4178 。无需安装依赖。

`npm test` 执行状态测试，`npm run build` 输出静态文件到 `dist/`。静态文件需经HTTP服务访问。

## 本次完成

- 自由移动基地、家具碰撞、鼠标绕障行走、邻近交互、跟随镜头。
- 工具台整备、资料柜回看、休息角闲谈，以及南门或地图桌出发。
- 主线任务和人物故事；任务结果与交谈已读状态分别表达。
- 五位人物资料，五段阶段交谈及四段可选闲谈。人物按阶段出现。
- 对话继续、略过、回看；关闭后回到交接入口，覆盖层阻止下层操作。
- 四段压缩示例流程；结果只领取一次，未通过可恢复战前状态。
- 待领取结果和当前地点续存；新战恢复个人魔力，基地不补生命。

这是浏览器设计原型。四个节点及演示报酬用于检查流程，不代表正式进度阈值或战斗平衡；与Unity战斗和正式存档分离。自由探索的基地交互方向已同步总案5.1.9，正式游戏仍待实现。当前场景组合复用工程已有像素地面、家具和角色素材；同伴使用临时代理外观，不据此确定正式人设。旧整幅值房概念图保留作追溯，已从基地交互视图移除。

## 验证

换机整理时重跑18项剧情状态、移动、碰撞、邻近交互与绕障路径测试，全部通过。此前实际浏览器验证按住W持续移动、共用桌阻挡、点击人物走近交谈、E交互、对话期间停止移动、工具台整备、南门出发、领取后回到可走动的基地。独立测试使用 `?test=exploration` 的演示记录，不覆盖正常入口的记录。历史截图和验证记录留在原电脑，不随本次精简开发分支同步。

机械设计检查仅提示暖纸色；保留的依据是现行美术规格ART-UI-BASE、ART-UI-MAIN-MENU与ART-UI-ARCHIVE-MATERIAL的学院纸白、木构和档案材质，不将其改成新的配色体系。没有将浏览器原型或概念图宣称为Unity正式HD-2D验收。
