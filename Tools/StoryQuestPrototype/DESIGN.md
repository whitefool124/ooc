# 剧情任务原型的实际视觉

本目录的设计上下文，不替代OCC总案。

用户已否定点击整张场景的基地形式，要求直接操控人物自由探索。基地现为占据主体视口的可移动场景，顶部仅保留当前事项，底部给移动与交互提示。邻近人物或物件时出现当前动作。任务和人物页面继续使用列表与单一详情区。

色彩来自现有学院档案方向：底色`#e9e4d7`，纸页`#f5f1e7`，正文`#302e29`，次要文字`#686052`，黄铜`#786132`，可执行状态`#235c62`。标题复用工程Fusion Pixel字体，正文使用中文系统字体。语义状态同时保留图形和文字。

基地随窗口填满可用空间，逻辑场地960×640，全部场景图片按同一源像素比例绘制。宽画幅使用2倍、较小画幅1倍，镜头跟随角色并略向前方留出空间。键盘输入读取命名动作，鼠标路径绕开家具；角色脚底碰撞与显示锚点分别处理。对话打开后停止移动，关闭后返回场景输入。

实际审阅：1920×1080和960×540的值房与对话；任务详情、人物资料、失败恢复和总结状态。场景对象可辨认，文字和主要操作未横向越界。修正了次要文字对比度、任务完成与已读混淆、尚未知晓的人物背景提前显示，以及关闭对话后的焦点返回。

自由探索场景复用工程原有像素素材，清单见 `.impeccable/exploration-art-sources.json`。同伴用现有单位作代理外观，不批准正式人设。旧概念图不再承担基地交互视图，原料仍保留。没有调用程序绘图或重着色替代新的美术生成。
