# 第一阶段界面审核前端

在仓库根目录运行 `python Tools/UiReview/server.py`，打开 <http://127.0.0.1:8876>。
也可双击本目录的 `启动审核页.cmd`，它会复用已启动的本版审核服务。

交付版本为 `OCC_Stage1_20261022_UiFinal`。页面直接读取归档中的真实截图，不生成游戏效果图，不启动 Unity，不修改游戏或飞书。16 个页面/反馈状态均有作者自评、标记、具体问题、影响和改法。表格与截图互相联动，支持历史参照、两种输出、原图像素和优先级/审核状态筛选。

用户评分、结论、认同程度、意见和优先级默认为空或待审核，与作者自评完全独立。编辑后写入浏览器备份并同步 `Worldbuilding/归档/2026-10-22_界面人工审核/user-review.json`；每次覆盖之前留历史备份。不同标签并发修改会提示冲突，不静默覆盖。支持 CSV、JSON、Markdown 导出及同版本 JSON 导入，导入前自动下载已有意见备份。

服务器只绑定 127.0.0.1，不发布到外网。桌面/窄屏验证使用独立的测试端口与测试记录，不向用户记录填入测试分数。页面内的自评分是作者主观评价，不是用户认可或 HD2D 正式样板批准。
