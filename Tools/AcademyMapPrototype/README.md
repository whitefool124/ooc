# OCC 学院地图原型

> 当前状态：v0.20 已为全部道路建立地图名称标注，并为全部600栋建筑生成与正面道路对应的唯一门牌地址。道路名称与门牌按缩放级别显示，避免全图总览被文字遮满。它仍是可审阅地图，不是最终逐栋详图。

这是学院全域地图的本地浏览原型：使用 MapLibre GL 将当前建筑与分区草案渲染成可缩放、可点选的二维矢量图。

所有几何修改必须遵守 `GEOMETRY_CONTRACT.md`。分区、建筑、地表、道路和水体的拓扑问题由自动检查阻止进入导出与构建。

## 使用

```powershell
npm install
npm run validate:geometry
npm run dev
```

默认访问地址由 Vite 输出。执行 `npm run build` 可生成静态预览产物。

执行 `npm run export:geojson` 可从原型数据导出 `data/academy-campus-v0.20.geojson`。该命令会先运行几何校验。导出文件使用学院本地米制坐标，可作为 QGIS／后续 GeoPackage 母版的导入交换格式；网页端仍保留独立的浏览坐标换算。

## 边界

- `data/academy-campus-v0.11.geojson` 只保留为四分之一面积下的局部密度与地图表达参考，不是新图母版。`academy-campus-v0.12`—`v0.14` 为失败实验；当前单一几何源是从零重建并持续精修的 `src/data.js`，GIS交换文件为 `academy-campus-v0.20.geojson`。
- v0.7 将学院内河、中庭湖、南段河道与外环排水渠合并为一个连续水体；路网删除重复并行廊道和无服务对象的悬空尽端，并将入口、场地或其他路口作为每条尽端路线的必要终点。
- v0.8 为全部 91 栋建筑指定唯一正面道路，重排市集街巷、工坊临街巷、生活服务巷及封存入口路；任何建筑离声明道路边缘超过 14 m 都会导致校验失败。`npm run report:frontage` 可输出逐栋退界报告。
- v0.9 将 15 栋具有特殊功能的建筑改为 U 形、错台、切角、多边形或锯齿采光轮廓；普通宿舍、库房和街铺继续保持规则体量。地图详情面板会显示特殊建筑的平面原型。
- v0.10 沿既有路网增加 24 栋建筑，总量由 91 栋增至 115 栋；增量集中在教学、生活、工坊与市集的空疏街段，封存缓冲、水岸和郊野课程场地只做最低限度补充。建筑覆盖率由约 5.99% 提高至约 8.16%。
- v0.11 将图书馆、基础实操堂、室内练习馆、医务室、受控档案库、外环维护站和魔法生物管理舍扩为与功能相称的体量，并建立学院体育场、护障对抗场、小队战术训练场三个完整设施组。每组同时具备场地、配套建筑、入口道路和 POI；建筑总量为 120 栋，覆盖率约 9.73%。
- v0.12、v0.13、v0.14 分别尝试了规则扩建、另造城市形态和四翼放大，均已判定不符合“v0.11只是局部示例、新城从零规划”的要求，只保留用于追溯错误方向。
- v0.15 从零建立隔河双核心：西岸学院、东岸城市公共核心，连续中央河湖，普通主桥与巨蚓专用桥分离；内外两条巨蚓线路、18座地标、三组大型课程设施和480栋独立建筑均进入同一几何源。
- v0.16 将普通道路统一为正交街网：道路长度 100% 为水平或垂直方向，保留折角均为不小于30°的明确转向；普通道路增至58条。学院正厅与议政厅旁的过大十字铺装改为贴墙门廊带；可识别建筑由480栋提高到600栋，覆盖率约14.11%，并新增城市片区大块无解释空地采样检查。
- v0.17 保持600栋总量，将其中24栋改为食堂、饭店、商店、旅店、诊所、浴室洗衣、邮政票务和分区站房等可点选日常设施；新增教学、生活、市集、工坊4处街坊公园。普通建筑按区域与用途套用固定宽深规格，同区域同规格尺寸不再随机变化；覆盖率约15.84%。
- v0.18 进一步取消同一区域普通建筑之间的多档规格：教学、生活、市集、工坊、封存和外环各自只保留一个可见宽深模数；用途名称仍可不同，但体量不再随名称跳变。地标和24栋具名日常设施是仅有的功能性体量例外。西门新增一处具名入口公园以消除规格收敛后暴露的无解释空地；覆盖率约15.32%。
- v0.19 重排全部普通建筑：同区平行街段共用坐标基线，相邻标准建筑保持8 m沿街间距和5 m临街退距；十字路口处对非正面道路至少保留3.5 m侧向净距。封存区使用48×30 m紧凑模数解决受控道路、缓冲庭和现有地标共同形成的收口条件，没有引入随机缩放；覆盖率约15.28%。
- v0.20 为68个道路／桥梁／巨蚓通勤线段保留名称，并在地图近景沿线显示；其中连续线路共享同名，形成67个可读道路名称。600栋建筑全部按正面道路方向排序，同一路两侧分别使用奇数与偶数门牌，生成600个唯一完整地址。普通建筑名称不再作为近景主标签，门牌直接显示在建筑轮廓内；具名设施继续显示名称。
- 总览突出主步道、维护道、桥梁与巨蚓轨道，同时以细线显示支路和受控路，使建筑临街关系在全图尺度可读；近景再强化次级道路。显示层级不能代替真实路网，全部道路与步道仍必须组成一个连通网络。
- 地图使用虚构地点的本地米制坐标换算为浏览坐标；没有真实地理位置或外部底图。
- 建筑位置、形状、名称和占地均来自待审核的 `学院全域地图_建筑与占地草案_v0.1.md`，仅用于体验验证。
- 不包含 Unity 场景、战斗格图、正式美术或正式地图资产。
