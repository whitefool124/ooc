# 学院档案 UI 正式资产简报

- 用途：剧情与肉鸽共用的战外档案界面；制作书页边框、主行动卷轴按钮与次级分页签，不改变术式、装备、法宝卡牌和悬浮详情的排版。
- 玩家一秒阅读：这是一本可操作的学院档案；深浅纸层负责容器层级，书脊负责页面归属，卷轴只标识主要行动。
- 材质与轮廓：温暖象牙纸、柔和旧墨色、少量氧化黄铜；一体化外轮廓，禁止把折角、扣件、阴影拆成悬浮贴片。
- 光向与颜色：固定左上受光；纸白为大面积基底，棕墨用于结构与文字，黄铜只在装订处，冷青只由交互态另行提供。
- 构图：正面正交 UI 资产，无透视；书页边框留透明中心以作九宫格，按钮中央留完整文字安全区。无字、无图标、无背景。
- 密度：大块连续像素簇，统一方形宏像素格；无散点、抖色、渐变、软阴影、摄影纸纹和中世纪鎏金繁饰。
- 接入：界面资产不受战场 32×32 画布限制；Point／Clamp／无压缩／无 Mipmap。边框和按钮均以原生图的九宫格区域拉伸，不缩放角部。保留动态文字与交互层，旧程序拼件须全部移除。
- 审核：原料、无缩放解码、manifest、1×／4×／灰阶／棋盘格／实际页面接触；人工审美确认前最高为 REVIEW_READY，不进入 Unity 正式资源目录。
