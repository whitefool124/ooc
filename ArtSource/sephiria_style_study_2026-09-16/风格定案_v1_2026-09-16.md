# OCC 战场画面风格定案 v1

日期：2026-09-16　状态：**定案（用户确认）**　性质：本轮探索的唯一结论文件

依据：用户 1080p 实机截图 + 赛菲莉亚游戏本体资源实测 + 本轮全部拼接验证。
适用范围：战场地面、墙体、结构、道具、单位、光照分层与摆放。
产出目录：`ArtSource/sephiria_style_study_2026-09-16/`（证据与脚本都在这里）。

---

## 1. 一句话定案

**1920×1080 全屏；原生 320×180 整数放大 6 倍（1 原生像素 = 6 屏幕像素）；
地面按 16 PPU 重画，物件与单位沿用现有 32 PPU 素材；静态画面不加光照与暗区，
明暗氛围全部交给运行时的 URP 2D Light2D 层。**

---

## 2. 规格表（每条都有实测依据）

| 项目 | 定案值 | 依据 |
| --- | --- | --- |
| 原生画布 / 放大 | 320×180 逻辑、**6 倍** → 1920×1080 | 截图原生步长实测 = 6 屏幕像素 |
| 1 原生像素 | **6 屏幕像素** | 同上（无光区块内方差 = 0） |
| 战场视口 | 1408×768 | 规格表 ART-VIEWPORT-OVERVIEW |
| 一屏可见 | **7×4 玩法格**（6 倍下） | 192px/格 |
| 玩法格（PPU） | **32 原生像素**（物件与单位按此网格） | 游戏本体 Sprite `PixelsToUnits = 16`，一格 16px；OCC 逻辑格为其 2 倍 |
| 地面美术网格 | **16 px 子网格**，每玩法格 2×2 张 | 见 §3；目的是让颗粒与参考同级 |
| 地面瓦片 | **16×16**，近乎平色 | 本体瓦片实测 16×16（4710 个） |
| 墙体 | **16×24**（格 + 上方 8px） | 本体墙实测 16×24 |
| 单位 | **32×64 画布**，主体贴底边，脚底偏移 0 | 工程新批次单位实测；参考角色约 1.2 格（OCC 为 2 格） |
| 道具 | 小件 16×16；结构 32 / 64 / 96 宽（沿用现有素材） | 本体实测：桶 18×24、火把 12–28、灯 16×41、宝箱 16×20 |
| 层次 | 地面 → 地面叠加 → 墙 → 大型结构 → 小道具 → 单位 → 覆盖层 | §4 R4 |
| 光照 | **不画进素材**；运行时 Light2D | 无光区块内方差 0、有光区 5–10% 像素被改 |

**混合 PPU 的后果（必须知道）**：地面是 16px 网格、物件是 32px 网格，
所以一台 2×2 的机器在 16px 地面上占 4×4 张地面瓦片；小道具（16px）按子格对齐、大物件按玩法格对齐。
两套对齐心智不能混用，地图工具里要分开处理。

## 3. 画法规则（美术）

1. **地面近乎平色**：材质差异先靠色相/明度，不靠纹理密度。砖层只出现在墙体。
2. **材质内 4–6 色**，主色（占比最大那档）**≥45%**，通常 50–70%。
3. **结构缝按尺度给**：16 PPU（地面/墙）砖距 4px、缝 1px、层高 4px；32 PPU（结构/单位）砖距 8px、缝 2px。
4. **有机斑块不随结构放大**：土/草按 2–4px 成团（16 PPU），连续、绝不出现孤立单像素。
5. **材质交界**：2–4px 长阶梯互锁 + 1px **本材质自身暗色**接触线；阶梯顶面给 1px 对方材质受光色读作高度差。
   不用纯黑勾地面交界，不烘焙每格边框。
6. **只有硬边**：无抗锯齿、无渐变、无抖色、无中间过渡色。
7. **不臆造细节**：不加碎石投影、铆钉带、密集裂纹、苔痕。
8. **描边**：素材自带的描边**保留**（本轮明确不去除）。运行时不要再叠第二圈。
9. **光与阴影不进素材**：接地投影若需要，用独立的叠加 sprite（参考做法：`Cliff_GroundShadow_*`）。

## 4. 摆放规则 v1（A2 定案）

| 编号 | 规则 |
| --- | --- |
| R1 | 玩法格 = 32×32 原生像素；地面美术画在 16px 子网格上，每格 2×2 张 |
| R2 | **底边中心**对齐所属格底边中点；多格物件以**左下格**为所属格，底边对齐占格最下排、水平中心对齐占格中心 |
| R3 | 允许向上/左/右探出占格；**不允许越过占格底边往南探**（脚本断言强制） |
| R4 | 层次（后→前）：地面 → 地面叠加 → 墙体 → 大型结构 → 小道具 → 单位 → 覆盖层 |
| R5 | 层内按**底边 y 升序**绘制；同 y 按类别优先级（结构 < 道具 < 单位） |
| R6 | 单位 32×64 画布、主体贴画布底边，**脚底偏移 = 0** |

实现：`drawn/../tools/compose_A2_rules.py`（可执行、带断言，布局表可换）。

## 8. 已知限制 / 未决

1. **一屏 7×4 格**是 6 倍倍率的直接代价；盘面要更大必须相机滚动或降低倍率（会牺牲颗粒匹配）。
2. **混用 PPU**：地面 16 / 物件 32。若将来物件也改 16 PPU，全部尺寸与对齐要重算。
3. 结构类与 08-22 老单位在 6 倍下细节糊，需要按新语言补画或重画。
4. 单位比参考大（OCC 2 格 vs 参考 1.2 格）是**有意选择**，不是误差。
5. 潮湿/破损/血迹等状态变体、外沿东/西/北向立面、多格地表尚未制作。
6. 未进 Unity：无 importer/GUID 复核、无实机运行验证、无人工审美签核。
