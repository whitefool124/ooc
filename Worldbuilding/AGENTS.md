# Worldbuilding 工作约定

## OC 世界观唯一参考

- `Worldbuilding/OC世界观/` 是 OC 世界观的唯一活动参考；其 `README.md` 与 `00_项目总览/世界观索引.md` 定义效力、版本、状态和主题路由。
- 项目外副本、飞书页面、汇编稿、旧 OCC 策划及 `Worldbuilding/归档/` 均不具备世界观规则效力。
- OC 世界观负责力量来源、时代、制度、组织、地点、人物背景、技术边界和叙事因果。
- OCC 总策划案负责模式、流程、战斗、数值、节点、奖励、界面和存档。
- OCC 新增或改变世界设定时，先更新 OC 世界观对应主题源文件，再同步 OCC 总策划案、数据表和实现。
- OCC 可以为可玩性抽象世界规则，但不得建立与 OC 世界观冲突的第二套设定。发现冲突时必须明确列出位置并等待用户裁决，不得静默覆盖。

## 写入规则

- 重要世界设定写入 `Worldbuilding/OC世界观/` 的对应主题源文件，并同步更新世界观索引。
- 历史版本、过程记录、废案和发布镜像进入 `Worldbuilding/归档/`，不得放回活动目录形成并列母版。
- 飞书同步只能从当前活动源生成发布镜像；飞书内容不能反向覆盖本地世界观源文件。
