# OCC 中文像素字体候选说明 v0.1

> 状态：仅用于选型预览，尚未替换 Unity 当前字体。
> 检查日期：2026-08-07。

## 统一检查条件

- 使用同一套 OCC 入口、按钮和战斗 HUD 文案进行实际渲染。
- 检查简体中文、数字、拉丁字母和常用 UI 标点。
- 四款候选的当前核心 UI 字符均可正常渲染。
- 四款候选均按各自官方仓库的 SIL Open Font License 1.1 发布，允许免费商用与随软件捆绑；正式导入时必须同时保留 OFL 文件。

## 候选

### A：精品点阵体 7×7

- 定位：像素颗粒最强，接近早期掌机、终端与低分辨率汉字。
- 优点：在小字号和按钮中像素味最直接。
- 风险：长段正文密度高，复杂汉字辨识度最低。
- 官方仓库：https://github.com/scott0107000/BoutiqueBitmap7x7
- 预览版本：1.71。

### B：精品点阵体 9×9 Bold

- 定位：粗重、紧凑、战斗 HUD 感最强。
- 优点：标题、按钮和战斗读数辨识度高，视觉性格鲜明。
- 风险：正文连续使用会显得拥挤，建议配合更大的行距。
- 官方仓库：https://github.com/scott0107000/BoutiqueBitmap9x9
- 预览版本：1.93 Bold。

### C：俐方体 11号

- 定位：方正均衡，仍有明显点阵结构。
- 优点：标题、按钮与较长说明文字之间最平衡；简体常用字覆盖有官方说明。
- 风险：像素冲击力弱于 A、B。
- 官方仓库：https://github.com/ACh-K/Cubic-11
- 预览文件：仓库当前 `Cubic_11.ttf`。

### D：秋叶圆体 16

- 定位：圆角点阵，较柔和、较现代。
- 优点：可读性较好，能弱化全界面的生硬感。
- 风险：官方仍注明项目尚未完工并持续更新；若选用，正式导入前需要扩大完整文案字形审计范围。
- 官方仓库：https://github.com/yzdnn/QiuYeYuanTi-16
- 预览文件：仓库当前 `QiuYeYuanTi-16.ttf`。

## 已淘汰

- 流行点阵体 16：字符映射检查看似通过，但实际简体 UI 渲染出现占位字形，不进入可用候选。
- 方舟像素字体：官方仍提示中文缺字较多。
- Zpix、三二像素体：商业游戏嵌入需要额外付费授权，不进入本轮免费商用候选。
- Fusion Pixel Font：作为当前已实装基准保留，但用户已明确不喜欢，不列为候选。

## 选择建议

- 要最浓的复古像素味：A。
- 要强像素且适合战斗 HUD：B。
- 要兼顾像素感与整套 UI 可读性：C。
- 要更柔和、有圆角个性：D。
