## 使用说明

每条记录包含 `domain → id → asset_id → path → status → runtime_reachable → use_point`。生产、QA、导入和绑定完成时只更新对应条目；所有 `runtime_reachable=true` 条目均为 `FORMAL_QA_PASS_AND_BOUND` 后，方可计算可达覆盖率 100%。
