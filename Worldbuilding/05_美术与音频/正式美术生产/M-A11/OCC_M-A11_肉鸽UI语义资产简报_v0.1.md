# OCC M-A11 肉鸽 UI 语义资产简报 v0.1

## 资产角色与玩家阅读

- 资源组：玩家应在一秒内区分金币、阶段贡献、公开时序、已探索、核心许可、风险、重量、以太负荷与剩余次数。
- 装备位组：玩家应仅凭轮廓区分主手、副手、头部、胸甲、手部、腿部、背架、以太核心、导器与两个饰品位。
- 地图状态组：玩家应不依赖“现／可／清／锁／？”等字符，直接区分当前位置、可前往、已清理、已访问、权限不足、已知和未知。

## 视觉方向

- 近代工业魔导仪表符号；所有形体都来自可制造、可维护的器材、量表、许可牌和穿戴结构。
- 原生 `32×32` 正交像素图标，透明背景、硬 Alpha、Point、Clamp、PPU32。
- 地图状态是独立 `16×16` 微图标层，按整数倍显示并使用 PPU16；禁止从 32px 图标缩小。
- 近黑外轮廓；煤灰／铁灰承担主体；冷青仅表示以太与可执行能量；锈红仅表示风险；安全黄仅表示金币与许可；安全灰绿表示阶段成果和次数。
- 每图一个主轮廓、二至三个结构分区、一个语义识别点；含透明色总色数不超过 7。

## 锁定不变量

- 不含文字、数字、阴影、环境光、渐变、抗锯齿、透视和细碎装饰。
- 不使用中世纪纹章、奇幻宝石、厚重蒸汽朋克齿轮框或无来源发光。
- 装备位图标表达槽位类别，不冒充 32 件学院装备的逐件内容图标。
- QA 必须同时保留原始 PNG、4× 最近邻审查表和 JSON 报告；未通过不得接入正式界面。

## 目标尺寸审查

1. `32×32` 原尺寸下可凭轮廓区分语义。
2. 4× 放大后无单像素噪点、半透明边缘或非整数边界。
3. 冷青、锈红、安全黄和灰绿只承担规定语义。
4. Unity 导入为 Sprite/Single、Point、Clamp、无 Mipmap、无压缩、PPU32。
