## 共用合同

- 玩家一秒首读为“干净古朴的学院石质地板”，不是 UI 按钮、图标、墙砖、金属板或装饰徽记。
- `16×16` 逻辑像素，最近邻 `2×` 交付 `32×32`；每张 5–6 色、全不透明、无抗锯齿与孤立噪点。
- 格界必须来自灰缝、石边与相邻接触；禁止四边同宽同亮的闭合内框。
- 每格内部保持大面积安静基底，只允许一个材质故事：小缺口、旧修补、磨亮边或浅色矿脉四选一。
- 四张同族明度最大差不超过 6，混合平铺不得出现亮暗棋盘、脸谱、圆斑、十字、字母或方向符号。

## 候选 A：大块学院石板（目标实装）

- **读法：** 长期维护的大块暖灰石灰岩铺地。
- **形状：** 上／左轻磨亮、下／右浅灰缝，边缘非对称且有少量错台；不画完整闭合倒角框。
- **密度：** 内部约 85% 安静石面，每张只保留一处短矿脉或补缝。
- **色板：** `limestone`；克制中性暖灰。
- **失败条件：** 读成方形按钮、浴室砖或四边框。

## 候选 B：回廊条石（备用探索）

- **读法：** 老回廊按横向石层铺设的暖色条石。
- **形状：** 每格含一条断续横向层缝，并与相邻格错位；战斗格边缘仍以较弱灰缝识别。
- **密度：** 大块横向石面、极少修补。
- **色板：** `archive_warm`；更接近档案馆与旧教学楼的沙暖石色。
- **失败条件：** 读成墙面砌砖、木板或格内产生第二套强网格。

## 候选 C：旧馆磨石（备用探索）

- **读法：** 阴凉旧馆长期踩磨的深灰板岩地坪。
- **形状：** 不规则阶梯石边，内部只有一条宽缓磨痕或天然色带。
- **密度：** 比 A 稍沉，但不能抢单位、范围与敌人意图。
- **色板：** `old_slate`；深灰绿石面配极少棕灰修补。
- **失败条件：** 过暗、像废墟、裂纹太强或威胁语义过重。

## 分流规则

1. 三套分别生成 4×接触表和混合 `12×9` 平铺。
2. 满足自动门禁后，以学院地板读法、安静程度、边界自然度和与现有暖色 UI 的协调度选择实装套。
3. 非实装套若仍可用，保存在 `alternates/` 并标记 `FORMAL_BACKUP`；不满足读法的套进入 `rejected/`，标记 `REWORK`。
4. 实装保持 `academy_courtyard_a-d` 路径和 GUID；备用资产不得进入运行时稳定 ID 集合。
