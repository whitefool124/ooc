# OCC M-A18 学院战场物件独立像素重制 v0.1

**状态：FORMAL / QA_PASS / RUNTIME_COMPLETE（2026-08-23）。** 本批替换已被产品否决的 v08 脚本几何物件；不改变稳定资源键、路径、GUID、碰撞、地图语义或玩法。

## 1. 全批合同

- 应用环境先于画布：本批对象都占一个逻辑战斗格，运行时以完整格矩形绘制；在 1920×1080 默认格为 128px（32px 源图 4×），在 960×540 为 64px（2×）。先以单位、范围覆盖与生命条共同画面确定有效轮廓，再制作 32×32，不按单图预览把物件盲目画满。
- 有效轮廓预算：轻掩体约 `24–28px × 12–17px`，重掩体约 `24–28px × 20–27px`，导能柱约 `16–22px × 23–29px`，封印台／箱体约 `18–25px × 13–21px`；接地点均在下半格，剩余透明区承担越视、单位叠加和范围提示可读性。
- 每张物件图必须有独立单图来源；同族破损态可引用完整态保证材质、透视、占地和重心连续，但不得从拼板硬切。
- 生成渠道只使用 Codex 内建直接图像生成能力；不得使用本地生图工作台、localhost API 或私有 relay。
- 目标为原生 `32×32` 逻辑像素表现：硬边像素簇、二值 Alpha、最近邻显示、至少 1px 透明安全边；规范化只可去背、定尺寸、硬 Alpha、限色和输出 QA，不得补画美术结构。
- 统一战棋俯视 3/4：顶面清楚、前立面压短、接地点在格内下半部；禁止正面立绘、等距菱形地面、摄影透视和漂浮阴影。
- 材料限定为暖灰石灰岩、旧橡木、粗麻绳、羊皮纸、陶土、锻铁与少量旧铜；冷青只允许作为仍在工作的细小以太刻痕。禁止钢制装甲、LED、警示条、发光面板、现代箱体和科幻机械轮廓。

## 3. QA 与放行

每张最终资产必须输出原料登记、最终 32×32、1×、4×、灰阶、透明棋盘格和机械报告；每族必须输出三态横排接触表；全批必须输出 12×9 实战模拟并在 Unity 的 `1920×1080`／`960×540` 真实战斗画面复核单位遮挡与投影。只有全部通过后才可登记 `FORMAL / RUNTIME_COMPLETE`。

## 4. 生产与放行结果

- 七个家族共 21 张状态图均由直接图像渠道逐张生成独立原料；未使用本地生图工作台、localhost 服务、私有 relay 或脚本矩形部件。损坏石凳的一张伪棋盘格稿、档案架两张正立面稿和战利品箱一张正立面稿在候选阶段被拒绝，未进入 Unity。
- 规范化只执行透明隔离、整轮廓最近邻定尺寸、硬 Alpha 和受控限色，没有补画结构。21/21 机械报告为 PASS；有效轮廓均落入各自应用预算，色数为 9–12 色。
- 正式原料位于 `raw/battlefield_props_v09/`，规范化资产位于 `normalized/battlefield_props_v09/`，逐项报告、1×／4×／灰阶／棋盘格、七组三态接触表与 12×9 混合场景位于 `QA/battlefield_props_v09/`。
- 21 张 PNG 已按原文件名覆盖 `UnityProject/Assets/Game/Resources/Art/FormalAcademyCombat32/`；21/21 `.meta` 保留，稳定 GUID 未改变。Importer 读回为 Sprite／Point／Clamp／PPU32／Uncompressed／无 mipmap／Alpha FromInput。
- 运行时取消场地物统一缩进，使 32px 源图在默认 128px 格严格 4×、在 960 档严格 2×显示；透明边界和独立轮廓负责视觉占用。单位完整 64×64 画布按整数倍量化、水平居中和脚底对齐，默认从旧 116px 增为 128px，可越出逻辑格但不改变命中格。
- 实机截图：`UnityProject/Artifacts/M-A18/battlefield_props_v09_runtime_1920x1080.png` 与 `battlefield_props_v09_runtime_960x540.png`。两档均确认武器／盾牌未裁切、角色与物件层级可读、物件无正立面建筑视角和高科技读法。
