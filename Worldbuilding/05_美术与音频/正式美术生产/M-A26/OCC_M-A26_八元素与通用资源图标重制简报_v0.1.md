# OCC M-A26 八元素与通用资源图标重制简报 v0.1

## 应用与阅读目标

- 八元素身份用于术式筛选、详情、奖励和档案：一秒先以结构读出元素，再由颜色确认；不画元素石、水晶徽章或同一圆环换色。
- 通用资源用于学院地图顶栏、战前预览、奖励、装备详情和战斗读数：一秒读出资源职责，不依赖文字、数字、感叹号或 UI 边框。
- 全部为独立 `32×32` 像素资产，透明硬 Alpha、至少 2px 安全边、最多 10 色；不改变任何资源／元素规则和 UI 布局。

## 视觉方向与锁定不变量

- **元素结构：** 火为分叉热焰，水为受压水束，风为绕过导流片的三股气流，土为承重阶石，雷为两触点间的导电分叉，冰为霜夹结晶，光为光阑投射，暗为吸光缺口；轮廓互不复用。
- **资源结构：** 行动点是推进节拍，负荷是承压刻度，次数是消耗槽，贡献是学院登记筹码，许可是双联冲孔票，探索是展开路线，金币是黄铜币，生命是缝合医务带，魔力是紫罗兰刻度储液，注意是抬起的机械示警片，运行以太是校准回路，零件是垫片／螺栓／小板组合，风险是破裂危险楔，护盾是合拢护片，时序是档案进度盘，重量是铸铁砝码。
- **颜色职责：** 火橙红、水深青蓝、风浅灰绿、土赭石、雷金黄／紫、冰象牙／淡蓝、光暖白／旧金、暗炭黑／梅紫。金币／许可用黄铜，贡献用灰绿，生命用医务绿，魔力用紫罗兰，危险用锈红；冷青只留给确实工作的未定向以太和可执行节拍。
- 无蓝水晶模板、无同一盾牌／液滴／圆环换色、无中世纪纹章、无赛博霓虹、无柔光、无文字数字、无场景投影或方形 UI 底板。

## 生产与晋级

每项先有 manifest，再以 Codex 内建 imagegen 独立单件生成。原料必须归一化为原生 `32×32`、硬 Alpha和限色，并完成 1×／4×／灰阶／棋盘格、旧新接触、人工审美、稳定 GUID、Importer、Resources 和 1920×1080／960×540 应用接触后才可晋级 `FORMAL`。禁止拼板切图、本地生图工作台、localhost、私有 relay 或自动回退。
