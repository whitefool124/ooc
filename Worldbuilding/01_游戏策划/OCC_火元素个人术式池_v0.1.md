# OCC 火元素个人术式池 v0.1

> **版本状态（2026-08-08）：** 本文件保留为已实装 `F-P01–F-P50` 的历史与迁移依据。新的玩法设计源为 `OCC_火元素个人术式池_v0.2.md`；在完成显式存档、奖励池、图标和运行时迁移前，v0.1 仍是当前 Unity 实现源，不得把两版 ID 静默混用。

## 0. 文档定位

- 状态：火系 50 个个人术式已完成；五个功能组均已通过内容池边界审查，卷轴与法宝扩展另立后续批次。
- 归属：肉鸽内容池。条目以战后公开三选一获得，战斗中仍按既有技能栏、3 AP、魔力、冷却、速度条与确定性结算运行；本文件不是抽手牌或卡组系统。
- 三层边界：本文件只统计个人术式。火系卷轴、法宝不占 50 个个人术式配额，另在 `OCC_三层内容池配置_v0.1.md` 管理。
- 数值依据：`OCC_战棋数值标尺合同_v0.1.md`；状态与环境依据 `OCC_战棋状态与环境标签合同_v0.1.md`；元素边界依据 `OCC_八元素术式设计语法_v0.1.md`。
- 命名规则：优先使用自然、易读且可直接联想到施法画面的世界内名称；两字名可用于足够明确的基础术式（如火矢、火墙、引爆），但不为压缩字数堆叠修饰词，也避免同组名称只有一字差异。

## 2. 共用生产规则

- 所有条目均为火元素个人术式，`content_layer=personal_spell`、`provenance_type=个人传统`、`element_secondary=无`；使用个人魔力，法杖或徒手作为导具，不占卷轴/法宝次数。
- 普通稀有度条目进入普通战斗个人术式候选；少见条目也可进入普通战斗候选；稀有条目只进入精英、宝藏或稀有战斗的稀有个人术式候选。具体候选规则以 `OCC_三层内容池配置_v0.1.md` 第 1.1 节为准。
- 伤害按“基础伤害 → 固定护甲/适用掩体 → 最低 4 → 护盾 → 生命”结算。除条目明确外，实体掩体阻挡视线和投射路径；友军不会成为单位目标，但线、扇形和区域条目会按预览对友军生效。
- 燃烧遵守既有状态合同：目标回合开始触发 8 或 12 点伤害；同名不叠层，取强度高、持续时间长。不得另设灼热层数、火种资源或随机蔓延。
- 所有条目默认专业级法律；达到区域爆破、无差别风险或重大设施破坏的条目升为战术级并在条目中注明。

### A 组使用边界

- F-P01/F-P05 提供低成本单点伤害的射程取舍；F-P09 提供带轻延时的短射程爆发。
- F-P03/F-P06/F-P08/F-P11 建立或延长燃烧；F-P12 读取但不消费燃烧；它们为 C 组的引爆术式提供明确前置。
- F-P07/F-P10/F-P11 是位置条件严格的切线或近距选择，不替代 B 组的燃烧地格控制。
- A 组不处理护甲、掩体耐久、设备、位移、治疗、护盾或光学信息；这些职责留给 D/E 组或其他元素。

## 8. 火系个人术式池完成校验

- 总数：50 个个人术式，ID 为 `F-P01` 至 `F-P50`，无空缺、无双元素条目。
- 泛用性：每个分组均含普通、少见、稀有条目；任何火系构筑都可从低成本直伤、点燃、地格、攻坚、脱困/防护中选择，不强制围绕引爆或地格单一路线。
- 联动：点燃/火场可供引爆读取；破甲服务所有伤害来源；防护、脱困、机动和资源回收可独立使用。所有联动读取公开状态、地格或资源，不创建隐藏层数。
- 边界：火系不获得随机蔓延、无限燃烧、风系自由飞行、光系显影/眩目、水系完整清洗、土系构筑掩体或雷系连锁过载。
- 后续：火系卷轴与法宝另行扩展，不计入本 50 项；进入下一元素前，需先确认是否接受火系完整池及后续卷轴/法宝的生产顺序。
