# OCC 魔法技能与道具内容合同 v0.1

## 0. 文档定位

- 状态：世界观—玩法生产合同；2026-08-06 第一轮决定已冻结并通过 24 项三层样本校验，2026-08-08 已冻结首批 20 件正式法宝内容包。
- 归属：剧情模式与肉鸽模式共用；两种模式复用同一战斗规则，以获取、叙事权限和持续范围区分。
- 世界观上位依据：`../00_项目管理/以太_世界观与魔法体系圣经_v0.1.md` 第 0 节。
- 适用内容：个人术式、卷轴、法宝，以及由它们提供的单人战棋技能、消耗品和交互能力。
- 非目标：本文件不逐项决定具体内容的最终强度；共用基础数值以 `OCC_战棋数值标尺合同_v0.1.md` 为准，不恢复旧七系或 112 条旧目录，不修改 Unity 数据结构。

若本文件与圣经第 0 节冲突，以圣经第 0 节为准。圣经后文的七系、旧年表和 112 条术式是粗稿素材，必须逐条迁移审查，不能直接视为现行内容池。

## 1. 已决定的共同硬规则

1. 所有超凡效果来自以太素，且必须有输入、定式、媒介、释放、收束和责任链。
2. 魔力可以外化为物质；外化不是无代价资源生成，仍须填写魔力、媒介、收束、身体/工程代价与直接结果。外化物分为维持型、定时型、永久型；质量、密度、精度和持续时间共同决定成本，不能形成无限资源或永动循环。
3. 八元素为火、水、风、土、雷、冰、光、暗；冰/水、雷/风独立，光/暗同系对立且本质中性。
4. 角色可多方向学习但有主/副专精；双元素组合只用于少数高阶内容。
5. 稀有天赋独立于元素并可并存。主角开局选择正常元素不改变正史。
6. 个人魔力是自然恢复的个人储量；普通施术主要形成疲劳和伤病，不默认制造污染。
7. 污染主要来自工业设备、事故、遗迹、不当储能和主动越限。若条目写入污染，必须说明污染源、暴露对象、清理责任和确定性后果。
8. 战棋结果确定：无隐藏命中率、隐藏暴击率、随机哑火、随机反噬或随机故障。所有直接结果在提交前可预览并可重演。
9. 强术式以个人施法为核心；卷轴、法宝、法阵、多人协作只能辅助定式、供能、校准、放大、稳定或分担。
10. 八元素共用个人魔力、疲劳、伤病、装置储能、校准与耐久规则，不建立八套元素负荷。元素只改变典型伤病、事故表现和战术反制；不设固定元素克制倍率。

## 2. 三类“以太”数据不得混用

| 数据概念 | 定义 | 恢复/获得 | 可否直接互换 |
| --- | --- | --- | --- |
| 个人魔力 | 人体可调动的个人储量 | 休息、环境、情绪、冥想和明确资源 | 否；不能直接当钱，也不能无媒介灌入设备 |
| 封装储能 | 魔法石、卷轴或法宝中的可释放能量 | 魔法石可充能；卷轴和成品法宝的封装次数不能通过普通充能恢复 | 否；转移必须由具体接口和损耗规则支持 |
| 运营货币“以太” | 肉鸽地图上的抽象化购买/校准资源 | 战斗、事件、商店或结算 | 否；它是运营层结算值，不等于角色当前魔力或某件设备的剩余充能 |

具体命名可以后续调整，但任何内容表、提示和策划说明都必须显式标注属于哪一类。

## 3. 三层内容模型

### 3.0 共用装备与组件词汇

| 概念 | 生产定义 | 与三层的关系 |
| --- | --- | --- |
| 法杖 | 魔法师的通用施法导具；引导个人魔力，提高射程、精度或效率，不内置固定术式 | 服务个人术式，不构成独立层级；普通人不能靠法杖施法 |
| 法宝 | 封装固定术式与有限使用次数的消耗品；现代与远古只表示来源、工艺和可生产性 | 对应“法宝”层；次数耗尽后失效或报废，普通充能不能恢复 |
| 魔法石 | 无元素倾向的通用储能石，需要充能 | 属于储能组件；可有限补充/代付个人术式消耗，也可作为法宝制造材料，但不能给成品法宝补次数 |
| 元素石 | 与单一元素稳定共鸣的稀有催化石，用于强化、稳定或改变对应元素效果 | 属于元素组件；可装入法杖或用于法宝制造，不替代训练且不作通用电池 |

身体承受与个人魔力通道是个人施术的默认隐含条件，不再为每个术式枚举呼吸、手势或身体部位。除非某个技能把沉默、束手、视线或姿态明确设计为可反制条件，否则不写成强制媒介字段。材料仅在确实会消耗、锚定场地或形成任务交互时记录。

### 3.1 个人术式

- 使用者：具备施术能力并接受相应训练者。
- 学习：受元素主/副专精、训练资格、媒介熟练度和身体承受力影响；跨元素可学但成本更高。
- 供能：个人魔力。
- 校准：由施术者在训练、准备或施放过程中完成；导具可以降低误差，不能替代全部个人责任。
- 消耗：行动点、个人魔力、冷却、延时、媒介、专注占用、疲劳或伤病，可按条目组合。
- 耐久：术式本身无耐久；使用的导具或材料可另有耐久/数量。
- 故障：条件不足时拒绝施放；主动越限才产生已预览的固定代价。
- 战棋用途：构筑的可重复核心技能。

### 3.2 卷轴

- 使用者：至少具备基础施术能力；无需事先学会卷轴中的具体术式。完全无魔力者不能裸手启动卷轴。
- 元素门槛：卷轴降低知识门槛，不取消控制门槛。非专精使用必须配置额外魔力、疲劳、施放时间或其他固定代价。
- 供能：卷轴封装定式与一次性储能；启动仍须经过身体、导具或材料媒介。
- 校准：制作时完成主要校准；使用者在启动时完成身份、目标和收束校验。
- 消耗/耐久：使用后载体报废；默认不可现场复写、充能或修复。
- 法律：同时审查卷轴所载效果与卷轴的持有、运输、交易许可。
- 战棋用途：背包中的一次性临时技能，使玩家在不永久学习术式的情况下扩大本场选择。

“远古大威力卷轴”仍归卷轴层，但必须额外标记 `ancient_provenance`、有限存世数量和不可复制原因；不能据此推导现代卷轴可以稳定量产同等效果。

### 3.3 法宝

- 共同定义：封装固定术式与有限使用次数的消耗品；每次使用消耗公开次数，次数耗尽后失效或报废，不能通过普通充能、换魔法石或工坊维修恢复。
- 现代来源：按标准工艺制作，同型号效果与次数可稳定标注；完成培训并持有适当许可的普通人可以操作。现代能够生产的是“一件件有限次数的法宝”，不是可无限充能的永久设备。
- 远古来源：需要个体适配、古代知识解读或专家监督；现代技术只能鉴定、稳定和安全封存，不能可靠复制其次数、结构或效果。
- 魔法石/元素石：可以在制造阶段作为储能或催化材料，也可成为法宝不可拆换的内部组件；成品法宝不能靠更换石头补充次数。
- 主角交互：魔导增幅适配可放大、稳定或越限标记为 `amplifiable` 的法宝。越限必须消耗额外次数，或造成身体伤害、法宝提前报废、污染吸收、连锁异常中的固定组合。
- 耐久：默认不另设日常耐久条；剩余次数就是主要消耗。受击或越限若会直接毁坏法宝，必须作为公开的条目规则。
- 法律：现代法宝按效果和用途管理；远古法宝额外需要鉴定、登记、运输和封存许可，但不因远古来源自动成为禁物。
- 战棋用途：背包或快捷栏中的多次消耗品，在有限次数内提供预设主动效果；不能成为永久装备被动或无限基础动作。

远古法宝可以启发现代研究，但其材料、工艺、原始校准或封装结构至少有一项不可稳定复制，因此不能直接转化为现代量产同款。

## 4. 法律合同

### 4.1 效果等级

| 等级 | 判定原则 | 常见权限 |
| --- | --- | --- |
| 民用级 | 小规模、可收束、低外溢，用于生活、生产或基础救护 | 登记或一般培训即可使用 |
| 专业级 | 需要专业判断，失误可造成人身、财产或证据损害 | 学院、教会、行会或行业执照 |
| 战术级 | 直接用于作战、强制控制、危险处置或高危设施 | 军警、灾害队、特许行动人员 |
| 战略/禁制级 | 可造成广域、持续、不可逆或制度性伤害 | 国家审批、多人复核与监察；部分用途直接禁止 |

等级由效果、规模、场所和用途共同决定。同一火系原理可以是民用点火、专业熔切、战术燃烧区或战略焚毁，不得只凭元素或载体层级判断。

### 4.2 物品控制

效果等级之外，每个物品还必须配置：

- `possession_rule`：持有资格。
- `transport_rule`：运输与封装要求。
- `trade_rule`：能否公开交易、限定渠道或禁止交易。
- `site_rule`：在学院、城市、前线、医院、遗迹等场所的使用限制。
- `trace_rule`：使用后留下的可取证痕迹。
- `disposal_rule`：废卷轴、损坏储能单元、污染部件或遗物碎片的处置责任。

## 5. 确定性战棋合同

基础生命、伤害、护甲、护盾、治疗、行动点、魔力、移动、行动条、状态、掩体、卷轴与法宝次数的数值单位与首档，统一由 `OCC_战棋数值标尺合同_v0.1.md` 冻结。每个内容条目仍须明确填写自身数值、而不能只引用档位名称。

### 5.1 提交前必须公开

每个主动能力在玩家确认前必须能展示：

- 行动点、个人魔力、装置充能、消耗品数量与其他即时成本。
- 射程、目标规则、作用格、视线/路径要求和友军影响。
- 确定性伤害、护盾、治疗、位移、状态、持续时间和地形变化。
- 冷却、延时、专注占用、耐久/稳定度变化。
- 越限、故障阈值、使用后伤病或污染等直接后果。
- 条件不满足时的明确拒绝原因。

### 5.2 禁止的写法

- “有概率命中/暴击/失控/反噬/损坏”。
- “造成少量/大量伤害”但没有可计算值或公式。
- 使用后才揭示本可在战前得知的目标限制、元素需求或设备状态。
- 把剧情未知等同于规则隐藏；未知来源可以保留，但当前操作的直接机械结果必须明确。
- 用污染作为所有强力内容的万能代价；优先从魔力、行动点、冷却、延时、疲劳、伤病、媒介、充能、耐久、稳定度和法律责任中选择符合来源的代价。

### 5.3 越限

越限不是随机事故，而是独立的显式选择。条目必须配置：

- `overdrive_available`：是否允许越限。
- `overdrive_requirement`：天赋、设备状态、许可或环境条件。
- `overdrive_gain`：相对正常使用增加的确定性收益。
- `overdrive_cost`：固定的身体伤害、疲劳/伤病、设备耐久、污染吸收或连锁异常。
- `overdrive_preview`：提交前显示的完整后果文本。

主角的魔导增幅适配只改变具备 `amplifiable` 标记的法宝或储能装置，不自动强化所有个人术式与卷轴。

### 5.4 元素环境与反制

- 现场已有对应物质或有利条件时，可以降低成本或扩大效果；缺少时通常以更高魔力成本外化完成。
- 环境只有在条目明确填写 `environment_hard_requirement` 时才是硬条件，不允许用未公开环境规则临时拒绝施术。
- 不设固定元素克制倍率。条目通过目标规则、位置、掩体、锚点、导电路径、视线、装备或状态给出确定反制。
- 土系固定构造依附承重表面；雷系连锁沿预览可见的导电路径；光暗效果遵守视线；暗系不消除非光学痕迹。

## 6. 可生产内容字段

所有正式条目都必须填写以下合同。字段可映射到未来数据表或 ScriptableObject，但当前以语义完整为验收目标。

### 6.1 身份与来源

| 字段 | 必填内容 |
| --- | --- |
| `content_id` | 稳定唯一 ID，不使用显示名作为主键 |
| `display_name` | 世界内名称 |
| `content_layer` | `personal_spell` / `scroll` / `treasure` |
| `provenance_type` | 个人传统/现代制作/远古遗产；法宝必须标明现代或远古来源 |
| `content_form` | 主动技能、被动、基础动作、消耗品、部署物、交互能力等 |
| `combat_affinity` | `melee_only` / `weapon_universal` / `ranged_spell` / `support`；表示战斗适配，不构成新内容层级 |
| `mode_scope` | 剧情、肉鸽或两者共用 |
| `provenance` | 时代、机构、地区、制造者/传统或遗迹来源 |
| `rarity` | 内容稀有度；不得代替法律等级 |
| `element_primary` | 八元素之一；无元素转换时也必须说明依据 |
| `element_secondary` | 无或第二元素；非空即按少数高阶组合审查 |
| `talent_requirement` | 无、通用稀有天赋或明确专属天赋 |
| `talent_interaction` | 天赋如何改变效果；不得把天赋伪装成元素 |

### 6.2 使用资格与媒介

| 字段 | 必填内容 |
| --- | --- |
| `user_requirement` | 普通人、基础施术者、受训施术者、特定适配者等 |
| `proficiency_requirement` | 主专精、副专精、跨系允许条件和双元素要求 |
| `knowledge_requirement` | 是否必须已学会术式；卷轴默认不需要 |
| `casting_carrier` | 徒手、法杖、卷轴或法宝；身体施术默认隐含，只有真实可反制条件才另行注明 |
| `delivery_mode` | 身体强化、武器附着、接触导能、离体投射、自身架势、目标标定或其他明确方式 |
| `weapon_requirement` | 无、近战武器、远程武器或任意武器；若为武器附着必须填写 |
| `stone_configuration` | 无、魔法石、对应元素石或二者组合；说明供能与强化职责，不得混用 |
| `calibration_owner` | 施术者、制作者、工坊、专家组或遗物适配过程 |
| `activation_sequence` | 玩家与世界内都能理解的启动—释放—收束步骤 |

### 6.3 战斗成本与时序

| 字段 | 必填内容 |
| --- | --- |
| `action_point_cost` | 固定行动点成本 |
| `personal_mana_cost` | 个人魔力成本；不用则为 0 |
| `stored_charge_cost` | 装置/卷轴/遗物储能成本；不用则为 0 |
| `consumable_cost` | 媒介、弹药、卷轴本体或材料数量 |
| `cooldown_rule` | 无或明确冷却与重置时点 |
| `delay_rule` | 是否推迟行动条及确定值 |
| `concentration_rule` | 是否占用持续维持位、如何中断 |
| `fatigue_injury_cost` | 正常使用与越限分别造成的疲劳/伤病 |

### 6.4 目标与效果

| 字段 | 必填内容 |
| --- | --- |
| `target_rule` | 自身、单位、格子、方向、物件或区域 |
| `trigger_window` | 立即、下一次合法攻击、本次行动、至下次行动或明确行动条节点 |
| `consumption_rule` | 提交即消费、合法攻击提交后消费、触发后消费或时限结束清除 |
| `range_rule` | 距离、形状、起点和高低/遮挡规则 |
| `line_rule` | 视线、路径、穿透和阻挡规则 |
| `deterministic_effect` | 伤害、护盾、治疗、位移、状态、地形/物件变化的确切值或公式 |
| `manifestation_rule` | 无外化，或维持型/定时型/永久型；生成物、质量/格数、持续、解除去向与相位痕迹 |
| `timing` | 立即、回合开始/结束、行动条节点或交互时点 |
| `duration_and_stack` | 状态按目标回合计时；同名状态单实例，强度取高、时间取长；若为明确转化则写出转化条件 |
| `status_or_instant` | 六种单位状态之一、即时效果或无；不得为单个元素临时发明新状态 |
| `environment_tags` | 创建、移除或利用的地格/环境标签；持久/临时方式、行动条消失标记、覆盖和基础转化结果 |
| `friendly_fire` | 对自身、友军、NPC与中立物件的影响 |
| `counterplay` | 敌方、地形或任务目标可采用的明确反制 |
| `preview_text` | 提交前的人类可读摘要，不依赖内部 ID |
| `environment_rule` | 有利环境、外化附加成本、硬条件或无环境依赖 |
| `counter_rule` | 位置、装备、环境、状态或操作层面的明确反制；不得只写固定元素倍率 |

### 6.5 储能、耐久、故障与维护

| 字段 | 必填内容 |
| --- | --- |
| `charge_capacity` | 总充能/次数及跨战斗继承方式 |
| `recharge_rule` | 个人魔力自然恢复、魔法石充能，或卷轴/法宝不可补充；成品法宝必须为不可补充 |
| `durability_capacity` | 无或明确耐久/稳定度 |
| `durability_loss` | 只在何种受击、越限或高负荷条件下损失 |
| `repair_rule` | 现场、工坊、专家稳定或不可完全修复 |
| `fault_threshold` | 公开触发阈值 |
| `fault_effect` | 固定、可预览、可重演的后果 |
| `pollution_source` | 无，或设备/事故/遗迹/不当储能/越限中的明确来源 |
| `pollution_consequence` | 暴露对象、固定影响、清理与责任 |
| `maintenance_trace` | 使用痕迹、检修记录、证据与废弃物 |

### 6.6 法律、经济与模式

| 字段 | 必填内容 |
| --- | --- |
| `effect_legal_level` | 民用、专业、战术、战略/禁制 |
| `possession_transport_trade` | 持有、运输、交易规则摘要 |
| `equip_or_inventory_rule` | 技能栏、装备位、快捷栏、背包尺寸与携带上限 |
| `acquisition_story` | 剧情模式中的学习、购买、委托、遗迹或人物关系来源 |
| `acquisition_rogue` | 肉鸽奖励池、商店、事件、宝藏或首领来源 |
| `persistence_story` | 剧情存档中的永久学习、库存、维修与后果 |
| `persistence_rogue` | 单局继承、战后消耗、跨节点状态与局外是否仅解锁内容池 |
| `workshop_actions` | 校准、充能、维修、改装、拆解或禁止操作 |

剧情与肉鸽可以使用不同获取表和价格，但同一 `content_id` 的战斗效果、目标规则与确定性结果必须一致。肉鸽人物档案不得反向改写剧情正史。

肉鸽内容稀有度的出现、重复和战后三选一构成以 `OCC_三层内容池配置_v0.1.md` 第 1.1 节为准。稀有度是内容池运营字段，不是抽手牌/卡组规则，也不改变战斗内技能栏与确定性结算。

## 7. 主角与稀有天赋专用字段

- 固定主角的正常元素由开局选择写入存档；正史只记录“主角接受了某一正常元素方向的训练”，不指定唯一官方元素。
- `magic_device_amplification`（魔导增幅适配）只作用于标记为 `amplifiable` 的法宝、储能装置或极少数经审查对象。每个可增幅条目必须填写正常效果、增幅效果、额外次数消耗、越限效果和四类风险中实际采用的固定组合。
- `magical_creature_affinity`（魔法生物亲和/沟通）用于沟通、安抚、调查、协作和少量战术互动，不自动等于召唤、控制或驯服。具体范围与代价仍待后续决定。
- 两项天赋可与任意元素主/副专精并存，不能进入普通随机技能池，也不进入肉鸽角色档案、奖励池、构筑、事件能力或可复制机制。肉鸽模式与固定主角故事无关，不得以“特定人物档案”方式间接引用这两项正史天赋。

## 8. 条目验收门禁

一个条目只有同时通过以下检查，才可进入正式内容池：

1. 能追溯到以太素，且元素与媒介写法符合圣经。
2. 三层归类唯一；不能同时把同一实体写成个人术式、卷轴和法宝。
3. 三类以太数据没有混用。
4. 成本、目标、效果、时序、持续、叠加与反制均可计算。
5. 无隐藏概率；越限、故障、伤病、耐久和污染后果可预览。
6. 法律效果等级与物品控制规则分开填写。
7. 剧情与肉鸽的获取/持续范围明确，核心战斗规则一致。
8. 强力内容至少具有一种真实机会成本，且不是只写一句“可能污染”。
9. 普通人使用现代法宝的能力来自标准化封装与操作训练，不被写成突然获得个人施术天赋。
10. 远古法宝说明不可稳定量产的原因；现代法宝也必须保持有限次数，不把储能工业变成无限捷径。

## 9. 已决定、待决定与可自主补全

### 9.1 已决定

- 本文件第 1 至 8 节的三层边界、使用门槛、供能方式、次数原则、法律判定、确定性规则和生产字段。
- 个人术式是可重复核心技能；卷轴是一次性临时技能；法宝是不区分现代/远古层级、但必须标明来源的有限次数消耗品。
- 现代与远古法宝均以公开剩余次数为主要消耗，次数耗尽后失效，普通充能与维修不能恢复。
- `OCC_三层跨元素校验样本_v0.1.md` 已用八元素 16 个个人术式、4 个卷轴和 4 个法宝验证本合同；样本值只作原型，不冻结最终平衡。

### 9.3 可由后续内容生产自主补全

在不改变已决定规则的前提下，内容作者可自主补全：

- 稳定 ID、显示名、制造者、学校/机构、材料外观和使用痕迹。
- 民用、专业和战术场景中的具体用途与任务交互。

- 剧情与肉鸽中的获取来源、稀有度、奖励池位置和工坊操作；不得据此更改正史或核心战斗效果。

若补全会引入新元素、第二超凡来源、随机战斗结果、普通人无物品施法、远古法宝量产、法宝普通充能恢复次数或新的主角专属天赋，必须退回产品决定，不能自主添加。
