>

## 效力

`Worldbuilding/OC世界观/` 是本项目中 OC 世界观的唯一活动参考。世界规则、历史、国家、社会、组织、人物、地点和剧情设定只能在本目录对应主题源文件中建立或修改。

- `00_项目总览/世界观索引.md` 负责登记当前版本、文件状态、已锁定原则和待补范围。
- `00_项目总览/历史对话确认基线.md` 记录从本项目历史对话恢复、且由用户明确确认的设定；它在同主题内优先于本次整合前的导入稿。
- `00_项目总览/世界观总纲.md` 负责跨主题底层规则，但其中与“历史对话确认基线”冲突的段落须先标记并裁决，不能继续当作锁定事实。
- 各编号目录中的主题文件负责该主题的正式细节；总纲没有展开的内容，以对应主题文件为准。
- `Worldbuilding/归档/`、旧 OCC 策划、历史汇编、飞书页面和导出文件只用于追溯或发布，不构成世界观依据。
- 不再维护项目外的 `E:/数据库/OC世界观` 副本。

## 与 OCC 的边界

- OC 世界观决定 OCC 中什么设定成立：力量来源、时代、制度、组织、地点、人物背景、技术边界和叙事因果。
- OCC 总策划案决定游戏如何运行：模式、流程、战斗、数值、节点、奖励、界面和存档。
- OCC 可以为可玩性抽象世界规则，但不得另建相互冲突的世界观。新增或修改 OCC 设定时，先更新本目录中的对应世界观源文件，再同步 OCC 总策划案、数据表和实现。
- 若世界观与玩法发生冲突，必须明确记录冲突并由用户裁决；不得让旧实现、旧策划或发布镜像静默覆盖本目录。

## 当前锁定底层原则

1. 所有超凡现象的唯一源头是以太素。
2. 魔法是可测量、可训练、可维护且有代价的能量工程，不是脱离客观条件的许愿。
3. 元素分类为火、水、风、土、雷、冰、光、暗八种；光暗为一系的中性对立分支。
4. 人体施术、魔法机器与魔导武器长期共存，个人能力始终受身体、知识、媒介、资源和制度约束。
5. 世界处于近代魔法工业文明，不采用中世纪奇幻或纯蒸汽朋克作为默认基调。
6. 维克多的学院期中，储能／释放技术刚进入试点；它将生产力、国家能力、垄断、污染、战争与阶级重组推向临界。新世界大战随后在灰垣主战场爆发，但不代表全社会已完成成熟工业化。

## 使用方式

1. 先读 `00_项目总览/世界观索引.md`，确认主题文件和设定状态。
2. 再读本次涉及的主题源文件；不要把整个目录当成一篇无差别汇编。
3. 新设定写入对应主题文件，并同步更新索引；涉及时间变化时同时更新时间线。
4. 未成文目录表示当前确有缺口，不得用归档材料或旧 OCC 文档自动补位。
5. 对外发布时从当前源文件生成镜像；发布镜像永远不反向成为编辑母版。
