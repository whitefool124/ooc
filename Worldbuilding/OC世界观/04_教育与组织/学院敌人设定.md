# 学院敌人设定

> 状态：**已确认（第一阶段口径）**
> 归属：`04_教育与组织/`
> 效力：定义学院每一名敌人的完整档案，以及**所有单位共用的通用场地装置与材料库**。
> 边界：不规定数值、射程、冷却、AI 优先级与地图格位；台词只给方向。
> 上游：`学院当前可玩内容设定合同.md`、`学院精英考核设定合同.md`、`封存塔与终考前提.md`。
> 第一阶段边界：正式敌人集以对应数据表为准；所有遭遇的胜利条件为击倒全部敌人。地图装置与材料使用同一套场地库和规则，不设置单位专属地形；后续阶段候选机制不进入本阶段配置。

## 一、七条设计规则

1. **命名**：名称取自该单位最显眼的器具或动作，2–3 个字。
2. **非人上限**：构装体**精英**只留**楔角**一个（普通级的替身偶是训练构造物，不计入该上限），兽类只加**老寻**一个；其余全部是人类。
3. **能力必须来自魔法与场地，不来自人设。** 每个技能均须明确施术介质与所用场地要素。
4. **第一阶段任务目标一律为歼灭。** 考核、纠察、封锁、考察等只影响叙事背景；战斗均以击倒全部敌人为胜利条件。不配置护送、保护、核验、清障等额外目标。
5. **机制必须服务战斗与战损控制，不能为了机制而机制。** 每个单位须能说明其压力来源，以及忽略该单位造成的生命、行动点或资源损失。
6. **场地装置通用化。** 地图材料与装置属于**场地库**，不属于任何单位。敌我使用同一条规则；同一装置必须能在多场复用，不做单位专属机关。
7. **单位机制＝对玩家角色行为的公开条件应对。** 玩家角色完成指定动作后，该单位公开切换为对应行为。触发条件、来源、目标、预计结果、次数、冷却与取消条件全部可见；不得暗中重排行动条。正式回合之外立即结算的反击统一作为被动效果，后置反击与路径截击仅表示其触发窗口。

## 二、通用场地装置与材料库

这是本作场地的全部词汇。**任何单位、任何关卡都从这张表里取用**，不存在专属条目。

### 2.1 地表

| 名称 | 直觉因果 | 基本规则 |
|---|---|---|
| **普通地面** | 平整可走 | 移动成本 1；任何地图都必须保留一条只靠它的保底路线 |
| **碎晶** | 脆片硌脚 | 移动成本 2；只由晶簇破坏产生 |

### 2.2 效果层（每格至多一个，后生成者覆盖先在者）

| 名称 | 直觉因果 | 基本规则 | 改变方式 |
|---|---|---|---|
| **浅水** | 水会灭火、会弄湿纸、能洗掉痕迹 | 进入成本 2；进入即移除燃烧；**可覆盖火场、散页、痕迹、约束纹** | 可被火场覆盖（蒸散） |
| **燃烧地格／火场** | 火会烧、会蔓延、会被水浇灭 | 进入或停留受伤；**可点燃散页**；**可覆盖浅水、散页、痕迹、约束纹** | 被浅水覆盖即熄灭 |
| **散页／可燃堆积** | 松纸走得慢、会烧、会被风吹跑 | 进入成本 2；**可燃**（被点即转火场）；**可被风逐格搬动** | 被火点燃、被风吹动、被浅水打湿（暂时不可燃） |
| **痕迹**（气味／脚印／读数） | 走过会留下印子，水冲火燎就没了 | 可被**追踪类单位**读取；读取者沿痕移动不受慢行场地影响 | 被浅水、火场、强风清除 |
| **约束纹** | 地上画了圈就不能踩 | 走进该格的单位留在原地 | 被浅水、火场、烟尘覆盖 |
| **烟尘** | 烟挡光、呛人 | **阻断光与显影**；削弱远程射线；持续若干回合 | 被强风吹散或铺开 |

### 2.3 物块

| 名称 | 直觉因果 | 基本规则 | 谁都能拿它做什么 |
|---|---|---|---|
| **轻掩体** | 矮台子能站、能挡一点 | 可进入，不阻线；耐久 8；站在其上回合开始 +2 盾 | 双方都能站、都能打坏 |
| **重掩体** | 厚墙挡视线也挡路 | 不可进入，阻移动与攻击线；地图预设耐久 24，技能临时生成耐久 12；正交邻接回合开始 +4 盾 | 双方都能借它取盾、切线、拆掉；临时版本仍是同一种重掩体 |
| **永久重物块** | 建筑结构 | 不可进入、阻线、不可破坏 | 只定义骨架与远程线 |
| **灯藤** | 中空藤篱能钻人、挡视线、能砍 | 可进入，成本 2；阻攻击线；耐久 6；藤内只打正交相邻；构成"已知入口／搜查"关系 | 双方都能藏、都能搜查、都能砍 |
| **蓄能晶簇** | 脆晶会被打爆、碎片硌脚 | 不可进入，不阻线；耐久 16；破坏时对正交邻格造成伤害并生成碎晶 | 双方都能打爆、都会被爆裂波及 |
| **精英稳压晶簇** | 加厚稳压件，专门挨大冲击 | 同上，耐久 24 | 同上；只用于精英层承接大型冲击 |
| **过载装置** | 会炸的设备 | 耐久公开；**被破坏时对四邻结算一次过载伤害，敌我一致** | 双方都能放、都能拆、都能被它伤到 |
| **护罩发生器** | 会撑护罩的机器 | 耐久公开；给附近单位**结构护盾**，需持续存在 | 双方都能拆；拆掉护盾即消失 |

### 2.4 全场环境状态

| 名称 | 直觉因果 | 基本规则 |
|---|---|---|
| **风** | 风会吹动轻的东西 | 公开风向与风级；**只作用于松散材料**（散页、碎晶、烟尘），逐格搬动、公开可预览。第一阶段仅由具备换风能力的敌方单位改变风向，次数有限且公开。风不改变其他术式的路径与射程 |
| **光带／光柱** | 光走直线，挡上就有影子 | 公开直线照明区；**被重掩体、建筑、灯藤遮断即留下暗段**。任何光源装置都能产生 |

### 2.5 组合深度（只写规则会怎样，不写解法）

规则对双方一致，所以玩家可以自己开发用法。已知会互相作用的组合：

- 风 × 散页 → 搬动、堆成临时墙
- 风 × 火场 → 火势沿风向转移
- 风 × 烟尘 → 吹散或铺开
- 火 × 散页 → 点燃
- 浅水 × 散页 → 打湿，暂时不可燃
- 浅水 × 火场 → 覆盖熄灭
- 浅水 × 痕迹 → 洗掉
- 浅水 × 约束纹 → 覆盖
- 碎晶 × 风 → 危险格被搬走
- 光 × 烟尘 → 光被散射
- 重掩体 × 光带 → 切出暗段
- 破障 × 物块 → 耐久伤害翻倍（既有规则）
- 过载装置 × 冲压／爆裂 → 提前引爆，敌我一致

**这一节是本作鼓励玩家自主开发场地效果的地方**：系统不提供"标准解法"，只保证规则一致、因果直觉、预览完整。

## 三、单位机制：对玩家角色行为的公开条件应对

每个单位的独有机制就是它的**反应**。全部遵守工作稿 9.2：触发条件、来源、目标、预计结果、次数冷却、取消条件都在确认动作前显示；来源被控制、攻击线被切断、目标移位或次数耗尽时预览立即刷新。

| 单位 | 介质 | 常用的通用装置 | 对玩家角色行为的公开反应 | 忽略该单位的战损 |
|---|---|---|---|---|
| **划线教官** | 土 | 重掩体、轻掩体、物块 | **拆除依托**：玩家角色从掩体获得护盾或拆除该单位生成的结构 → 该单位下回合优先处理对应结构 | 掩体被拆除，护盾与攻击线同时失效 |
| **小铃** | 风 | 风、散页、书架（重掩体） | **火场换风**：玩家角色生成火场或点燃散页 → 该单位下回合换风，将着火散页吹向玩家角色一侧 | 火场扩散至非预期位置 |
| **老寻** | 缚环 | 痕迹、灯藤 | **停留留痕**：玩家角色在同一格停留超过一个自身回合 → 该格痕迹加深，老寻可循迹扑击 | 藏身失效，接敌伤害提高 |
| **楔角** | 以太压载 | 浅水、灯藤、稳压晶簇 | **改线重算**：路线地形或占位改变 → 立即公开重算路线与终点；撞空后下回合优先选择可受击单位 | 冲压路线持续造成损失 |
| 补盾助教 | 以太·结构接口 | 轻／重掩体 | **受伤补盾**：玩家角色伤害其友军 → 该单位下回合优先为该友军授予护盾 | 掩体存在时，敌方持续获得护盾 |
| 背弩生 | 绞盘重弩 | 重掩体、光带、烟尘 | **失线换点**：背弩生失去攻击线 → 公开选择新架设点；架设期间不能射击 | 每回合承受一次远程伤害，并支付行动点改线 |
| 拴索助教 | 土 | 约束纹 | **绕行补刻**：玩家角色绕开约束纹 → 该单位在新路线前一格刻印（每回合限一处） | 退路受限，容错降低 |
| 提灯巡查 | 光 | 光带、烟尘、掩体 | **藏身转灯**：玩家角色进入藏身 → 该单位优先将灯转向该方向 | 藏身不能规避接敌 |
| 试制员 | 过载试制品 | 过载装置、护罩发生器 | **拆除补放／邻近引爆**：玩家角色拆除装置 → 该单位优先补放装置；玩家角色与装置相邻 → 该单位优先引爆 | 行动点持续消耗于绕行与拆除 |
| 老库管 | 旧式检定器 | 效果层与装置 | **生成退件**：玩家角色生成场地效果或装置 → 该单位下回合优先清除该对象 | 场地铺垫被清除，行动点投入损失 |
| 灯台值守 | 光 | 光柱、重掩体、烟尘 | **暗段转灯**：玩家角色借暗段绕行 → 该单位将光柱转向新路线（每场限次） | 路线受限，移动消耗提高 |
| **塔之守卫** | 塔的储能阵列 | 塔内机关（护障维护／显影巡查／冲压隔离） | **拦路清场**：玩家角色在塔之守卫行进路线布置物块或危险格 → 已放行机关优先公开清场 | 前三回合不能攻击塔之守卫，场地压力持续提高 |

### 3.1 反应的执行边界（次数／冷却／取消条件）

上表的每一条反应都必须能填满下面三栏，否则不算成立：

| 单位 | 次数与冷却 | 取消条件 |
|---|---|---|
| 划线教官 | 每回合限一次 | 换位；不再依赖该结构；把他引离自己筑的区 |
| 小铃 | 换风每回合限一次；每场换风总次数有限 | 先把散页烧光或打湿；不站在下风向 |
| 老寻 | 痕迹加深每格每回合一次；扑击走普通攻击冷却 | 移动离开该格；洗掉痕迹 |
| 楔角 | 重算随地形变化即时发生；撞空后的优先级调整每场一次 | 重算后立刻换位；让他再次撞空 |
| 补盾助教 | 每回合限一次 | 分散伤害；先拆结构；先破势 |
| 背弩生 | 换点每回合限一次；重新架设占一整次公开动作 | 在架设窗口内压制他 |
| 拴索助教 | 补刻每回合限一处 | 覆盖印记；把他逼出有效距离 |
| 提灯巡查 | 转灯每回合限一次 | 用烟尘衰减；切线；离开光带 |
| 试制员 | 补放每回合限一次且消耗库存；引爆每回合限一次 | 耗尽库存；保持距离 |
| 老库管 | 退件每回合限一次 | 用低成本效果骗出退件；改用不依赖场地的手段 |
| 灯台值守 | 转灯每场限两次 | 一次转到位后再绕；或上去找他 |
| 塔之守卫 | 放行每回合一次，共三回合；清场每组机关一次 | 清场后再布；或直接拆掉该组机关 |

## 四、核心位档案

### 划线教官（人类·精英教职·土系）

| 项目 | 内容 |
|---|---|
| 一句话 | **他在地上划线，线内是他筑起来的地。** |
| 来历 | 学院教职，持"刻阵"资格：在维护现场标定安全结构、维护距离与作用边界。年轻时也是外环维护出身，做了二十年现场，手上的旧伤是某次封存作业留下的。 |
| 外貌 | 五十上下。维护护具、工具袋、标定桩与一柄夯土短杖；腰上的重锤是拆结构用的，看起来更像工具不像武器。 |
| 性格与说话 | 办公务口吻，短句。不寒暄也不刻薄，看到错误直接说，只说事。考核结束会给一句实话点评。 |
| 任务背景 | 精英考核的标准考官。他考的不是你能打多少伤害，而是**你会不会先读结构、再决定先拆哪一段**。（E01 考验／E02 乌龙） |
| 表现 | 先插桩、再夯土。动手之前地上一定先出现他要动的那一段线——**他从不凭空起墙。** |
| 单位机制 | **拆你所倚**（见上表）。他用的全是**技能临时生成或地图既有的重掩体**——同一种通用物块，不是他的专属地形。 |
| 核心威胁 | **他不断重画战场的地形**，你上一回合占好的掩体和视线，这一回合可能被他改向或拆掉。 |
| 玩家反制 | 抢先占位；把他筑的结构打掉（耐久公开）；把他引离自己筑起来的区；或者换一条不依赖结构的打法。 |
| 出场 | **E01／E02**核心位；E06；EV16 |
| 退出 | 判通过或未通过，可中止；**非致命**。 |
| 人物关系 | 与塔之守卫同一工种的前后辈；与补盾助教、替身偶是固定编队。 |

### 小铃（人类·图书管理员·风系）

| 项目 | 内容 |
|---|---|
| 一句话 | **她管的是这间屋子里的风、纸，和你能不能站住。** |
| 来历 | 学院图书馆阅览厅的当值馆员。图书馆始终属于教学区；**阅览厅属高密度可燃与受限资料环境**，当值馆员就是这一区的安全责任人员。 |
| 外貌 | 老花镜挂在脖子上，袖口用夹子别住，**不佩武器**；随身一根引风短杖。 |
| 性格与说话 | 全院最安静的人，从不提高音量。不凶、不刻薄，只是不让任何事糊过去。 |
| 任务背景 | 你**逾期没还书**，还在阅览厅大声争执。按学院规则，可燃资料区的当值馆员可就地进行一次**现场纠察**：把当事人留在阅览厅，直到处置完成。**把她打垮，处置就结束。** |
| 表现 | 她站在阅览台后几乎不动，**场上的纸替她动手**。风一起，满屋散页按公开方向挪动；她只在需要时抬手换一次风。 |
| 单位机制 | **火场换风**（见上表）。风和散页均为通用条目；第一阶段由小铃作为公开的敌方换风来源。 |
| 场地来源 | 书架（重掩体）、阅览长桌（轻掩体）、散页——全部取自通用库。 |
| 核心威胁 | **她把火变成会走路的东西。**你用火清出通路，她就把着火的那一页吹到你别的地方。 |
| 玩家反制 | 把散页烧光或打湿会让她没有可吹的东西；用书架切出暗段与挡风区；或直接压制她本人。 |
| 出场 | **E04 图书馆纠察（教学区·歼灭）**核心位；**EV02／EV03** |
| 退出 | 收手，给你开一张罚单；**非致命**。 |
| 人物关系 | 与提灯巡查是同事；与老库管互相看不上；塔之守卫借过她一本书，一直没还。 |

### 老寻（兽类·老练寻迹兽）

| 项目 | 内容 |
|---|---|
| 一句话 | **它把你的行踪写在地上。** |
| 来历 | 学院追踪与压力测试课的老训练兽，服役太久。年轻个体还在普通课上带新生，它只在郊野的考核里出场。学生都认识它，有人偷偷喂它。 |
| 外貌 | 一身旧伤，**缚环补焊过很多次**，走路有点跛。毛色发灰，眼睛浑但很亮。鼻子始终朝着你的方向。 |
| 性格 | 安静，不叫。看人的方式像在核对名单。 |
| 任务背景 | 郊野考核的搜查位：证明在这片场地上，"躲起来"不是一个能一直用的答案。 |
| 表现 | 它不追。低头、嗅、抬头，然后慢慢往一个方向走——**它走的路线就是你之前走过的路线。** |
| 单位机制 | **停得越久痕越深**（见上表）。介质是脖子上的**缚环**（既有魔导器类型），读的是**痕迹**（通用效果层）。 |
| 核心威胁 | **它把你的行踪变成公共信息**，然后由场地和别的人来处理你。 |
| 玩家反制 | 走浅水或以火场覆盖痕迹；或者放弃藏身，直接处理该单位。 |
| 出场 | **E03**核心位；**EV06**支援位 |
| 退出 | 输了会自己坐下等管理者来牵；**非致命**。 |

| 项目 | 内容 |

## 五、支援位档案

> 下列单位的**单位机制一律是第四列的条件应对**；他们使用的装置全部来自第二节的通用库。

### 补盾助教（人类·以太·结构接口）

**一句话：他把掩体当插座用。** 现场维护组的看护位。补盾的硬条件是**贴着同一片轻／重掩体**，所以他的奶源不是自己，是场上的结构。
**反应**：你打谁他就补谁。**战损账**：掩体在，你就一直在打护盾。**反制**：拆结构，或把他与结构分开。他还有一手**借墙**：结构被破坏时把碎料转成一次护盾。
出场：**N03**；**E01／E03／E04**／E05；EV13；**B01**。非致命。

### 背弩生（人类·器材·绞盘重弩）

**一句话：他逼你离开那条干净的长线。** 高年级学生。绞盘重弩**要架设才能用**——架设占一整次公开动作，架好后 2–5 格有效，**相邻两格内打不到**。
**反应**：你切线他就换点；架设期间不能射击，那是你的窗口。**战损账**：不切线就每回合稳定吃一发；换线要付移动与站位。**反制**：用重掩体、灯藤、烟尘切线；贴进死区；逼他重新架设。
**表现**：他在封线或处理装置，不是狙击你。**课后他会主动找你聊刚才那一发。** 出场：**N05**；**E02**／E06；EV03。非致命。

### 拴索助教（人类·土·约束纹）

**一句话：他把地面变成不能踩的地方。** 远程控制位，职责是不让事态扩散。
**反应**：你绕他就往前挪，在你新路线前一格刻印（每回合限一处，公开预告）。**战损账**：退路被刻死，吃的是你的容错。**反制**：用浅水、火场、烟尘覆盖约束纹（通用覆盖规则）；绕行；把他逼离有效距离。**他会先警告。**
出场：**N06**；**E02**。非致命。

### 提灯巡查（人类·光·显影）

**一句话：光照到的地方，你藏不住。** 负责让读数可追溯的岗位。
**反应**：你藏他就转灯。显影沿**直线**传播，**被重掩体、灯藤遮断即失效**；**烟尘会散射他的光**。他几乎不造成伤害。
**战损账**：有他在，你无法用藏身规避接敌。**反制**：切线、躲遮挡、用烟尘让步。
他是**精英层通向封存塔那条线的接口人**。出场：N10／N16；E05／E06；EV03／EV08；**B01**。非致命。

### 试制员（人类·过载试制品）

**一句话：他把没验收的东西一件件摆到你面前。**
工坊试制岗，资历浅、手快、胆子大，验收流程经常"稍后补"。围裙口袋插满工具，脚边一只木箱。
**任务背景**：**E02 失控校准室封锁——他就是那个忘了摘充电台的人。**
**单位机制**：**你拆他补、你近他引爆**。他把**过载装置、护罩发生器、胶着地形**摆到场上——这些都是通用装置，玩家同样可以拆、可以借、可以被它们伤到（过载伤害敌我一致）。他一共只带固定数量的试制件，**用完就没有**，所以他是越打越空。
**战损账**：不处理该单位，行动点会持续消耗于装置处理，输出窗口被推迟；硬吃爆点则直接损失生命。
**玩家反制**：优先拆装置（比追人便宜）；把过载区反用成他的坟；硬吃几发换他库存。**不含任何随机抽取。**
出场：**E02**核心位；EV13。非致命。

### 老库管（人类·旧式检定器·以太）

**一句话：他把你的东西一件件判成不合格。**
封存库的老保管。旧制服、袖套、老花镜、翻烂的登记簿，手边一台旧式检定器。**他和塔之守卫是老同事。** 会把你的名字读错，然后按读错的名字继续办下去。
**任务背景**：**E05 封存库权限核验**——他在门口按旧流程拦人，**把他打垮，路才通。**
**单位机制**：**你铺他就退**。**旧式以太脉冲**（随身检定器投影一条公开直线，造成以太伤害并施加破势——他判你的防护"不合格"）；**退件**（清掉场上一个效果层或装置，走通用覆盖与清除规则）；**登记**（挂公开的"待检定"标记）。
**战损账**：他吃的是你的**行动点**——铺垫被退件沉没，你被迫在"再铺一次"和"直接输出"之间选。他老、慢、伤害不高，但让你的场地投资贬值。
**玩家反制**：利用重物块切断旧脉冲；在标记生效前抢输出；用低成本效果骗出退件，或改用不依赖场地的手段。**不引入核验条件类目标。**
出场：E05 核心位；EV08；EV16。非致命。

### 灯台值守（人类·光·光柱）

**一句话：他让一条走廊永久不安全。** 观测塔当班值守。**EV06 的求援信号就是他发的。** 人在塔上，**不是不敢下来，是值守不能离岗。**
**单位机制**：**你用暗段他就转灯**（每场限次）。光柱是通用环境状态，**被重掩体或建筑遮断就留下暗段**。
**战损账**：那条廊不能走，绕行多付一整段移动；不绕就吃伤害。**反制**：走暗段、切线、上去找他。
出场：**EV06**；**E03**支援位。非致命。

| 人物关系 | 与划线教官同一工种的前后辈；与老库管是老同事；借过小铃一本书，一直没还。 |
