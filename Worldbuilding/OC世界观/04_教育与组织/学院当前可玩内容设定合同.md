# 学院当前可玩内容设定合同

> 状态：当前 Build 设定依据（2026-09-07）  
> 适用范围：第一人生阶段当前已设计的固定首次体验、学院任务调度图、雨后灯庭、工坊、医务室、市集与封存区域。  
> 上位玩法依据：`Worldbuilding/策划案/OCC_项目总策划案_v1.0.md`。本文件只说明这些内容在世界内为何成立，不新增数值、地图格子、敌方 AI、奖励结果或 Unity 改动。

## 1. 当前可玩内容的一句话口径

玩家打开的是维克多·维恩的一份**学院人生档案**：一名已经完成入学、持有基础实操许可的普通在校生，接受学院调度台派发的课程、维护和安全任务。地图节点把从入学至毕业间有代表性的遭遇压缩为可选择的任务序列，不是某一天的连续课表，也不是校方制造的模拟世界。

固定首次体验只取这段学院人生中的一小段入门链：确认学生档案、阅读任务调度图、完成雨后灯庭实地对抗、接受后续的事件与服务节点，再面对第一场精英考核。它不宣称维克多在当天才入学，也不预先结算毕业、战争或人生终局。

## 2. 普通学生档案与首次三件套

### 2.1 档案上可见的内容

首次体验的身份卡只应公开以下事实：

| 字段 | 世界内含义 | 不应暗示的内容 |
|---|---|---|
| 学生身份 | 已注册、已入学的普通在校生；享有常规课程和低至中风险实操任务的申请权 | 推荐生、贵族秘传、特殊班或罕见血统 |
| 实操权限 | 已通过基础防护与环境回路课的最低安全检查 | 已取得完整专业资格或不受导师监督 |
| 本次任务许可 | 调度台为本次节点签发的区域、器材和记录权限 | 对全校区域的自由通行或无限制调用封存物 |
| 任务记录 | 已完成／待完成的代表性课程和服务记录 | 精确学期、日期或连续日程 |

### 2.2 三件套的课程来源

| 当前接口 | 世界内来源 | 设计边界 |
|---|---|---|
| 普通学生身份 | 学院公开考核与工读入学后的常规学籍 | 维克多的个人背景不改变这项通用身份 |
| `就地接线` | 《基础防护与环境回路实操》中的现场固定：辨认掩体、接入临时防护回路、确认导流方向 | 它是基础课程技巧，不是家族天赋或独门能力 |
| `借障导流` | 同一课程的低门槛过渡术式：借邻近稳定结构承受和分散短时冲击 | 只能说明当前战斗规则中已经允许的护盾与移动效果，不外推新效果 |

因此，教程首次触发这两项能力时，应该把它们读作“你已学过的公共实操”，而不是揭露主角出身秘密。

### 2.3 现有实现标签的校正边界

当前 Unity 和旧数据中还遗留“护障检修户”“确认固定出身”“入学资格验证”等文字。这些是早期实现别名，与现行“普通在校生／学院实地对抗课程”设定冲突；它们不再具有世界观效力。本合同不直接修改实现，后续做 UI 与数据文案统一时，应分别归一为“学生基础配置确认”与“学院实地对抗课程”。

## 3. 学院任务调度图

学院的调度台由教学事务、区域维护和巡查记录共同维护。它不是按比例绘制的校园平面图，而是一张面向学生的任务概览：

- 区域色块表示任务所在的功能区；连线表示当前许可、人员安排和安全条件下可衔接的路线，不等于唯一的现实步行路线。
- 节点摘要来自任课教官、维护工单、巡查记录、公开求援或已批准的观察任务；危险度、可预见对象、目标和奖励类别因此可在出发前写明。
- 未公开的细节可以保留，例如对方的具体情绪、现场临时损耗和未核验的异常；它们不得反向否定已经展示的目标、对象类别或风险等级。
- “学院时序／节点进度”只记录此份人生档案中任务推进的抽象程度，用于安排阶段考核；它不是倒计时、缺课处罚、敌情迫近或剧情中的永久关门。
- 学生可以在出发前撤回，已完成节点可以作为通路复访，因为调度台处理的是任务许可与记录，不是把整个校园封成一次性赛道。
- 中庭钟楼、湖畔站与驮轨巨蚓通勤环线可以作为调度图和场景中的方向标：它们解释校园如何通勤与报时，但不显示为玩法倒计时，也不改变节点连线、耗时或可达性。

### 3.1 七区的当前内容语义

| 区域 | 原本用途与常驻人员 | 当前可以合理承载的节点 | 当前不应被写成 |
|---|---|---|---|
| 教学区 | 教室、图书馆、公开练习场；教师、助教、学生馆员 | 课程对练、资料查阅、公开讲解、器材借还 | 无人监管的高危遗迹或秘密军事实验 |
| 郊野区 | 校园外环的护障、排水、观测与生态带；巡查员、维护学生、生态员 | 灯藤与浅水场地、护障巡检、寻迹兽观测、求援 | 与学院无关的野外战争前线 |
| 封存区 | 受控档案、旧器物和观察隔离空间；封存记录员、双人巡检组、核心守卫 | 获授权的观察、维护链替班、受控遗物登记 | 学生自由寻宝、无记录拆封或可随意买卖遗物 |
| 工坊区 | 校准台、维修间、材料柜；工坊导师、技师、工读助手 | 锻造、术式专精、器材验收、材料工单 | 无来源的免费强化或不经检查的危险改造 |
| 市集区 | 学院许可的学生补给、食材和常用器材交换点；商户、膳食供应和巡查岗 | 商店、补给、食材、公开委托交付 | 黑市、封存物私下交易或绕过许可的军用品买卖 |
| 中庭 | 连接主楼、公告与集合的公共空间；学生、社团、值班助教 | 公告事件、集合、临时换班、公开演示 | 无人注意的高风险战斗实验场 |
| 生活区 | 宿舍、洗衣、膳食与工读排班；宿管、后勤、不同年级学生 | 休整、人际事件、餐食来源、工读通知 | 所有人都可无条件进入的封闭私人空间 |

图书馆始终属于教学区；它可以服务封存资料的调阅，但不因此改成封存区。

## 4. 出发、整备与已知风险

学生在进入节点前会在**实操整备点**完成登记。它由任务所属区域的值班助教或维护责任人接收，并与工坊、医务室共享必要的安全记录。

1. 学生带来的私人物品、已登记装备和学院借用器材分别登记；借用器材必须写明归还和损耗责任。
2. 调度摘要公开任务目标、已知对象、风险级别和报酬／记录类别。选择出发即接受本次许可；未出发前撤回不构成战败。
3. 医务室可以阻止明显不适合高风险任务的学生出发；封存区、异常维护或跨区域任务还需要导师或记录员加签。
4. 背包、术式和装备调整是整备点的实际工作，不是脱离世界的菜单操作。已完成节点的复访不自动补充物资，因为登记台不会把同一次配给重复发放。

## 5. 战斗 1：雨后灯庭

雨后灯庭是旧校区外庭的**学院实地对抗课程**。前一场降雨使排水沟、湿石板和灯藤都处于可被观察的状态，教师因而把它列为“环境回路、遮挡判断与安全处置”的综合练习，而不是入学审核。

- 高年级陪练生“火矢”代表可公开阅读的火系施术压力；缚环寻迹兽是受缚环约束、用于追踪与压力测试的训练兽。两者都在课程记录和助教视线内行动。
- 击倒两者意味着完成本次实地对抗记录：寻迹兽的缚环熄灭并由管理者回收，陪练生以认输结算。它们不是无名怪物，也不应在普通课程中死亡。
- 浅水、灯藤、掩体和焦痕是该旧庭原有的排水与绿化／维护条件；基础课程要求学生读懂这些条件并安全处置。具体格子、数值、敌方脚本和三条验收路线仍完全以总策划案为准。
- 课程记录员以战场日志、助教观察和器材回收记录战果。主角生命归零时，当前肉鸽人生阶段按游戏规则结束；这是一份叙事档案的失败结果，不把战斗改写成“醒来继续训练”。

## 6. 服务与资源的世界内含义

| 当前资源／节点 | 谁提供／谁承担 | 世界内交换含义 | 不改变的玩法边界 |
|---|---|---|---|
| 金币 | 学生本人、工读报酬与许可商户 | 常规补给、餐食和服务的货币支付 | 不调整总案价格、库存或效果 |
| 学院贡献 | 学院登记的课程完成、维护服务与公共责任记录 | 可交换为学院内部的有限优先级、检查服务或指定餐食配额；不是现金，也不能买通封存权限 | 不调整获得量或消耗量 |
| 材料 | 工坊工单、课程余料、公开任务交付 | 经过来源登记的维修、校准和一次性制作材料 | 不新增材料类型或掉落 |
| 工坊 | 工坊导师／技师和校准台 | 确认装备结构、术式适配与材料去向；首轮免费操作属于课程配额 | 不扩大可锻造／可专精对象 |
| 医务室 | 医师、护理员与膳食协作岗 | 健康确认、治疗、战前餐食与不适合出发时的阻拦 | 不改变恢复比例、餐食池或次数 |
| 市集／商店 | 学院许可商户和补给登记岗 | 已登记的常规器材、材料和补给交换 | 不售卖封存物、未登记军用品或绕过库存的物品 |

## 7. 人员与训练实体职责

| 身份 | 任务中的职责与权限 | 可出现的当前场景 | 常规战败／退出后果 |
|---|---|---|---|
| 陪练生 | 以已公开的技巧为学生施压，服从课程边界与停战信号 | 教学区、中庭、郊野的对抗课 | 认输、记录复盘、接受检查；非致命 |
| 助教／教官 | 签发任务、观察安全、处置越界和确认课程结果 | 首战记录、整备点、精英考核 | 可以中止课程或判定未通过；不以伤亡作为常规目的 |
| 巡查员 | 维护区域许可、处理护障与公共秩序问题 | 郊野、生活区边缘、市集、封存外围 | 以撤离、报告、交接或临时限制通行为优先 |
| 检验偶 | 承担重复、可控的术式／器材测试，避免真人承受未知载荷 | 工坊、教学练习场、经批准的封存观察 | 停机、封签、回收和校准；不可当作无来源魔物 |
| 封存记录员 | 维护双重记录、物件来源与观察权限 | 封存区、遗物事件、维护链交接 | 暂停访问、补全记录或移交安全组 |
| 核心守卫 | 只在封存核心与高风险维护边界执行硬性阻断 | 封存塔核心、终考前提 | 先隔离／驱离／报警；若异常升级，后果由专项内容另定 |

## 8. 封存与遗物的学生访问规则

学生接触封存资料或遗物，必须同时满足：有明确教学、维护或观察目的；有可追溯的授权者；在入区与离区各留一条记录。高风险对象另需导师或封存记录员与执行人双签。

当前内容中可以成立的事件入口只有以下几类：

- **被封存的观察记录**：学生在有监督的情况下比对既有观察档案；可带走的是被许可的抄录、课程线索或公开任务回执，而非原件。
- **维护链替班**：原本的巡检／记录班组需要合格学生协助完成已拆分的低风险步骤；学生承担的是登记、传递、观察或外围维护，不是擅自开启核心。
- **遗物／卷轴来源**：它们来自经登记的教学样本、工坊校准件或任务中已移交的安全物件。发放前必须完成来源登记和适配检查，不能以“路边宝藏”出现。

任何没有授权、没有记录、要求拆封或私下转卖的情形，都不是当前学院节点的合法普通结局；若将来要做此类剧情，必须先单列风险、责任人与失败后果。

## 9. 从新游戏到首次战斗的闭环

| 流程 | 玩家在世界内收到的答案 |
|---|---|
| 新游戏／继续 | 新游戏建立一份独立的学院人生档案；继续读取同一份档案，失败或放弃结束该档案的当前阶段，不是时间倒流。 |
| 身份卡 | 我是已入学的普通学生，持有基础实操许可和本次任务许可。 |
| 地图与节点预览 | 学院调度台把已批准的区域、路线、任务目标、已知风险和回报类别汇总给我。 |
| 整备与出发 | 值班人员登记我的装备与许可；我可以在出发前调整或撤回，进入后要对物资和任务记录负责。 |
| 雨后灯庭 | 这是有记录、受监督的环境安全与对抗课程；陪练对象和训练兽的非致命边界已经写明。 |
| 失败与退出 | 退出保存继续同一档案；主动放弃或生命归零结束本阶段档案，并按玩法规则进入结算。 |
