## 一、精英考核在学院制度里是什么

普通课程对抗（陪练生互练）之后，学院还有一档更实际的评定：**在真实设施现场、由教职带队完成的对抗处置**。它不产生分数，产生的是**风险许可的等级**——学生能不能从"在受监督下进入专业设施"，升到"可独立承担外围维护接口"。

这就是精英考核。**它首先是一门课，不是审判。** 学院在这里的态度和陪练课一致：会把难度做足，但不打算让任何人真的出事；学生受伤主要来自流程、站位和自己不肯让开，而不是来自某个人的恶意。

四个要点：

1. **它用真设施、真载荷。** 不是木刀对练，所以受伤和失能是真的。这解释了为什么精英战会打输、会死人（按玩法规则结束本阶段档案）。
2. **它由教职带队。** 学生不是被扔进场地，而是在一套标准教学编队面前作业；教官有权中止考核（见 §9）。
3. **它比较的是同类记录。** 不同学生、不同场地的考核结果要能横向比较，所以编队必须标准化。
4. **它与终考不是一回事。** 精英考核考"你能不能在有人带的情况下完成一次现场对抗"；封存塔的终考考"你能不能独立承担"（见 `封存塔与终考前提.md`）。

学院时序上，精英考核消耗 3（普通战 2），因为一次考核要占用整块设施、一个授权窗口和一整套值守编队。

## 二、标准编成：一名教官 ＋ 一条维护链

学院把这类考核固定成一套教学编队：**一名划线教官担任核心，配两名助教或陪练**——其中一个维持结构与接口（维护位），另一个把学生从安全站位上逼出来（施压位）。

这解释了一件看起来像"换皮"的事：**不同区域的精英考核看到的是同一套人，变的只是场地与设施。** 工坊、郊野、封存区的精英编队相同，是因为它们是同一门课在不同现场开设，用的是同一份教学编制。差异必须来自场地、设施和那一场的具体命题，而不是换一批人。

**"划线教官"是岗位，不是一个人的名字。** 学院里有若干持这一岗位的教职，都能开设同一份标准考核。所以玩家在不同区域遇到的是**不同的当值教官**——就像同一门必修课换个老师上，考纲一样，脾气不一样。名字与个性留给台词专项，本文不指定。

## 三、划线教官

| 项目 | 世界内内容 |
|---|---|
| 身份 | 学院教职。"刻阵"是真实工种：在维护现场把安全结构、维护距离与作用边界标定出来，别人才能安全作业。 |
| 为什么在精英层 | 他是能独立签发并监督高风险现场作业的人；普通课程由助教或高年级陪练承担。 |
| 为什么身边必带维护队 | 他的职责是让考核在真实设施上安全进行。所以身边固定有一个维护位（随时恢复被测试者赖以站住的结构）和一个施压位（把人从安全站位逼出来）。 |
| 战斗表现的世界内解释 | 回合开始获得的护盾＝他在自己周边维持标定结构；破势重击＝他拆掉你站以立足的结构，而不是单纯加重伤害。 |
| 他实际在考什么 | 你能不能先读出接口和维护关系，再决定先拆哪一条，而不是站在原地比输出。 |
| 战败后果 | 他判定你通过或未通过。可以中止考核。不以伤亡为目的。 |
| 编成边界 | 只与**可预览的维护关系或封线关系**组合；不单独存在、不做数值大怪。 |

## 四、维护链上的岗位

学生被要求先识别接口、再决定拆哪一条。这五个岗位就是可被读取的"接口"：

| 岗位 | 世界内职责 | 在考核里构成什么 |
|---|---|---|
| 补盾助教 | 维持结构与维护接口，给最需要的一方补齐防护 | **可被切断的队友接口**——考核的主拆解对象 |
| 拴索助教 | 远程控制源，负责封住换线口 | 迫使学生在作业前预留退路 |
| 背弩生 | 远程窗口与视线压力，低速高单发 | 提供一条可被读、可被切的公开射线 |
| 提灯巡查 | 显影与破势，负责让读数可追溯 | 破势来源；与补盾助教构成可见维护链 |
| 替身偶 | 承担重复、可控的术式／器材测试，避免真人承受未知载荷 | 可回收校准实体，被拆掉不影响人员安全 |

真人不承担未知载荷：这是学院把"施加破势、承受爆破、反复撞击"交给检验偶的原因，也是它**不可当作无来源魔物**的原因。

**维护链同时也是安全网。** 助教维持结构不只是给教官加防护，也是为了让作业面在载荷下不塌。所以"拆维护链"在世界内的真实含义是**拆掉现场的安全栏杆**——这是一个合法、有效、赢得更快的选择，但它会被教官看见、被记录、并且当场点评。精英战的教学要点之一就是让学生意识到这件事有代价。

## 五、楔角

| 项目 | 世界内内容 |
|---|---|
| 是什么 | 校准工坊为三类维护材料制造的**精英构装体**，不是战斗兵器，是校验设备。 |
| 原始用途 | 在维护现场验证浅水冷却、灯藤隔离与稳压晶簇承压三类材料的承压极限：按公开路线冲压，记录材料在哪一格、以什么方式失效。 |
| 为什么出现在首轮固定精英 | "三材承压场"是把它放回原始用途的考核：学生要在它按公开路线冲压时读懂路线、改线，并利用被改变的材料反击。 |
| 行为边界 | 它不判断、不记仇、不受劝说；锁定的目标格不因玩家移动暗换，只按当前公开地形与占位重算路线。 |
| 战败后果 | 停机、封签、回收与校准。它是设备，没有伤亡问题。 |
| 表现要求 | 蓄压、锁线、撞击物块、浅水冷却、干地卸压必须是不同且可预览的姿态或灯色——这是设备在**如实报告自己的状态**，不是演出。 |

## 六、精英稳压晶簇

它不进普通战，因为它不是"更硬的晶簇"，而是**能记录载荷的校验件**：加厚基座、稳定环与维护接口是为了在承受大型以太冲击时留下可读的失效记录。

所以它的正确位置只有一个：承接精英级构装体的公开冲压或维护关系，并忠实地坏掉。它敌我一样受爆裂与碎晶影响。

## 七、三场精英的动机

学院对精英考核的定位是"课"，所以三场开局都不写"有人要对付你"。每场各有自己的来由，**考验、乌龙、误会各占一场**：

| 节点 | 动机类型 | 一句话 |
|---|---|---|
| E01 刻阵工坊高阶考核 | **考验** | 你报了名，这是排进课表的正式考核，教官按标准编队陪你打一场。 |
| E02 失控校准室封锁 | **乌龙** | 有人下班前忘了摘充电台，第二天开机读数跳红，你正好在圈里。 |
| E03 断崖导能柱考察 | **误会** | 巡查记录把昨夜在柱基附近活动的人读成了你，教官按流程带队来确认身份。 |

E04–E06 属扩展池，沿用同一门课、同一套编队与同一类动机，只是现场与来由不同（"开玩笑／整新生"这一类留给扩展池，本阶段三场不做）。

### 7.1 E01 刻阵工坊高阶考核｜考验

- **事情**：这是排进课表的正式考核。工坊当天清场，教官按标准编队到场，把设施交给你当作业面。
- **为什么打**：他不是敌人，是考官。他要看的不是你能打多少伤害，而是**你会不会先读接口、再决定先拆哪一条**。
- **本场好玩的地方**：维护链本来是**安全栏杆**——助教续盾是为了让作业面不塌，也让你不至于被真的埋在里面。你要是把维护链拆了，确实赢得更快，但教官会当场点评一句"你把我这边的护栏拆了"。这句话应当进战斗台词，是这一场最好笑也最像课堂的地方。
- **怎么结束**：他判通过或未通过。没过可以补考。观察廊上很可能有同学在看。

### 7.2 E02 失控校准室封锁｜乌龙

- **事情**：前一天下班前，有人把一台单元挂上充电台忘了摘。第二天开机，校准室的载荷读数直接跳红，按流程封锁现场。
- **为什么打**：你正好在附近，被一起圈进去了。三个人不是来打你的，是来**把房间弄回安全状态**的——而你一直站在他们要做事的格子上。
- **每一招其实在做什么**：

| 表现 | 实际在做什么 |
|---|---|
| 拴索助教的石索锁步 | **撤离暂留**：把你按在原地等撤离组过来，不是拷问。 |
| 重弩的绞盘重矢 | **在打那台卡住的装置**，你老站在射线上。 |
| 补盾助教的续盾 | **维持作业面的结构**，不然那台单元会掉下来。 |
| 替身偶 | 替人去挨那台单元的载荷——这就是它存在的意义。 |

- **怎么结束**：房间安全了，大家收工，顺带把你的考核记录签了（"你在异常处置里干得不错"）。事后那张"忘了摘充电台"的班次记录会被翻出来，这是学院里最常被拿来笑的事。
- **友好边界**：全程没有一个人想伤你。你受伤主要因为你不肯让开。

### 7.3 E03 断崖导能柱考察｜误会

- **事情**：郊野导能柱需要现场考察。巡查记录上写着"昨夜有人在导能柱基座附近活动"，值班的把这一条读成了"有个学生在禁区乱逛"。而你那天正好在那一带做外环维护的工读。
- **为什么打**：教官按流程带队来确认身份。你当场没法证明你不是那个人——你的许可确实覆盖外环，但不覆盖柱基。于是"先按标准考核流程处理"。
- **转折**：打到一半，原始记录调出来了，是认错人。但教官没有当场收手——你已经打到这一步了，他干脆把这一场**记成你的考核**，"反正你都要打一场，省一趟"。
- **怎么结束**：他用自己的方式道歉——不说道歉的话，但给你签个好东西，或者请你喝一杯难喝的茶。
- **埋线**：这一场真正的起因是**一份写错的记录**，不是恶意。它和塔之守卫每天面对的"读数对不上台账"是同一个世界的毛病，但本场**不点破**，只当一次普通的乌龙。

### 7.4 三场的共同基调

1. **不写恶意**：没有一场的动机是"有人想害你"。
2. **伤害有来源**：受伤来自流程、站位、载荷和不肯让开，而不是来自某个人的恨意。
3. **胜负不对人**：赢了不代表谁被羞辱，输了也不代表谁被记恨；教官可以中止、可以补考、可以当场改判。
4. **笑点来自课堂**：护栏被拆、忘了摘充电台、记录认错人——笑的是流程和乌龙，不是某个角色的狼狈。

## 八、精英奖励从哪来

| 奖励 | 世界内来源 |
|---|---|
| 三个被动术式三选一（回火导流／动势点火／缓冲覆层） | 不是拾取物。考核结束后，教官按学生**实际用出来的那条路线**签发专项术式登记：火术续航、位移后武器强化、回合开始保底防护，分别对应他亲眼看到的三种打法。所以只能选一项，且选择可以解释为"记录你证明过的那一条"。 |
| 低压回路护额、定锚支架 | 工坊与封存区出的登记器材，随考核合格发放。定锚支架能抵消一次强制位移，正是对付承压机冲压推位的对症件。 |
| 金币 6 | 工读报酬与考核补贴，不是战利品。 |
| 随机精英的"精英奖励" | 同一口径（考核合格后按路线签发与发放），具体内容包待冻结。 |

## 九、非致命边界与战败后果

| 对象 | 战败／退出的世界内后果 |
|---|---|
| 教官、助教、陪练生、巡查员 | 判定通过或未通过、中止考核、记录复盘、接受检查；非致命。 |
| 替身偶、楔角 | 停机、封签、回收、校准。 |
| 学生（维克多） | 生命归零时按玩法规则结束本阶段人生档案；这是**一份档案的失败结果**，不写成"醒来继续训练"，也不写成校方模拟。 |
| 重新挑战 | 考核记录允许重考；恢复到场前状态是重考的正常口径，不是时间倒流。 |

**待确认项**

1. 精英考核的"许可分级"说法是否成立——即通过精英考核＝可被授权独立承担外围维护接口。

3. 精英奖励按"路线签发"的解释是否采用。
4. 三场的动机分配是否确认为「E01 考验／E02 乌龙／E03 误会」，以及"开玩笑／整新生"是否确实留给扩展池。
5. "划线教官是岗位而非固定一人"是否采用——这决定玩家在不同区域遇到的是不同当值教官，还是同一个人。
