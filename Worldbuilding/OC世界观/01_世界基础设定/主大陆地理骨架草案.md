## 一、先确定的整幅构图

主大陆采用“北部草原与内流湖盆—中央错列山地与东西通道—南部弧形山地及通海河谷”的结构。西部与东部分别保留足以承载农业和人口的连续平原；西南是多港湾和岛链，东南是相互分隔但可以通海的盆地。

山系不照着每一条国界描一圈。分水岭、河谷、平原边缘和海岸提供不同类型的边界条件；现有国界先保留为政治草案，不能因为补地理就静默重画用户已有疆界。

主大陆面积量级约5,500万平方公里，现有整数米坐标及比例不变。大陆名称、全球经纬度、其他大陆位置和各国正式国名本轮不作新决定。

## 二、七个自然地理单元

| 单元 | 第一版安排 | 后续能够承载的内容 |
|---|---|---|
| 北部草原与湖盆 | 北缘较寒凉，内陆草原与封闭湖盆相接，南侧低山和高山并存 | 季节迁徙、农牧接触、盐湖与草原生态；不能把北方帝国全境归为同一种环境 |
| 西部河谷平原 | 西原河及支流汇集的王国核心农耕区，西侧通海 | 庄园、地方城市、粮食转运和主角生活圈 |
| 东部大河平原 | 中央山地向东排水，连片平原提供人口与内部交通纵深 | 东部国家的征粮、陆路组织与河流运输；不预设成熟工业设施 |
| 中央山间走廊 | 错列山脊间串联河谷、低鞍部和盆地，容纳缓冲诸邦 | 东西商路、边境许可和灰垣战争；不是第七大国，也不是唯一跨大陆山口 |
| 西南裂岸与岛链 | 多港湾、短河、背山海岸和近海岛群 | 海权共和国的多中心港口网络及海上联系 |
| 中南通海河谷 | 南贯河穿越南弧山地的缺口，连接内陆和南海 | 和平中立国的贸易、调停和避难功能；独立原因仍包含既有外交与高阶施术者条件 |
| 东南山间盆地 | 山带分隔数块盆地，外流湖和河谷仍接向海岸 | 寡头家族的地方基础、遗迹分布及盆地间竞争 |

## 三、四组主山系

| 山系工作名 | 走向与作用 | 规划高程口径 |
|---|---|---|
| 北缘—西北山系 | 从西北海岸低山转入草原南缘，分隔北部与西部平原；保留多处低山口 | 主体约1,500—3,500米，局部峰区可到4,000米量级 |
| 中央断山带 | 南北向错列山脊与断陷谷地，承担主大陆中部的分水与交通约束 | 主体约2,000—4,500米；灰垣通道走较低鞍部和河谷 |
| 东陆分水山系 | 位于东部平原南缘，分开东海外流与东南盆地水系 | 约1,800—3,800米，至少保留一条南北陆路 |
| 南弧山系 | 西南至东南的弧形高地，包含支脉、海岸平原和中南通海缺口 | 约2,000—5,000米；高峰集中在部分山段，不均匀铺满整条山弧 |

这些是地理规划范围，并非已生成或测绘的高程。当前骨架图不冒充全大陆4公里DEM；以后在既定主脊与流域约束下生成区域地形，不能先填随机高山再反过来解释国家。

## 四、五组流域与两类湖泊

| 水系 | 流向与出口 | 明确保留的区别 |
|---|---|---|
| 西原河 | 北缘及中央山地 → 西部平原 → 西部海湾 | 浅河支流衔接主角生活圈；下游可研究区域航运，不能先认定全程通航 |
| 东原河 | 中央山地 → 东部大河平原 → 东海 | 北侧丘陵支流在平原汇入，不任意穿过南侧分水山系 |
| 南贯河 | 灰垣南缘高地 → 中南河谷 → 南弧缺口 → 南海 | 中立国具有真实通海条件；河谷不自动等于全部河段都能通大船 |
| 陆心湖内流域 | 草原南缘及东部低山 → 北部封闭湖盆 | 陆心湖没有本轮设定的地表出海河；盐度与枯丰变化待气候细化 |
| 岚盆河 | 东陆山系南坡 → 岚盆湖 → 东南河谷 → 海岸 | 岚盆湖是外流湖；不能与陆心湖混成同一类水文环境 |

地图中的支流共用主河汇流点的整数米坐标。河网附有用于规划核对的节点高程关系；它们只表达设计上的上游、下游、湖面和海平面，不是地形采样值。入海口落在现有海岸上，湖内连通段与河段分开记录。

## 五、五组交通联系

1. **王国—灰垣通道**：王国内地—雾桥村—浅河镇—星契学院城邦—灰垣山间通道—东部平原。保留学院的独立法律与国际中立地位。
2. **中南通海谷道**：灰垣南缘—南贯河上游—中立国河谷—南海口岸。陆路、渡口及具备条件的河段分工，不把整条路线预设成航道。
3. **草原南缘商路**：沿农牧接触地带串联多处山口与集散地，存在季节差异和绕行路线。
4. **西南沿海交通链**：港湾间陆路、短程航运与岛链航路互相补充，不画陆桥串起所有岛屿。
5. **东陆山口通道**：东部平原通过鞍口进入东南外流盆地，再接海岸。

本轮不批量定首都、城市人口、铁路、成熟工业走廊或道路等级。雾桥村、浅河镇及学院的现有地图点位不移动；大陆级点位仍不替代后续区域旅行距离与道路测定。

## 六、三处天然异常区的落点

- **中央山根异常带**：沿中央断裂、山根和谷地分段出现，跨越国家及缓冲带。分别确定稳定段、季节活跃段与危险点，不能一律封为禁区。
- **陆心湖回响区**：湖盆、地下岩层和以太环境相互作用；盐湖与异常现象均不能成为对方的唯一解释。
- **南弧雾带**：山地水汽与天然以太环境叠加的局部雾区，保留可通行段，不取代全球气候规律。

三处都以天然成因为基础。本轮不新增统一远古事故，也不裁决远古文明衰落真相。

## 七、六方边界的处理

北方与王国之间采用“山脊、低山口与农牧接触地带相间”的边界条件；王国与东部国家之间保留缓冲诸邦及灰垣通道。西南地区保留裂岸港湾网络，中立国保留通海河谷，东南地区用山盆地组织地方分隔。

以上确定的是后续细化的地理条件。本版直接复用已有国家及岛屿顶点，不移动用户既有疆界，也不把四个国家写成天然封闭国。没有改变任何六方制度、联盟或战争结果。
