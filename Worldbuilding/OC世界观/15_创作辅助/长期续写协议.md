# 长期续写协议

## 目标

这份协议专门用于保证这个世界观可以被长期、反复、多人次地续写，而不会在几十万字之后出现设定冲突、语气漂移、时间线崩坏或世界基调失控。

如果目标是长期扩展，就不能只靠记忆，必须把续写本身工程化。本协议服从目录根部 `README.md` 和 `00_项目总览/世界观索引.md` 的效力规则。

## 一、续写的四层结构

后续所有写作内容，必须明确自己属于以下哪一层：

### 1. 底层规则层

包括：

- 超凡源头
- 魔法规则
- 元素与机器逻辑
- 资源与污染机制
- 国家、工业、战争的硬约束

这层变化最慢，一旦改动，影响最大。

### 2. 中层制度层

包括：

- 学院制度
- 军队编制
- 执照与法律
- 财阀与组织运作
- 宗教与思想体系

这层是世界如何运转的骨架。

### 3. 人物与组织层

包括：

- 角色背景
- 家族、组织、派系
- 利益冲突
- 职业路径

这层最适合写故事张力。

### 4. 剧情事件层

包括：

- 主线剧情
- 支线事件
- 战争爆发
- 阴谋、恋爱、成长、任务

这层变化最快，也最容易把前面三层写乱。

## 二、续写顺序原则

长期续写时，默认遵守以下顺序：

1. 先确认底层规则有没有冲突
2. 再确认制度层能否支撑新内容
3. 再把人物放进制度和世界里
4. 最后才推进事件与剧情

换句话说：

**先问世界能不能承受，再问角色会不会去做。**

## 三、每次续写前必须回答的 6 个问题

不管是自己写，还是由 Codex 或其他协作者续写，每次开写前都应该先回答：

1. 这段内容属于世界哪一层
2. 它会不会改动已锁定设定
3. 它发生在什么时间点
4. 它涉及哪些国家、组织、职业和元素系别
5. 它会不会影响其他文件里的既有设定
6. 写完后需要同步更新哪些索引或模板

如果这 6 个问题答不清，就先不要写长文。

## 四、文件维护规则

### 1. 主设定文件只做“整合后写入”

不要把草稿、脑洞、剧情即兴直接写进主设定文件。

主设定文件应该只承载已经成形、经过整理的内容。

### 2. 新增内容必须写进正确目录

例如：

- 国家写进 `03_国家与地区`
- 社会结构写进 `08_社会与日常生活`
- 角色写进 `11_角色档案`
- 剧情写进 `13_剧情与事件`

### 3. 汇编稿不是主稿

飞书页面、附件汇编和其他导出内容只是发布产物，不是主编辑目标。

真正要维护的是源文件本身。

### 4. 每写一篇重要新文档，至少更新一处索引

最低要求是更新：

- `00_项目总览/世界观索引.md`

必要时还要更新：

- 时间线
- 术语索引
- 角色关系

## 五、设定冲突处理规则

后续写到百万字时，冲突几乎一定会发生，所以要提前定规则。

### 1. 底层规则优先于剧情灵感

如果一段剧情需要推翻底层规则，默认先改剧情，不先改世界。

### 2. 已锁定设定优先于暂定设定

如果冲突发生，优先保留“已锁定”内容。

### 3. 后写内容不能偷偷覆盖旧内容

如果真的要改旧设定，必须在对应文件里明确标注“修订”。

### 4. 废案要单独归档

不要直接删除旧想法，统一丢进废案区，避免未来反复绕回去。

## 六、百万字规模下的拆分策略

如果你真要写到很长，文件一定会越来越多，所以必须提前定义拆分原则。

### 1. 世界主设定按主题拆，不按心情拆

例如：

- 魔法体系
- 经济工业
- 国家地理
- 军事战争
- 组织与势力

### 2. 剧情按阶段拆

不要把所有剧情都塞在一个文件里，而是按：

- 卷
- 篇章
- 事件阶段

拆开。

### 3. 角色按重要性分层

主角、核心配角、组织关键人物、背景人物分开维护。

### 4. 时间线必须单独维护

任何长篇世界观一旦没有总时间线，最后一定崩。

## 八、协作者续写原则

如果以后长期让 Codex 或其他协作者参与续写，使用以下固定工作流：

### 新增设定或大段续写前

从以下来源定位相关段落；小修只读目标文件和适用规则，已读且未变化的材料不重复读取：

1. `世界观索引.md`
2. `世界观总纲.md`
3. 本次目标主题对应的主文件

### 每次完成续写后

完成后至少执行：

1. 更新对应主文件
2. 更新索引
3. 如有角色/时间影响，再更新角色卡或时间线
4. 如需发布，再从当前活动源生成一次性发布镜像；镜像不得留在活动目录充当并列版本

## 九、什么内容最适合继续写

为了让世界观尽快具备长篇承载力，优先级建议如下：

1. 国家格局
2. 经济工业体系
3. 军事体系与大战前夜
4. 学院、财阀、军方、教会等关键组织
5. 主角群对应的角色卡
6. 大事件时间线

## 十、叙事文本的文风规范

本节适用于史书、传记、世界内文献、剧情正文与角色独白；规则表、技术合同、数据表和验收记录以清晰为先，不强套文学口吻。

### 1. 避免讲解员语气

- 不用“先看……再看……”组织叙事，也少用“换句话说”“值得注意的是”“归根结底”等替读者总结的提示语。
- 少用“不是……而是……”“并非……而是……”这类二分式纠正句。需要转折时，让事件的因果、人物动作或材料之间的矛盾自己显露出来。
- 不把段落写成“提出概念—立刻解释—给出标准答案”的说明书节奏。史书可以叙事、停顿、留下争议，读者应有自行判断的空间。

### 2. 让作者在场

- 重要叙事文本须明确作者或叙述者的身份、材料来源、社会位置与盲点：他为何见到这些材料，为什么愿意相信其中一部分，又会漏掉什么。
- 作者可以表达偏好、犹疑、厌恶、怀念或讥讽；观点必须来自其经历、职业和可见证据，不能替世界宣布唯一正确结论。
- 第一人称宜节制使用。它应当改变读者对材料的理解，例如“我在退件簿里看见……”；不得只反复宣告主题。

### 3. 口气与句子

- 可少量使用符合人物身份的语气词与口语收束，如“吧”“呢”“罢了”“总归”“偏偏”“到底”。它们服务人物气质与段落节奏，每段最多一处，避免堆成撒娇或网络口吻。
- 长短句交替。关键信息落在具体物件、动作、账目、地名或人的选择上，少用抽象名词连缀。
- 对世界观事实保持克制：一项制度、技术或战争的意义，应从它改变了谁的路、钱、工时、伤病或权利中写出来。

### 4. 史书的额外要求

- 以时间推进为主线。每个时代至少写清关键事件、可用材料、制度后果与仍有争议的空白。
- 编年不等于流水账。选择能改变后续时代的事件，写出其起因、当时人的有限认知和长期余波。
- 未定事实必须保留为争议、传言、材料缺口或作者的保留意见；不得为了章节完整伪造精确年份、统一历法或单一真相。

## 十一、结论

如果想把这个世界写到百万字，关键不是“灵感够不够”，而是：

**你的设定是否能被持续维护。**

所以从现在开始，世界观必须同时具备三种东西：

1. 可读性
2. 可扩展性
3. 可维护性

而这份协议的作用，就是保证你后面写得越多，世界越稳，而不是越写越乱。
