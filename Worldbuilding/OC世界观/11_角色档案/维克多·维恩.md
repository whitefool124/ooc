# 维克多·维恩

> 状态：已锁定核心（2026-09-07）。维克多是 OCC 当前首名完成的可玩主角；玩家可在新存档的角色选择界面选择他。肉鸽的随机性只呈现他人生中的不同可能性，不替换其身份、身世或主线故事。学院、全面战争与战争转折构成其完整可玩人生，毕业不是结局。

维克多的父亲博恩是佃农兼灌渠与农具修补工，母亲艾妲在教会厨房和村中缝补间轮值；妹妹梅拉比他小六岁。这个家庭既不掌握遗迹秘密，也没有稀有血统。父母希望他取得一个能被跨国承认的资格，首先是为了让他拥有不依附土地的职业选择，而不是替家族翻案。

## 二、外在形象与可玩阅读

- 身形偏瘦但结实，长期劳动留下粗糙手指与不自觉检查器物边缘的习惯；深褐短发、灰绿眼睛，左眉尾有幼年修渠时留下的小疤。
- 校内常穿修补过的深炭色短外套、耐湿长靴和无指防热手套；铜扣、笔记夹和制式学生证只承担工作与许可含义，不做贵族装饰。
- 常用物是学院借用、后来凭工读逐步买断的折柄导热短杖。它既是引导火系术式的媒介，也是检查热损、松动接头与护障缝隙的工具；不是祖传武器。
- 短杖的握环系着三枚大小不一的旧铜签片。它们最初只是他工读时区分“操作、维护、担保”三类记录的顺手办法，后来成为他的识别物：每遇到高危器物，他都会先取下一枚签片登记，而不是先抬杖施术。
- 战术单位要读为“携带工具、能走入危险区域的学生”，而不是制服化的军人或天才法师。视觉上以炭墨、旧铜和很小的受控火光为主，遵循现有 64px 单位合同。

### 余温复写

维克多最具辨识度的本领不是强大的火术，而是一项从维修工作中练熟的微型火系技巧：他用几乎不伤介质的低温火，令被硫化、刮磨或覆写过的铜牌、纸边与导线标签显出残留痕迹，再用冷却、护幕和人工复核确认读数。他称它为“余温复写”，从不把它当作能替代证据的魔法。

这项技巧源自公开训练，任何熟练施术者理论上都能学习；难得的是维克多愿意在没有掌声、也可能惹麻烦的场合停下来做完复核。学院后期，人们记住他的方式不是“最强的火术师”，而是那个带着三枚铜签片、能让被抹去的名字重新显出来的年轻人。

## 三、能力、战斗与限制

| 项目 | 设定 |
|---|---|
| 以太适配 | 正常中上水平；优点是稳定、肯复核，不是储量异常或稀有天赋。 |
| 主修系别 | 火：擅长点燃、加热、干燥、焊接式熔接和短时热压；成长方向是把火用成受控的工程力量，而非单纯爆炸。 |
| 共同课程 | 中性护幕、基础调息、器物安全和野外急救；均为学院公开课程。 |
| 首发可读动作 | 火花、以太护幕、回路调息与导热短杖近距动作，分别对应现有教程中的攻击、防护、恢复与互动阅读。具体数值、候选奖励与后续术式仍以 OCC 总策划案为准。 |
| 优势 | 能在移动、地形与器材限制下保持动作顺序；习惯先确认风险、再处理最坏的泄漏点。 |
| 限制 | 施术时间过长会造成手腕痉挛、脱水与注意力下降；潮湿、破损媒介和临时过载会明显降低火术稳定性。他在压力下会独自接手责任，反而延迟求助。 |

维克多没有魔法生物沟通、魔导增幅适配或任何隐藏能力。若未来取得更强器物或双系学习成果，必须来自课程、工坊、关系与公开代价，不能追溯成血统觉醒。

## 四、性格与内在矛盾

| 维度 | 设定 |
|---|---|
| 表层气质 | 安静、观察力强、对陌生人有礼但不热络；做事先列顺序，讨厌把问题说得比实际更轻。 |
| 长处 | 在资源有限时仍能看见他人承担的成本；会把复杂话说成可执行的步骤。 |
| 缺点 | 把“不给人添麻烦”误当作独立，把被托付的工作误当作必须独自偿还的债。 |
| 核心欲望 | 获得一份不靠土地、姓氏或施舍维持的专业资格，并让故乡的人遇到事故时有更可靠的选择。 |
| 核心恐惧 | 自己取得的上升机会来自他人被迫承担的风险；若留下记录或指出问题，会让家人与同伴失去本已脆弱的安全。 |
| 价值变化 | 从“把分内工作做好即可”走向“专业资格意味着看见责任链并拒绝伪造它”；他学会寻求协作，但不把责任推给别人。 |

## 六、已锁定的故事功能

维克多不是被预言选中的救世主。他的故事以一个普通学生如何取得专业资格、发现制度中的责任逃逸、在不越过许可与能力边界的前提下保护具体的人为核心。他既能进入战斗，也能成为工坊、医务、封存、生活区、边境与战区事件的连接点。贯穿他一生的行动准则是：**“先把会受伤的人写下来。”**

学院是他的第一可玩人生阶段；全面战争和战争转折是第二、第三可玩阶段。维克多在战争中以独立受雇的维护者／乱世游侠身份行动，不是正规军人；他在统一灰垣主战场上的关系轨迹、战争终局与完整晚年见 `07_军事与战争/灰垣主战场与三阶段战争主线.md`。不得再将毕业后的职业、晚年或死亡写成替代战争内容的预设后记。
