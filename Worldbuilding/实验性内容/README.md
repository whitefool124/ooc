# 实验性内容

本目录存放**尚未进入正式管线的实验性素材与样板**：为验证某个做法是否可行而产出的原料、解码结果、拼装样板与 QA 记录。

## 效力

- 本目录**不构成任何规则**，也不具备美术合同效力；其中的文件不是正式资产，不得直接导入 Unity。
- 与 `ArtSource/` 的区别：`ArtSource/` 存放已进入正式生产流程的原料与 manifest（走完校验与人工审美）；本目录只放还在试的东西。
- 与 `Worldbuilding/归档/` 的区别：归档是**已有结论的过去版本**，只用于追溯；本目录是**尚未得出结论的候选**，随时可能被采用、改写或丢弃。

## 使用方式

1. 新实验按 `YYYY-MM-DD_主题/` 建子目录，保留原始 `source`、解码结果与 `qa` 记录，便于复核。
2. 实验得出结论后：被采用的走 `ArtSource/` 的 manifest 与校验流程转为正式资产；被否决的移入 `Worldbuilding/归档/`。
3. 不要把本目录内容当作活动规范引用；正式美术规范以总案第 5 节与附录 A、美术与界面规格表、`Tools/OCCArt/occ_art_contract_v1.json` 为准。
