# 非护盾特效样板

已在原专属场景 `Assets/Scenes/PixelVfxShowcase.unity` 更新七种模式：火矢轨迹、火焰爆破、以太消解、空间冲击、热浪折射、移动光源、地面电弧。护盾椭圆罩体、边缘高光、折射罩与碎裂代码已移除；鼠标落点不再向护盾边界吸附，改为场地内自由定位。正式护盾数值和战斗结算没有改动。

`verification.json` 是本轮 Play Mode 的最终成功回执。七个按钮通过真实 UI Raycast 与点击处理，分别取得不同的 GPU 输出；重播、暂停、慢放、原画对比、强度与自由落点均已执行。Shader 没有编译消息。`native-0.png` 至 `native-9.png` 是实际 240×180 缓冲读回，其中 7 为原画对比，8 为慢放与提高光强，9 为改变落点。

`fire-final.png` 是 Unity CLI 在火焰爆破暂停状态下直接捕获的真实完整 Game View。验证器使用异步 ScreenCapture 的 `showcase-1.png` 和 `showcase-6.png` 捕获到了随后的界面状态，已移除这两张不对应指定效果的截图，以原生缓冲与最终 CLI 截图为准。

验证前出现过两个已解决的问题：后台不推进 Player Loop，以及长首帧跳过一次性效果。展示场现在仅在运行期间允许后台播放，销毁时恢复原值；单帧演示时间最多推进 50ms。验证器等待真实演示阶段并请求 Game View 重绘。早期失败日志保留用于追溯，不是最终结论。

场景、材质与 PNG 的 GUID 不变，没有替换正式美术。场景字段和保存走 Unity Editor API 与 CLI，没有手改 YAML。当前光照仍是屏幕空间法线和遮挡近似，这些样板尚未绑定正式技能、伤害和地形结果。

最终验证期间 Console 为零错误、零警告；其后用于冻结截图的 CLI 动态 eval 引出了插件自身的字符转换异常，和之前同类工具问题一致。该异常不属于展示场 Shader 或战斗逻辑，保留 Console 记录并单独归类。

战斗外界面方案见同目录 `战斗外界面特效规划.md`，是待审阅方案，尚未批量实现或同步飞书产品母版。
