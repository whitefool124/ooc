# 实际掩体路由补齐与温室实景

实机场景核对发现，完整掩体由 `AcademyBattlefieldLayoutCatalog.CoverVariant` 选择 `Art/AcademyCoverCandidates20260924` 资源，并不会复用旧档案木架完整态。旧档案木架损坏/残骸及宝箱、诱导灯的配套仍保留，但不能称为全部完整掩体已覆盖。

本轮新增训练挡板完整态、书箱完整态两套配套（四张32×32数值图），`Hd2DBattlefieldPropMaps.Entry` 现在显式记录实际底色资源目录。两项均为非金属材质，使用内置黑色中性金属/玻璃区域输入；石材压边、木材、纸页、布带分别由独立法线和粗糙度表达，不新增硬件、发光或玩法。

## 来源

每项独立内置生图，四象限配套原料精确裁取上方法线/粗糙度。书箱第一版主体居中向上移动，不符合底色下半部锚点，保留为rejected_anchor_r1；第二版提供明确原生BBox x6–24、y15–30，纠正锚点，但法线中的布带仍混入固有色，因蓝通道检查失败未交付。独立内置编辑第三版仅修正数值法线，保留位置与结构。未以程序重着色或缩放代替生图。

已知32×32画布数值场注册选择每格原料实际RGB代表值，无插值、减色或新增RGB。OpenGL +Y上、线性、Point、Clamp、无Mip、无压缩，共用底色UV与32 PPU。实际数值范围、来源、切图及注册指纹见material_inventory.json和各物件目录。源区域严格对齐及完整场景像素密度仍需人工复核，注册不是普通Sprite1.2网格门槛通过，不降低门槛、不晋升FORMAL。

## 本次验证

局部离屏对照只覆盖新增两项，提供两个分辨率、法线/表面属性分别开关、旋转主光及中性光。没有重跑此前七项或全部关卡。

`live/greenhouse_live.png` 来自Unity Editor Play Mode真实B2战场相机，正常战场构建、材质、水/灯光、阴影和后处理均按当前运行时；通过已有隔离预览入口进入，不构成正常入口全旅程或Player包验收。实机中实际启用的配套物件身份见live/capture.json，退出恢复记录见live/cleanup.json。不为了同框临时摆放或替换物件，不投放诱导灯、不推进战斗或存档。

后台控制沿用已核实PlayUnfocused与临时关闭新建Game窗口的路径，不调用GetWindow/Show/Focus；退出恢复原窗口偏好，主场景保持干净、不保存。图片为原战场相机RenderTexture的sRGB读回，不含HUD，不缩放、不修图。

木凳64×32、训练垫64×32、诱导灯的实际投放反馈及大型玻璃仍待后续覆盖/核对。当前仅局部材质实装与实景证据，品质报告保持QA_PENDING；没有性能及人工审美批准。

首次温室实景发现宝箱发黑：局部样板的顶点顺序与正式Face网格不同，先前无条件翻转正式网格法线是错误的。正式三角形0,2,1本已产生朝本地-Z的法线，现撤回翻转及对应形状缓存标志，保留贴图、TBN重算与原足底深度。失败图/记录以_backface_r1保存；新实景另记每个配套纸板的朝镜头法线点积，不把局部样板通过代替实机。

修正后的温室宝箱朝镜头点积为0.9983，画面恢复棕木色受光。`academy_live/academy_covers_live.png`为真实`rail_patrol`关卡，三个训练重掩体与一个书箱实际启用新增配套，朝镜头点积为0.9936–0.9994。按现有节点目录选择含这些物件的局部遭遇，不临时添加物件。两次退出均确认Play关闭、场景未变脏、窗口偏好恢复。编译完成无错误；当前Console真实计数0错误，历史捕获缓冲仍含旧错误，未清空掩盖。

新增两项的10组离屏材质响应对照通过。四份数值贴图manifest执行Sprite入库检查仍因`hd2d_material_data_32`未注册而失败，输出空对象不是PASS；数值图保持QA_PENDING。HD2D审批验证同样未通过：完整场景密度、配置、正常入口/运动、性能和人工审美证据未补齐。本轮截图为1888×768战场内部RenderTexture，不冒充1920×1080完整游戏画面或性能验收。
