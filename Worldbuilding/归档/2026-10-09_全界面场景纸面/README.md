# 战斗外内容界面实装

用户授权：在已认可的纸黄色、简洁纸边和摄像机平行样板上缩小5%，全面实装内容页面，尽量保留原布局。

## 实现范围

- 整备样板整体缩小5%；角色档案、存档、学院介绍、教程、行程、百科、地图、节点预览、事件、工坊、医务室、商店、奖励与结算接入共用场景纸面。
- 共用后端在入场动画结束后一次放置真实世界空间 Canvas，纸面和按钮以受光面片呈现，文字保留清晰布局。九宫格纸边复用同一41×41原生图，适配不同矩形。
- 保留原控制器、回调和主要布局；悬浮提示仍使用原高层级窗口。设置保持系统界面，系统确认窗保留输入阻挡并使用纸面外观。
- 修复旧背景拦截鼠标、入场动画覆盖新锚点、世界空间地图拖动坐标、奖励输入优先级、纸面遮挡兄弟文字、网格面片重叠，以及滚动文字/受光面片裁切不一致。
- 页面隐藏前恢复布局；释放临时网格、材质和世界画布。静态几何缓存，裁切仅在视口/矩阵/图像变化时重建，中性补光不启用实时阴影。没有据此宣称帧率提升；未做独立 Player 性能基准。

## 验证

- 正常鼠标入口：开始游戏→书本打开→角色档案→返回主界面通过。没有确认创建新玩家档案。
- 装备悬浮提示、拖入背包、术式悬浮提示与选择、档案打开、返回地图，以及灯光拖动/保存/关闭/跨页保持九项检查通过。偏好在验证后恢复。
- 地图原生滚轮缩放、拖动、背包打开和返回地图通过。
- 百科原生滚轮与文字/面片裁切通过；前后截图已检查。
- 奖励封套打开、选择术式奖励、商店购买及金币扣除通过。
- 页面截图使用正式运行时代码与隔离验收状态。它们证明对应页面及操作，不代替完整新一轮通关验收。商店、工坊、医务室、事件的服务页与节点预览分别留图；战胜/失败结算亦分别留图。
- 资产稳定GUID、原生贴图、Point、Clamp、无压缩/无Mip、完整矩形、4px边框及 Resources 加载复核通过；正式资产合同报告为 PASS。
- 最后修改仅修复 Editor 停止 Play 时的临时对象释放；重新编译完成，商店页面进入/停止 Play 后 Console 无错误，隔离验收没有报告玩家存档改变。已恢复干净的 CombatTestArena Edit 模式及原 runInBackground=false。
