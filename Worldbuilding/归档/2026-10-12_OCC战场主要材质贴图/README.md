# 战斗主要材质配套图实装

本轮新增15套配套数据图（30张32×32 PNG），与上一套庭院石B合计覆盖庭院石、道路石、遗址石、泥土各A–D，共16张既有地表底色。底色未替换；地图配置、单位、交互和玩法未改变。

运行时 `Hd2DBattlefieldMaterialMaps` 以底色资源对象精确匹配，不按名称片段、颜色或亮度推断材质。普通/雨天地面、外围铺地、建筑石材、花圃泥土、既有石材屋面、地台及立体墙接入对应配套图。建筑重复采样使用原底色标识绑定。法线强度：庭院0.35、道路0.30、遗址0.32、泥土0.22；既有雨湿涂层继续叠加在独立粗糙度之上。

## 贴图来源与注册

每张底色变体各用独立内置生图原料制作配套数据。原料为四象限：左上法线、右上粗糙度，下方为重复板；仅精确裁切上方象限，不插值。道路/遗址/泥土B初版粗糙度包含过低数据，未交付该通道，各用独立第二版粗糙度原料修正。法线不是从底色亮度计算，粗糙度不是底色灰阶。

已知32×32 UV画布的数值场注册逐单元取原料实际RGB代表值，保留完整不透明背景和数值色彩，不新增颜色或减色。新地图声明OpenGL法线方向，Importer不翻绿；上一套庭院B按已测方向保留翻绿。全部线性、Point、Repeat、无Mip、无压缩，同底色UV，1原生像素=1/32米。原料、象限裁切、注册报告、交付指纹见 `material_inventory.json` 和各变体目录。

这是已知画布注册的数值贴图候选，不宣称普通Sprite自动网格门槛通过。源与凹凸/粗糙区域的准确匹配、完整场景像素密度和人工审美仍待复核。数值贴图专用角色尚未登记进正式Sprite入库合同，各manifest保留QA_PENDING，不冒充FORMAL。

## 验证范围

本轮只使用独立预览场景内的实际URP离屏渲染，调用真实运行时绑定器。每张地表材质提供960×540关图/开图对照；四组B代表提供1920×1080关图、仅法线、仅粗糙度、全部开启、旋转主光、中性光对照；另检验庭院B雨湿Shader。有效结果以 `probe/batch_state.json`、各目录 `result.json`、`render_metrics.json` 为准。

`four_materials_before_after.png` 按庭院、道路、遗址、泥土从上到下排列，左关图、右开图，直接拼接原始捕获。本轮没有进入Play Mode、打开/聚焦窗口、保存主场景、运行游戏全旅程或做性能基准。局部渲染不能替代游戏镜头品质批准。

生成期间CLI发现曾短暂失败，读取正确主工程实例描述后使用有效认证连接检查，再恢复CLI。没有修改另一工程或更换端口。一次动态eval超时；本次验证采用编译后的菜单方法。离屏工具编译过程中的MenuItem位置错误已修正，最终编译结果和Console增量分别留证；历史错误不清除、不伪称全程无错误。

本轮没有给人物、植物、玻璃、金属或木质纸板道具制作配套图；上述物件需要按各自透明剪影和材质区域继续独立生产，不能套用地表数据。
