# 首战入口错误提示修复

日期：2026-09-06。类别：肉鸽模式首次体验入口修复。

目标：解决用户从首次地图进入第一关时被“这里离得太远，请先走到相邻地点”阻挡的问题。

现场读回：Unity 位于主工程，用户已在 Play Mode；地图 CurrentNodeId=O、Origin.Acknowledged=False、B1=Locked，页面是雨后灯庭出发准备。距离不是阻挡原因，固定出身未确认才是原因；原界面将该前置条件误归入距离提示，且首战页没有确认入口。

涉及文件：UiPresentationModels.cs、FormalRogueliteUi.cs、FirstRunExperienceTests.cs。修改前副本见 before/，验证前玩家地图存档见 原存档.txt。

修复：首战未确认出身时显示正确原因；首战出发页显示“护障检修户 · 就地接线 · 借障导流”及可点击的“确认出身并出发”。用户点击后调用既有出身确认与战斗启动流程。已确认存档保留原“出发”操作；没有取消确认规则、绕过其他节点条件或变更战斗玩法。

验收标准：原始未确认出身存档可通过页面按钮直接确认并进入 B1；不再提示距离问题；B2 仍受既有条件约束；编译和相关测试通过；实际点击进入 Active 战斗。

验证结果：FirstRunExperienceTests、RainLanternCourtTests、RogueliteMapInteractionServiceTests 合计 21/21 通过，0.48 秒，job=af8a5f44-a0c1-43e8-b39f-2394a31ea324。编译 0 错误、0 警告，Console 无 error。新增回归覆盖未确认时原因、确认后可进入、进入 B1 后 B2 仍不可达。

实机：继续用户原存档 → 点击 B1 → 点击节点详情 → 页面确认按钮可用 → EventSystem 点击“确认出身并出发” → CurrentNodeId=B1、Origin.Acknowledged=True、CombatFlowPhase=Active、生命 18。没有新建测试存档、替换装备或直接改写解锁字段，存档通过正常流程保存。runtime/confirm.png 和 runtime/entered.png 为实际截图。

交付状态：按用户正在操作的场景，保留 Play Mode 并停在首战开场，未执行任何战斗行动。临时后台运行设置已恢复 false；主场景 dirty=False、compiling=False，未保存场景、未替换资产、未提交 Git。

完成后解锁下一步：用户可正常开始第一战；此前三条路线完整通关、动态美术与密集反馈验收仍是独立未完成项，本次入口修复不代表它们已通过。
