# 飞书同步说明

## 目标

把本地 `OC世界观` 的汇编稿同步到飞书 Wiki 页面。

当前默认同步源文件：

- `E:\数据库\OC世界观\00_项目总览\飞书同步源.md`

目标 Wiki：

- `https://jcnlgassfnsm.feishu.cn/wiki/Dqq0w6LgEiHNDykBpD9cLL4Fnmf`

## 前置条件

脚本会优先尝试从当前工作目录自动读取以下配置文件中的飞书配置：

- `opencode-lark.jsonc`
- `opencode-lark.json`
- `opencode-im-bridge.jsonc`
- `opencode-im-bridge.json`
- `opencode-feishu.jsonc`
- `opencode-feishu.json`

如果这些文件里存在：

- `feishu.appId`
- `feishu.appSecret`

则无需额外手动 export 环境变量。

如果本地没有这些配置文件，则需要在运行终端中提供以下环境变量中的一组：

- `FEISHU_APP_ID` + `FEISHU_APP_SECRET`
- 或 `LARK_APP_ID` + `LARK_APP_SECRET`

并确保该飞书应用已被加入目标知识库/页面，且拥有：

- 文档读取权限
- 文档编辑权限
- 文档 block convert 权限
- wiki 读取权限

## 同步脚本

脚本位置：

- `E:\数据库\OC世界观\15_创作辅助\feishu_wiki_sync.js`

## 使用方式

在 PowerShell 中执行：

```powershell
$env:FEISHU_APP_ID="你的_app_id"
$env:FEISHU_APP_SECRET="你的_app_secret"

node "E:\数据库\OC世界观\15_创作辅助\feishu_wiki_sync.js" `
  --wiki "https://jcnlgassfnsm.feishu.cn/wiki/Dqq0w6LgEiHNDykBpD9cLL4Fnmf" `
  --source "E:\数据库\OC世界观\00_项目总览\飞书同步源.md"
```

## 当前策略

当前脚本采用“整页替换同步”策略：

1. 解析 wiki 链接，拿到 docx 对象
2. 列出当前文档 blocks
3. 删除根节点下原有内容
4. 将 Markdown 分块转换为飞书 blocks
5. 逐块插入，重建整页内容

## 注意事项

1. 该脚本是为当前世界观汇编稿设计的，适合标题、段落、列表这类结构化文本。
2. 如果后续文档里加入大量表格或复杂图片，建议再补一版图片上传/表格增强逻辑。
3. 如果接口返回权限错误，优先检查应用是否被加入知识库成员且拥有可编辑权限。
