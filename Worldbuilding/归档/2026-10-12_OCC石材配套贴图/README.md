# 石板配套法线与粗糙度：局部实装

已为 `academy_block_court_b.png` 制作独立法线和粗糙度数据图，交付32×32。`Hd2DCourtyardStoneMaps.Apply` 已接入战场地面和学院建筑对应石板材质的正常构建路径，只绑定这一张底色，不套用到其他石材、木材或屋顶。

法线控制浅凹凸与破损边缘，强度0.35。原料绿通道方向实际为图像向下，Unity NormalMap Importer启用 flipGreenChannel 修正方向。粗糙度读取线性R通道，范围约0.522–0.859；Shader转为 smoothness=1-R，湿地继续叠加既有湿润响应。两图Point、Repeat、无Mip、无压缩，沿用底色UV与32 PPU。

## 来源与处理

两张1254×1254原料来自独立内置生图，保留在本目录；没有从底色亮度计算高度或粗糙度。完整来源与文件指纹见 `material_brief.json`、`normal_manifest.json`、`roughness_manifest.json`。

普通Sprite解码对法线得到1.1561置信度，低于1.2，结果保留为失败。随后使用已知32×32画布的数值场注册工具，逐单元选取实际观察到的代表像素，保留RGB，不插值、补色、调色板压缩或删除中性背景。该结果是另行登记的数值贴图候选，不是普通Sprite网格门槛通过；注册与美术仍待人工复核。现有Sprite入库合同尚未登记专用数值贴图角色，两份manifest明确保持QA_PENDING，不能晋升FORMAL。

## 本次有效证据

`probe_v4` 是实际URP离屏渲染，拥有独立预览场景、相机、光源和网格，直接使用运行时绑定代码。提供关图、仅法线、仅粗糙度、全部开启、旋转主光、中性光和960×540捕获。`before_after_1080.png` 左侧关图，右侧全部开启，直接拼接原始捕获。`probe_metrics.json` 记录非零像素差异。

前三轮probe输出空背景，属于失败证据，不参与本次通过判断。原因是URP Preview相机选择默认2D Renderer；有效版本只将离屏相机类型设为Game并显式选择工程3D Renderer，没有进入Play Mode、打开Game窗口或获取焦点。

本轮导入编译完成，新增Console错误为0，Shader消息为空；未清除或宣称历史Console警告消失。主场景路径保持、未变脏，未保存场景、未执行全流程测试。此证据只能证明局部材质真实响应，不能证明完整游戏镜头、运动、性能或八方旅人等效品质。品质报告保持QA_PENDING。
