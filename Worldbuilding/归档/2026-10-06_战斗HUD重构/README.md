## 原稿与差异

`before/` 保存本轮修改前的工作树文件及 Git 状态，包含用户已有未提交修改。`implementation.patch` 只比较本次起点与交付结果，不能用整仓库 Git diff 代替。`changed-files.json` 记录本轮文件与 SHA-256。新增脚本与对应 Unity 自动生成 meta 一并保留在工程中。两个稳定骨架 Prefab 通过 Editor API 修改，未手改 YAML；GUID 保持原值。

`approved-layout-concept.png` 为确认方向；`feishu-before.json`、各 XML 补丁与结果、`feishu-after.json` 为母版变更证据。辅助 Python 脚本用于留档，不是新的活动产品规范。
