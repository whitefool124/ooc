# 八方研究反哺 OCC：本轮交付

当前可体验：正常游戏入口 → 地图 → 背包整备 → 术式编组 → 返回地图。书桌局部环境漫反射与远景景深已接入现有运行时页面；不是完整材质升级完成或品质基线批准。

## 已落地

| 方向 | OCC 实施 | 实际边界 |
|---|---|---|
| 资产生成 | 独立中性木纹生图、原料/提示词/无损解码/诊断视图保留；新材质简报模板 | 木纹仅 QA_PENDING，未导入或替换正式桌面 |
| 材质结构 | 总案规定底色、法线、表面通道、金属及自发光分别记录，配套图注册同一 UV/颗粒 | 本轮未生成配套 normal/surface；禁止拿底色明暗冒充粗糙度 |
| 环境照明 | 现有 HDR 反射探针低阶 SH 投影，异步读取低分辨率 mip，局部表面自定义环境光 | 单点环境捕获，0.35 增益，非精确间接光；无空间遮挡或多点 GI |
| 反射与泛光 | 保留局部 HDR 反射与现有 Bloom；与漫反射通路分离 | 未宣称解决全部高光或材质质感 |
| 景深/阅读 | 等待几何创建后测量全部阅读承载内容，远景 Gaussian 模式 | 不照搬原研究镜头参数，不模糊文字与桌面阅读区 |
| 接触阴影 | 规范区分 AO、方向接触阴影与材质 AO，要求独立对照 | 本轮未加入新的接触阴影实现 |
| 云影 | 规范限定室外日光场景，并记录尺度、速度、相位和衰减 | 室内书桌没有添加云影 |
| 持续品质 | 母版/本地镜像/规格表/机器合同/技能引用同步；样板仍 QA_PENDING | 人工审美、完整性能及密度验收尚未通过 |
