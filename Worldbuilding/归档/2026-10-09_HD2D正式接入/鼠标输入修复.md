# Editor 鼠标输入残留修复

2026-10-09 用户报告镜头、双击行动、法术切换均无法使用鼠标。

直接证据：主工程 Assets/Scenes/CombatTestArena.unity，Play 时 EventSystem 与 InputSystemUIInputModule 正常启用，UI actions 启用，但设备列表为 Mouse enabled=False，OCCDetailsVerificationMouse enabled=True。前一轮 AcademyJourneyAudit 调用 DetailsInputFixture 后遇到域重载，Unity 输入设备存活而静态 native/simulated 引用丢失，退出恢复未生效。

已恢复真实 Mouse，并移除残留的验证鼠标。DetailsInputFixture 增加 beforeAssemblyReload、quitting、ExitingPlayMode/EnteredEditMode 清理，以 SessionState 保存设备 id、原启用状态与 runInBackground；End 支持静态引用丢失恢复和重复调用。AcademyJourneyAudit 仅分派 UI 事件，不需要隔离设备，取消其 Begin/End 调用。

验证：实际模拟静态引用丢失，End 恢复原鼠标、移除虚拟鼠标、恢复原后台运行设置；重复 End 保持有效。再次 Begin 后实际退出 Play，读回 current=Mouse:/Mouse、Mouse enabled=True、无验证鼠标。编译与新增回归检查的结果见下方补充。
