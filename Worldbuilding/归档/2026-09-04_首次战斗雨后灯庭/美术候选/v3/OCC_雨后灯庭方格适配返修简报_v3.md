# OCC 雨后灯庭方格适配返修简报 v3

日期：2026-09-04

## 任务合同

- 目标：重新设计水面与灯藤，使其适配 32×32 正交方形战场格，并准确表达各自玩法特性。
- 范围：两份独立内置生图原料；规范化为 `floor_tile_32` 与 `single_cell_prop_32`；不导入 Unity，不改变玩法规则。
- 验收：水面读成可进入、减速、灭火的浅水覆石；灯藤读成单位可站入中心的方格中空树篱；完成 1×、4×、灰阶、棋盘格与实际单位接触图。
- 解锁：机器门禁通过并经用户审美批准后，才补稳定 GUID、Importer、运行时接触与 Unity 场景复核。

## 水面 v3

- 单格是一整块学院石板，不拆成小铺石，也没有金属边框。
- 浅水以不规则薄水膜覆盖约七成格面，保留两角干石；石材从水下可见。
- 两段断裂反光和一处低对比涟漪只负责说明液体，不形成居中的图标。
- 最多 6 色、严格俯视、完整方格、不抢单位与战术覆盖层。

## 灯藤 v3

- 外轮廓顺应方格：北侧高藤冠、左右错落侧臂、南侧极低前缘。
- 中央是真实透明的方形站位空腔，不是暗色圆斑；单位脚底置于空腔时四周仍有藤叶。
- 叶团比枝干更显著；两枚暖黄维护灯荚是受控身份点，不形成光晕。
- 禁止圆环、藤屏、门架、花盆、相框和等高四边墙。

## 目标尺寸审查

- 水面 1×：仍能看见石板与薄水膜差异；五格相邻时形成水沟但不依赖跨格纹理。
- 灯藤 1×：先读方格内中空植物围合，再读灯荚；不得读成平面徽章或不可进入墙体。
- 单位接触：正式 64px 主角脚底位于空腔，低前缘不遮脚，后藤冠与侧臂仍可见。
- 重复接触：E1–F5 每格保持独立站位与独立销毁边界。
