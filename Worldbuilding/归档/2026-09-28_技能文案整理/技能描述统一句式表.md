# OCC 技能描述统一句式表

本表列出全部101条非空卡面描述。显示字段采用统一句式：目标／路径 → 直接效果 → 必要的构筑条件。行动点、魔力、冷却和次数在卡面固定字段显示，不重复写进描述。

本轮同步调整了部分效果与消耗：移除一般术式的行动条延后、生命／护盾额外支付，删减若干等待触发；保留构筑读取、反击和陷阱所需的条件。游戏实现留待技能表定稿后同步。

| 效果类型 | 统一句式 |
|---|---|
| 伤害 | 对【目标】造成【数值】点【类型】伤害。 |
| 状态／护盾 | 使【目标】获得【状态】；或使【目标】获得【数值】点护盾。 |
| 位移 | 沿【路径】突进最多【距离】格；或将【目标】推开【距离】格。 |
| 场地 | 在【位置】生成持续【回合数】回合的【场地】。 |
| 必要联动 | 若【已有战场结果】，再结算【追加效果】。 |
