## 怎么铺

1. 每格先铺对应材质的地面格；变体按 `variant = (gx + 2*gy + hash(gx//2, gy//2)) % 4` 选取（2×2 区块内不重复）。
   石砖同理用 2 变体。不作镜像/旋转——地面格带方向性受光，翻转会破坏固定左上光源。
2. 检查四邻材质，与本格不同的方向决定过渡格：单向用直边格，相邻两向用角格。
   过渡内容全部落在本格像素内，因此两张过渡格相邻放置即自然咬合。
3. 战场最南一排换成 `*_outer_s_32x40.png`，多出的 8px 是不参与交互的外立面。

## 画法

- **泥土**：周期值噪声（每变体不同周期）＋ 秩映射 5 阶色带（7% / 36% / 35% / 16% / 6%）＋ 孤立像素清理；
  每变体再点 1–2 处低对比土脊和 1 处石子。刻意收掉了高亮点细节：那类"每格一个亮斑"会在整片
  场地里形成 32px 节奏，暴露格子。
- **石砖**：16 宽 × 8 高错缝砖（15 砖体 + 1 灰缝，隔行错 8），砖体上沿受光、下沿与右侧压暗，
  灰缝为独立最暗色；变体 b 增加缺口比例、浅坑与两道裂纹。砖块身份按跨格物理砖计算，平铺不错色。
- **过渡**：按另一材质所在方向，在本格贴边像素落笔——泥土侧是接触暗线 + 不规则投影 + 外露石屑
  （带自身投影）+ 砾石；石砖侧是断续砖唇（迎光）或压暗（背光），再咬进几簇泥土碎屑。
  以 2px 为一簇落笔，避免孤立单像素，也避免读成"一刀切"。
- **外沿立面**：明确的背光面（主体用最暗两档砖/土色 + 地表前缘 1px 受光），与地面格拉开，
  不会读成"砖继续往下"。
