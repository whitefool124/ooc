# 服务页面独立2D物件审阅版

范围：工坊、医务室、市集与节点事件。参考已批准的整备／术式桌面，保留服务内容、回调和主要阅读顺序；用固定场景坐标组织独立承载层，移除整页旧底板及重复细边框。正文与控件平行于相机，桌面物件使用自己的承载角度。没有新增盒体模型；既有桌面和房间继续复用。

本轮新原料均由 Codex 内置生图独立生成。工作托盘第三轮通过主体网格检查，置信度1.2326，完整主体加安全边86×24；记录夹第二轮通过，置信度1.569，交付24×38。两项为硬Alpha、16色，原生解码后只裁剪安全边，没有几何缩放或新增颜色。每项保留独立来源、哈希、提示词、失败记录、1×／4×／6×／灰阶／棋盘格与manifest。托盘以完整剪影承载工坊物件和商品；记录夹以自然尺度放置，正文继续使用已批准的自适应纸页。记录夹第三轮网格失败且含不合格光线，未使用。

两项manifest机器验证PASS，状态仍为QA_PENDING。编辑器从归档加载审阅图；正式构建保留已批准资源的回退。没有复制用户对旧纸边的认可，也没有将新原料写入正式Resources目录。审美认可后可进行稳定GUID与正式导入。

技术验证：最终源码导入编译完成，Console无错误。隔离内存存档中通过真实InputSystem鼠标事件验证工坊专精／锻造切换、装备悬停与选中、返回地图；市集购买真实扣费；医务室餐食选择、限次状态与3金币扣费；EV1事件选择完成节点。市集隐藏再打开恢复3个购买按钮，恢复后再次购买成功，未累积陈列组或破坏点击。验证脚本见本目录。该证据属于服务页局部验证，不代表从新开局到结算的完整旅程验收。

性能处理：只在页面构建时复制承载面网格，按钮／数据变更复用已有层；颜色不变时不重复写材质；隐藏、重建和退出释放临时网格、材质、Sprite、Texture与生成的陈列组。市集审阅层实测52个Renderer、42个不同Mesh、52个材质实例；托盘读回86×24、Point、mipmapCount=1。没有测量目标设备FPS，不以这些计数宣称已完成全局性能优化。
