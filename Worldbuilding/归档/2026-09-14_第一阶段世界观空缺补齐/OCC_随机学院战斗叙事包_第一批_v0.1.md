# OCC 随机学院战斗叙事包｜第一批 v0.1

> 覆盖：现有节点表 N01–N18、E01–E06。
>
> 边界：只补任务原因、人员身份、权限和战后处理。敌群、底图、强度、奖励、目标与行动规则仍以正式数据表为准。

## 1. 普通战斗

| 节点 | 为什么发生 | 人员与风险边界 | 战后应留下什么 |
|---|---|---|---|
| N01 中庭侧锋对练 | 中庭集合后的短时对练，检查学生能否在公共空间读懂前方防守与侧面接近。 | 盾术、侧锋均为高年级陪练生；场地由助教临时划出，旁观学生与通勤路线不进入训练线。 | 认输记录、护具检查和下一次对练的建议。 |
| N02 宿舍外寻迹测试 | 宿舍外围需复核寻迹兽缚环在公共活动边界附近的响应。 | 寻迹兽由管理舍带领；盾术陪练生只测试学生的撤离与保护判断，不得进入宿舍私人区。 | 缚环读数、路线复核和生物回收记录。 |
| N03 护障课程示范 | 护障助教展示维持／拆解的公开流程，避免学生把“有护盾”误读为绝对安全。 | 盾术陪练生承担承压对象；演示有停工信号，护障只在练习许可内运行。 | 护障读数、器材状态和课堂复盘。 |
| N04 讲坛重弩校准 | 教学区的绞盘重弩需要在封闭回廊确认瞄准、回收和攻击线提示。 | 重弩陪练生用训练件施压，侧锋陪练生检验学生是否能在远程线与接近路线之间取舍。 | 弩机校准结论、箭矢回收和练习场开放状态。 |
| N05 档案庭火矢演练 | 档案庭的耐热护幕和资料转运路线需要复核火系远程压力下的撤离方案。 | 火矢、侧锋均按公开对练协议行动；真实档案留在防护柜，不作为可损坏的课程筹码。 | 护幕记录、运送箱检查和陪练认输回执。 |
| N06 校准台约束考核 | 工坊以受控约束线检查学生能否在被限制移动时仍保护器材与同伴。 | 约束助教持有停止权限；侧锋陪练生承担路线压力，校准台不允许学生擅改。 | 约束参数、台位状态和补修建议。 |
| N07 材料库承压事故 | 材料库的搬运支架出现压力分布异常，需要在封段条件下完成回收与人员安全确认。 | 检验偶承担重复负荷，约束来源用于模拟通道受限；不是材料失窃或学生惩罚。 | 材料序列、支架失效分析、封段解除或延长决定。 |
| N08 实训场综合对抗 | 完成基础模块的学生参与小队协作实训，验证近远压力下的沟通与撤离。 | 三名陪练生代表不同公开职责；教官可随时中止，不将课程结果等同于人身伤害。 | 小队记录、个人安全说明与可继续训练的项目。 |
| N09 市集护送演练 | 市集在人员密集时演练如何让补给与普通居民安全离开狭窄门厅。 | 盾线和重弩线均为学院训练配置；护送对象和商户均知情，不把真实顾客当演习耗材。 | 护送路线、商户意见、器材与场地交接。 |
| N10 药材铺权限误判 | 一批药材被错误标成受限物，市集巡查与护障助教需在不扩大恐慌的条件下复核。 | 现场先隔离再辨认；对抗压力来自维护链演练，不把店主或买药学生当嫌疑人。 | 来源更正、库存复位和公开的风险说明。 |
| N11 校门登记争执 | 校门登记台的通行记录与临时器材单不一致，需要在不阻断普通通行的情况下查清。 | 侧锋与重弩压力模拟拥堵时的安全风险；实际争议交给登记与申诉流程，战斗不裁定谁有理。 | 证件核验、器材交接、可申诉的书面说明。 |
| N12 旧道综合巡查 | 外环旧道雨后重开前，巡查组测试视线、遮蔽、撤离和通报是否仍可靠。 | 陪练生按巡查演练协议施压；公共通勤线已绕开，学生不承担无许可的野外风险。 | 道路开放等级、护障读数和下一次维护工单。 |
| N13 郊外导能柱回收 | 一根退役导能柱需拆回工坊，防止其在雨后继续提供错误读数。 | 束缚、燃烧与显影压力用于模拟回收时的多源干扰；破坏目标是待回收部件，不是随意毁坏公共设施。 | 部件序列、残留读数、回收运输与地基修补单。 |
| N14 失踪测绘队搜寻 | 测绘队失联于批准路线外缘，最后信号显示他们可能因地形与器材问题停在原地。 | 救援优先确认人员位置与撤离，不把“失踪”预设为死亡或敌袭；检验偶用于开辟受控通道。 | 人员状态、路线偏差原因、设备回收和医疗转介。 |
| N15 旧校舍封门检查 | 一扇旧校舍封门的隔离读数不稳定，需确认其仍能区分教学空间与受限储物间。 | 检验偶、盾线和重弩压力都在批准检查内；学生只能处理门厅接口，不能进入未授权库房。 | 封门状态、钥匙／封签记录与后续维修权限。 |
| N16 观测塔显影误报 | 观测塔把一组维护反光误读为高风险显影，需要先找出破势来源再恢复护障。 | 档案巡查员与护障助教是现场责任人员；误报不等于谁犯错，先确认读数再追究原因。 | 误报成因、护障复位与匿名险情摘要。 |
| N17 图书室导能演算 | 图书室的导能演算室复核一套可公开教学模型，防止学生只依公式忽略真实对象位置。 | 偏心目标与接近压力是演算场的实体化测试；原始受限资料不进入课堂。 | 模型误差、器材状态和引用版本更正。 |
| N18 试制器具回收 | 一件试制器具在测试结束后需要从指定区域安全回收，避免遗留在学生通行线附近。 | 三种远程压力模拟读数与视线受扰，测试重点是先处理来源而非抢器材。 | 器具封存／返工决定、测试日志和场地复开条件。 |

## 2. 精英战斗

| 节点 | 真实任务 | 权限与战后交接 |
|---|---|---|
| E01 刻阵工坊高阶考核 | 在高负荷刻阵台前验证学生能否识别重击窗口、护障维护与材料风险的先后关系。 | 刻阵教官主持，工坊安全员可停机；结果进入能力档案与器材维护台账。 |
| E02 失控校准室封锁 | 一间校准室因参数漂移触发自动隔离，需在不直接拆改核心台位的前提下恢复安全访问。 | 约束助教和重弩训练配置守住公开边界；处置后由工坊复测并决定是否继续封停。 |
| E03 断崖导能柱考察 | 外环断崖的一组导能柱受风雨侵蚀，需要检验学生能否先稳住人员与路线，再处理承压设备。 | 教官、检验偶和巡查员分担责任；若环境读数超限，撤离优先于完成考察。 |
| E04 封存器材护送 | 一件已登记、低风险但需持续监督的封存器材要从外围转移至校准点。 | 护送路线、接触动作和交接人均写入许可；学生不可擅自开启容器或更改目的地。 |
| E05 封存库权限核验 | 封存库在变更访问名单前进行一次压力核验，确认权限、护障与人员记录不会相互矛盾。 | 教官与护障助教负责硬性边界；战后得到的是核验结论与访问记录，不是自由通行权。 |
| E06 高塔外环清障 | 封存塔外环需要清除影响维护读数的障碍，作为后续真实异常处置前的环境准备。 | 约束、重弩与教官构成最终门槛；完成后只证明外围条件合格，不提前解决塔内异常或替代双签。 |

## 3. 共用验收

1. 每场战斗都有课程、维护、救援、护送或核验的明确目标，不出现无来源的怪物战。
2. 陪练生、助教、巡查员、检验偶与教官均保留既有身份、权限和非致命／停工边界。
3. 战后先处理人员、器材、场地和记录，再按正式玩法结算奖励；叙事不新增资源或改变节点结果。
