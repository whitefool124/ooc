## 3. B01 学院封存塔核心

### 3.1 任务公开目标

B01 是对封存塔“回波串扰”真实异常的一次批准处置。旧型储能调谐片使核心守卫、外围护障维护与显影巡查的状态读数互相误读，核心守卫因此执行硬性阻断。公开目标不是夺取塔心或消灭某个怪物，而是恢复一条可核验、不会继续放大风险的维护状态。

### 3.2 进入者与责任链

| 位置 | 世界内职责 |
|---|---|
| 封存记录员维尔 | 确认对象、区域、入离区记录与信息边界；不能单独取代导师或安全授权。 |
| 任务导师／安全负责人 | 确认学生的协作位、撤离预案、可执行动作与停工条件。 |
| 工坊与医务响应 | 核对器材读数、准备隔离与人员检查，不指挥封存对象。 |
| 核心守卫与外围维护链 | 仍在按既有隔离职责运行；因串扰互相放大，而非突然产生恶意或失去全部规则。 |
| 学生协作位 | 在已列明的维护接口、路线与保护任务内行动；不可私拆、改写核心指令或突破授权区。 |

### 3.3 战后与未完成处置

- 处置成功：核心进入停机／复核，外围维护链回到单一记录口径；学院发布删去敏感细节的事故说明，并安排器材与人员复查。
- 中止或失败：先撤离、隔离并保留异常读数；任务记录写明未完成处置与需要的后续响应，不能以沉默把异常变成“从未发生”。
- 两种结果都不等于学生单人承担事故责任；是否存在维护失职、参数错误或管理问题另走独立复核。

## 4. 共用验收

1. 所有服务、商店和特殊物件都有来源、责任人和去向，未出现免费无来源物品。
2. T02 承认冒险封签的黑市历史，但不让当前学院流程为黑市背书。
3. B01 保持真实工程异常、授权处置与多人责任链，不改写正式首领玩法或数值。
