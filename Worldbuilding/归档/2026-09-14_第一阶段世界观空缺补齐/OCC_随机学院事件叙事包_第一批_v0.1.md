# OCC 随机学院事件叙事包｜第一批 v0.1

> 覆盖：现有节点表 EV01–EV16。
>
> 规则：每则只补事件起因、人物处境与青春喜剧的观察角度；选项成本、奖励、战斗入口和结算完全沿用正式数据表。幽默来自学生与制度的摩擦，不嘲笑伤病、贫困、险情或受限器物。

| ID／地点 | 事件小故事 | 设定锚点与幽默边界 |
|---|---|---|
| **EV01／中庭：新生实战委托** | 中庭公告栏上贴着一张字迹端正的追加演练通知，旁边却被新生们贴满“请勿把盾牌当雨伞”的补充便条。原来上一批学生把折盾匣借去挡雨，发现它确实能挡雨，但校准后需要多写两页用途说明。值班助教决定把这件事变成公开委托：要么用贡献登记一只已经验收的折盾匣，要么参加预览过的追加演练，帮新生证明“护盾不是伞，至少不是好伞”。 | 折盾匣来自登记护具工坊；中庭是公告与临时交接区。笑点不改变其护盾用途，也不把新生写成无知笑料。 |
| **EV02／教学：档案室异常索引** | 档案室的索引镜把三份“导流夹复核”归进了“导流夹克复核”。学生馆员花了一整个午后向镜子解释衣物不需要验算以太阻抗。真正的异常是旧纸本的分类符号被潮气磨平，导致几份可公开的维护回执找不到原位。维克多可用贡献取得优先调阅，或留下来协助重新登记；后者得到的不是神秘知识，而是一枚认真得近乎固执的责任记录。 | 教学区图书馆可服务封存资料调阅，但不变成封存区。笑点来自档案技术与人类命名。 |
| **EV03／教学：被封存的观察记录** | 一份获准查阅的观察记录记载某件受限器物如何对“第三次铃声”产生反应。麻烦是学院换过钟楼齿轮后，第三次铃声比旧记录晚了七息，两个研究小组为此各自带着秒表和极差的耐心赶来。维克多可以放弃进入档案库，只提交协助回执；若接受预览战斗，则是在记录员监督下帮助核对观察条件，而非拆开任何封存物。 | 封存访问仍受双签与现场监督。笑点在学术较真，不把受限器物降格为玩具。 |
| **EV04／工坊：器材登记窗口** | 登记窗口前堆着三件看起来一模一样的旧护具，却各自坚称自己的序列牌从未离开过胸前。伊恩的助手发现问题不在护具，而在上周一名学生把清洁剂当成了金属光泽剂，擦亮了所有旧刻纹。维克多可用贡献拿走已复元的编架，或留下协助基础校准；后者让他恢复的不是“神秘魔力”，而是被一下午夹具、读数和反复确认磨掉的注意力。 | 工坊强调序列与校准；恢复只沿用既定效果。 |
| **EV05／市集：退货的护盾组件** | 市集的退货柜收了一只折盾组件，理由栏写着：“展开太慢，没能阻止室友把热汤洒在我的作业上。”马雷克把理由划线并改成“非器材缺陷”，又发现组件确有一枚松动的定位钉。维克多可以用金币买下修复后的合格件，也可以免费协助把退货和真正的故障分开登记，得到一笔贡献。 | 市集不售黑市货；笑点是学生把所有生活灾难都想找器材负责。 |
| **EV06／郊野：观测塔求援信号** | 观测塔的求援灯连闪三短一长，标准含义是“需要协助”，非标准含义是塔顶的测绘生把自己的午餐盒放在了信号镜旁，锡箔正好把光折成了额外一短。午餐盒不是全部问题：塔下的读数确实异常，巡查员需要人手沿许可路线核对。维克多可支付贡献换取调度调整，也可进入预览救援战，帮忙在已知风险下完成检查。 | 外环观测要先复核现场；笑点不否定真实求援。 |
| **EV07／郊野：路障与巡查告示** | 一块临时路障牌上写着“浅水沟绕行”，下面多了学生用粉笔补的“它看起来真的很浅”。巡查员没有擦掉，只在旁边添了“所以你会很有把握地踩进去”。雨后路基松软，最近的作业线需要人把一箱干燥夹送过去；维克多可承受既定的擦伤风险走短线，或绕行拿较少的报酬。 | 风险来自真实湿滑与维护工作；不把生命损失喜剧化。 |
| **EV08／封存：高塔值守记录** | 高塔值守簿的夜班页上有两种笔迹：一种工整得像刻出来，另一种急得把“封签复核”写成“封签复喝”。维尔发现后一种笔迹的学生并未饮酒，只是在连续替班后把同一个封签编号抄了两次。维克多可用贡献领取公开结算的报酬，也可加入已预览的精英变体，替值守组核对真正的维护压力。 | 封存区的喜剧是文书疲劳，不弱化替班与高风险许可。 |
| **EV09／中庭：医务室临时征集** | 医务室的临时征集牌旁摆着两只完全相同的篮子，一只装绷带，一只装被学生误放进去的社团横幅。阿黛尔让志愿者先分拣，强调“会折布不是医疗资格”。维克多可支付金币接受既定治疗，或参与预览护送战，帮忙把真正需要的物资和人安全送到位。 | 医疗由医务人员负责；志愿协助不取代诊疗。 |
| **EV10／市集：赞助账目追索** | 一家材料铺收到三份同名学生的担保函，落款格式来自三个不同地区，连印章的红色都各不相同。店主不敢贸然扣款，怕把“家庭支持”记成“学院贡献”，也怕把一次借用记成永久债务。维克多可支付金币协助补齐公开账目，或进入预览考核战，以完成的实务记录换取额外报酬。 | 赞助必须登记、不能变成隐形控制；幽默来自跨国文书的繁琐。 |
| **EV11／郊野：猎团旧标记** | 旧猎团标记在风雨里褪成了两支相反的箭头。负责更新的学徒解释说，当年的人本意是提示“注意两边”，后来的每个人都以为那是让他选择更有英雄气概的一边。生态员把标记周边设为观察点：维克多可用贡献取得测镜，或参加预览寻迹兽演练，确认真正的活动方向。 | 猎团不是怪物猎杀许可证；寻迹兽仍是受管理生物。 |
| **EV12／教学：术式抄录争议** | 两名学生为一页火术抄录争得面红耳赤：一个坚持逗点应在导引前，另一个坚持逗点属于终止条件。导师把纸压在桌上，指出他们争的不是标点，而是谁要为一次参数漂移负责。维克多可按既定金币取得已复核的术式附页，或协助对照标准骨架，换取贡献和一份“以后请在写字前先看版本号”的共同提醒。 | 标准术式有骨架与受控参数；不把抄录争议写成凭文字施法。 |
| **EV13／工坊：护具压力复核** | 一批护具在压力架上表现得异常团结：每一件都把应当承受的部分震动传给了旁边那件。伊恩怀疑有人把训练架的四个脚垫垫成了同一高度——在不平的老地板上，这是最有效的让全体一起不稳的方法。维克多可购买已验收的折盾匣，或参加预览维护链战斗，帮助工坊找出压力从哪里被错误传递。 | 护具／维护链都按工程失效处理；笑点来自“整齐”造成的灾难。 |
| **EV14／市集：临时医护征集** | 市集临时医护点收到一车药材，标签写得很清楚，箱子摆得很不清楚：止痛草、清火草和“请勿食用的清火草样本”被放在同一张长桌上。阿黛尔派来的人要求先分拣，再决定谁需要治疗。维克多可免费协助获得贡献，也可支付贡献接受既定的生命与魔力恢复。 | 市集可协作医护供应，但不得代替医务诊疗与来源审查。 |
| **EV15／郊野：导能柱错位读数** | 导能柱显示的角度偏了半格，三个学生围着它各自提出了解释：风、地面沉降，以及“它昨晚被一只很有主见的鸟停过”。最后一种说法并不完全荒唐——鸟巢确实压住了一条辅助线，但读数还提示更深层的地基问题。维克多可用贡献取得报酬，或进入预览破坏目标战，协助把危险部件与无辜鸟巢分开处理。 | 导能柱是低压观测设施；喜剧不把生态问题当成可随意破坏的障碍。 |
| **EV16／封存：维护链替班** | 封存维护组的两名成员同时递交了合规请假：一人去补修，一人去参加自己错过的补修说明会。维尔把两张单子并排放好，沉默得让值班灯都显得更亮。低风险替班可以用贡献结算；若维克多加入预览精英战，则是补上已拆分、已授权的协作环节，而非代替任何人开启核心。 | 保留维护链替班的合法边界与精英入口；笑点是学生制度的自指困境。 |

## 使用原则

1. 每则可用于节点摘要、环境物件、事件开场或结果后的短叙事，但不自动成为固定台词。
2. 任何笑点出现后，必须保留现实的风险、签发人、检查和合法出口。
3. 不改变 `OCC_学院节点内容数据表_v1.0.csv` 中的选项、成本、奖励与战斗入口；正式同步时逐条对照写入。
