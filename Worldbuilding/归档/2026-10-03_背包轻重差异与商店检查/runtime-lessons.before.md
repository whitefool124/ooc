# 已验证的技术知识与适用范围

2026-10-02，Unity 6000.5 / URP 17.6：

- URP 离屏摄影机目标需要深度缓冲。展示场 RT 使用 Point / Clamp / 无 mipmap，在 endCameraRendering 后处理，避免读尚未绘制的源。
- 展示场的 240×180 左视口及整数缩放是研究样板；正式战斗的格尺寸、平移和裁切由 BattlefieldPresentationAdapter 与实际 Bootstrap 提供，不能硬套演示坐标。
- 项目原 URP renderScale=0.5。展示场临时克隆 Pipeline 并还原原配置；不要为了效果静默改写全项目渲染资产。
- CLI 后台运行时 runInBackground=false 会停住演示。演示可临时开启并还原；正式游戏先检查真实前台流程。不要因此修改所有游戏运行配置。
- CLI eval 在中文路径连续调用曾出现 Illegal byte sequence / QuickInstaller reflection 异常。首选已编译 Editor 菜单验证并将工具错误与游戏错误分开报告。
- 静态截图不能验证时间。像素投射、冲击和照明必须核对阶段时间；暂停后捕获 GameView，异步截图必须绑定实际模式，不能把下一模式截图标成上一模式。
- 当前战斗光效使用 UI 加法合成、六级衰减、八段时间和整数粒子格；它是局部亮度叠加，不等于表面法线照明、遮挡阴影或背景折射。这些高级能力应独立验收，不借用展示场证据声称已接入。
- 自定义 MaskableGraphic 显式要求 CanvasRenderer，测试需 ForceUpdateCanvases，不能只检查生成了组件。当前 uGUI 自定义顶点参数方案出现整片青色加法覆盖；改为每个有限播放槽持有独立材质、通过 uniform 传时间/族类/强度，已用真实命中画面复核。材质随实例销毁，不在每帧创建。不要把未经画面核验的顶点传参方案直接推广。
- 遵守 RectMask2D 和 stencil，Graphic 禁用 raycast。Shader 放 Resources 保证构建包含，不能只凭 Editor Shader.Find 成功。实战截图同时看战场和 HUD，确认光效没有跨视口遮蔽信息。

研究参考与原始验证见 `Worldbuilding/归档/2026-10-02_像素技术美术与特效研究`、`2026-10-02_非护盾特效与界面规划`；历史护盾演示已被用户否决，不能继续当作认可方向。

战斗外界面迭代（2026-10-02）：

- 资源扣除提示与服务成功特效必须在 `SaveMapRun` 成功后发布。先发资源变化、后保存，会在保存失败时播放误导反馈。
- 服务结果刷新不应再次淡入整页；使用 `Invalidate(false)` 即时显示结果，再在重建后的目标图标上播放短效果。把效果挂在即将销毁的旧按钮或旧页面上会丢失。
- 自定义路线 Graphic 的 RectTransform 必须覆盖地图画布，不能用零尺寸矩形承载分散顶点，否则 RectMask2D 的包围盒裁切会把有效路线剔除。
- 短提示的文字槽会被通用画框安全边压小，导致整行不可见；取当前字体 `MinimumTextSlotHeight` 与实际换行 `preferredHeight` 的较大值，再设置提示高度与文字槽。只检查 text 非空或 preferredHeight 不能验证文字可见，需检查实际生成顶点与渲染画面。
- 几何采用共享 uGUI 材质、整数像素位置、有限时间步，不使用逐帧材质分配、永久闪烁或全屏辉光。瞬态实例与页面共同取消，强度零不创建实例。

界面小细节第二轮（2026-10-02）：

- 鼠标悬停与键盘焦点应共享一个短反馈实例；两种输入都离开后再取消，避免鼠标移出时误清仍有效的键盘焦点。不可执行按钮不播放可执行游标。
- 选中项同时提供静态形状提示。本轮页签书签在关闭动画时保留，不把悬停、键盘焦点与真正的业务选中混为一谈，也不把选中标记当作保存成功回执。
- 普通 MonoBehaviour 在 EditMode 的 SetActive 不能替代 Play Mode 生命周期验收。初次编辑态关闭/重开测试未调用真实 OnDisable，已改为输入状态测试；实际运行时单独验证关闭再打开，旧反馈实例为零、旧焦点框关闭。不得为迎合编辑态测试给产品组件添加 ExecuteAlways。

学院日常氛围第三轮（2026-10-02）：

- 氛围细节引用当前世界观中的具体生活制度。本轮采用生活区允许的低风险照明日用术，不能从装饰推导新许可、倒计时或成熟储能工业。
- 常驻环境器物可以保留静态照明；关闭动画时停止亮度变化。局部暖光采用小范围硬边几何，亮度只有低幅度变化，不用常驻强闪烁或整页辉光。
- 页面被不透明百科遮盖时，底层主菜单仍可能 activeInHierarchy=true。环境特效额外读取真实遮盖状态并停用，正常返回后恢复同一器物；只检查父物件 active 不足以证明没有无效更新。

用户审美修正（2026-10-02）：

- 用户拒绝所有文字小细节。第三轮的校园日常便笺已否决并从主菜单移除，历史截图只用于追溯，不代表当前认可方向。后续氛围靠器物、光效、美术与非文字动作表达，不用新文案替代视觉制作；正常功能文字保留。

无文字物件与悬停提示（2026-10-02）：

- 装饰物不附加设定文案。现有正式章节夹签可以作为档案桌器物，使用原生32×32的整数2倍显示，关闭射线；不改原图，也不把复用称为新生图。
- 主界面的当前可用人生阶段仍直接显示；重复说明移至图标与相关按钮的共用提示。保留操作名称、存档状态和安全确认，不能为了少字隐藏决策信息。
- 图标只承载可推断的语义，保留必要短标签；纯图标帮助入口纳入导航链并提供可见焦点，但初始焦点仍给主操作。不是每个控件都应该变成无名图标。
- 悬浮窗需在页面重建及不透明界面遮盖时显式收起，不能只依赖 PointerExit；本轮正常进入设置时已验证旧提示关闭。只在正式输入触发时显示，不默认铺开。
- 纯氛围器物可通过 RectTransform 局部鼠标位置响应，而无需成为 raycastTarget。灯光关闭动画时保持静态，悬停也不产生光点。本轮 Input System 注入位置验证光阶3并捕获实际画面，原鼠标输入位置随后恢复；与手工鼠标验收区分记录。

夹纸小巧思样板（2026-10-02）：

- 用户指出：摆装饰、加泛光和收起说明不是其期望的小巧思。以具体因果与物件关系设计：悬停新建档案牵动上层纸，固定夹子约束纸角，移开后纸张落回。下层纸与夹子不动。先把一个瞬间做清楚，再考虑扩展；不以数量替代发现感。
- 本轮用运行时几何做动作方向样板，不冒充新生图或正式美术资产。纯几何样板的材质细节仍需后续美术审阅，不能凭输入与清理测试通过宣称用户认可。
- 截图PNG编码会降低采样频率；本轮18帧记录了动作阶段及真实时间，但不是连续60fps录屏。GIF只按实测间隔包装，首尾延长便于审阅；3倍局部裁剪仅作截图放大，不进入游戏资产。

夹纸精修实装（2026-10-02）：

- 用户明确要求精修并实装，动作原型不能代交付。纸张物件沿用既有正式 archive_memo_note 材质，通过运行时九宫UV、翻角裁剪、背面和接触阴影完成动作；没有改写原图或将程序几何冒充新生图。
- 固定区域应从实际 sprite.border、sprite.pixelsPerUnit 和 canvas.referencePixelsPerUnit 推导，不能把原型固定边界14px硬套到正式材质。OCC Canvas的参考像素比例会使同一贴图的顶部边界变大；第一次精修发生固定铜件的微小牵动，最终改为完整固定顶部九宫区域，静止/受拉截图铜件区域像素一致。边界超过目标矩形时同比收缩，避免九宫中心倒置。
- 连续截图先缓存Texture，动作捕获结束后再编码PNG，退出时释放缓存。本轮按实测时间捕获19帧，覆盖拉起、停留和归位，采样比上一轮逐帧编码更完整；仍不称为60fps录屏。
- 完成效果后验证正常点击新建到档案选择并返回，不选择、覆盖或创建用户档案。切页清除纸张与旧提示，返回与停用重开均保持平放。

主界面小物件撤回（2026-10-03，覆盖上述夹纸实装的交付判断）：

- 夹纸与小灯的实际布置被用户否决；既往技术通过不构成美术认可。按钮空白处硬贴便笺、为便笺挪动标题，以及将无桌面承载的小灯悬在UI空白处，都不能作为精修小巧思交付。本轮从正式主界面撤下两者，恢复原按钮与居中标题；历史组件只保留技术追溯，不继续挂接运行时主入口。
- 动作因果还需空间与物件用途成立。不能仅因“新建档案”名称相近，就把便笺任意接到该按钮；局部动起来不证明环境和操作关系合理。应先确认物件在实际场景有自然的承载面、尺度和用途，再设计反应；已有UI控件不得被装饰挤压或改变造型。
- 2026-10-02的夹纸入口验证直接派发按钮事件，只证明回调与清理。2026-10-03曾补真实射线与Input System按下/释放验证，证明点击通路，但没有解决布局方向被拒绝的问题。验证分开记录视觉、实际命中、业务结果与人工认可，不能互相代替。
踩水岸边样板（2026-10-03）：

- 环境接触跟随 CombatMovementPlayback 的已执行路线及显示采样；每个实际到达的路点仅发布一次，记录路点的实际到达时间。采样帧跨过多个路点时补齐已发生接触，但不能把到达时间统统改成当前帧，否则会出现迟到的大量新波。路径缺失、端点变化或取消不编造途中脚步。
- 涟漪几何位于现有水面之上、单位与战术标记之下，逐水格裁切，保留一原生像素格边。当前英雄可见足底离画布底约4原生像素，须由实机接触复核，不能从角色逻辑格中心直接画大圆。图层不占射线；合并重叠接触，以最大亮度而非相加方式显示。
- 本轮验证用既有隔离内存旅程与默认第一战，通过实际地图节点、出发按钮、鼠标走格验证，并未写玩家档案。入场演出期间命中的是“战斗入场演出”遮罩，不能把这时的点击当成走格结果；等待演出解除后实际命中格子才可验收。隔离流程验证不能称为完整玩家存档旅程验收。
- 完整背景或遮罩会在页面转换时重置叠层；验证入口先等待地图显示，再点击实际节点。动作采样先缓存截图后编码，记录帧时间；本轮20帧跨1.184秒，局部GIF为原截图裁剪，不是60fps视频。

工坊夹具样板（2026-10-03）：

- 工坊动作状态需独立于反复重建的页面物件；同一目标刷新不重置定位，真实离开才清空。已完成目标重新打开静止，不从完成状态推断一次新成功。瞬态成功仅消费已保存服务事件一次。
- 有物理承载的细节仍需核对遮挡：台身在目标图标下方，夹口在图标前方，标签与操作按钮保持自己的布局。拆分UV移动原图部件时应检查原位置的露底和重复轮廓，不用成功触发日志代替实际画面。
- `PreviewUiCaptureSaveFailure` 会显示全局重试保存界面，不适合作为仍可点击工坊确认的故障入口；该尝试失败不能登记为服务失败验证通过。内存预览、真实点击、磁盘保存和人工审美继续分开汇报。

医务室热饮与战斗外尺寸（2026-10-03）：

- 用户明确放宽战斗外展示物件的画布尺寸，以画风统一和界面尺度自然为准；主体完整解码33×33的杯碟可以使用37×37含安全边画布，不能再因不符合32×32或32倍数而拒绝。战场与功能图标合同不随之放宽。
- 餐食可供应是环境蒸汽的依据，不是治疗按钮或悬停触发。蒸汽从实际杯口出发，原图杯沿、勺柄遮挡；商品图像、标签和价格需在实际截图中逐项核对。按钮名义宽度足够，不代表左对齐标签不会被新增图像压住。
- 医务室顶部和底部都有同名“返回地图”按钮，验证须明确选择位置。装饰射线关闭还需点击商品图像自身，确认下方真实按钮接收输入。人工审美之前，只用Editor临时加载已解码素材作应用审阅，保留QA_PENDING，不将技术通过冒充正式认可。

背包提放与背景候选（2026-10-03）：

- 完整背景中的植物和投影若没有可独立控制的层，应暂缓对应动作，不能连带移动墙面、地面来伪造风。热饮样板已获用户认可，再完成稳定GUID、Importer和实际正式资源复核后入库。
- 拖放源图隐藏后，预览需保留实际物品，而非只有占格色块；图像与接触影不接收射线，失败和取消不演落格成功。页面重建会销毁原网格，真实输入验证必须重新获取当前网格坐标。
- 悬浮窗虽不拦点击，仍会遮挡拖拽物品与目标格。拖拽期间收起，正常悬停保持原有行为；不能把输入通过当成可见性通过。默认旅程背包为空，用真实装备槽卸下已有胸甲进行样板验收，不注入测试道具。
