# 越格角色输入归属

主任务 VISUAL-INTEGRATION-01；分支 codex/art-visual-iteration-20260905。本轮让角色的可见身体与实际悬停、点击对象一致，属于两模式共用表现和交互适配；玩法内容规模不变。

## 问题与改动

原角色RawImage不接收射线。生产Canvas检查中，主角实际在E3，点击其越格头部却命中E4，悬停和右键也都归到E4。修复后同一像素对应的三种操作都归到E3；透明角仍命中后面的D4地块，没有把整张64px透明画布变成按钮。见 before-raycast.json 与 after-raycast.json。

新增 CombatTextureAlphaMask（每原生像素1bit）和缓存；非可读贴图在首次绑定时通过临时RenderTexture读取Alpha，随后只保留CPU位掩码，正式Importer不变。每个不同贴图只读取一次，事件查询不触发读回，失败时记录一次警告并保留格位操作。

新增 CombatUnitPixelRaycast 射线过滤，读取当前显示矩形、UV和事件相机；透明像素穿透，实际身体像素使用既有BattlefieldCellPointer回调，并映射到所属玩法格。FormalBattlefieldView只在格子首次出现单位时建立组件，当前首战3个；透明边角、图层重叠与视口父级裁剪继续生效。没有改自动攻击、双击移动、指令合法性、占格、单位尺寸或正式原画。
