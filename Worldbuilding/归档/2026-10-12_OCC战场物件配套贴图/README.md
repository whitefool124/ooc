# 战斗木质、金属与灯罩玻璃材质实装

七项物件：档案木架完整/损坏/残骸，宝箱关闭/打开/空箱，诱导灯。新交付18张32×32数值贴图：七张法线、七张粗糙度、四张金属/玻璃区域遮罩。底色、透明剪影、32 PPU、Canvas、UV和玩法保持原状。

运行时 `Hd2DBattlefieldPropMaps` 按精确底色资源身份绑定，`BillboardLit` 接入正常对象和战利品展示。GroundedSprite保留足底深度代理；没有配套图时调用原LitPassFragment。法线强度木件0.28、灯0.20。粗糙度R转smoothness=1-R；区域遮罩R为金属，G为灯罩镜面涂层，B不使用。玻璃涂层smoothness0.94是待审候选值。档案木架没有足够依据认定金属件，故使用内置黑色中性遮罩，纸和木头保持非金属。

这里的灯罩是局部镜面涂层，没有新增透明排序、透射或折射，也没有增加自发光以掩盖材质问题。晶体、温室大型玻璃、其他木质变体及机关尚未配齐。

## 来源与处理

每项物件各自使用独立内置生图原料，四象限法线/粗糙度/区域/粗糙度重复板。初版粗糙度过度追随底色暗部，全部重做独立粗糙度原料；原图保留但不交付该通道。闭合宝箱首版法线角部混入黑色数据，独立第二版法线替换。档案木架初版红色金属角码遮罩未使用，不新增不存在的金属语义。

已知原始32×32 UV画布的数值场注册逐格选择原料实际RGB代表值，不插值、不新造颜色、不把底色亮度转成法线或粗糙度，不删中性数据背景。源、裁切、注册、交付指纹见 `material_inventory.json` 和各物件目录。所有数据图线性、Point、Clamp、无Mip、无压缩；法线声明OpenGL +Y上，Importer不翻绿。

注册不能证明原料实际区域与底色严格一致。所有地图保留QA_PENDING；普通Sprite的1.2网格门槛没有降低，也不将数值场注册冒充Sprite解码通过。生成值并未逐像素满足提示词目标范围，实际RGB范围登记于inventory，物理区域与审美须人工复核。

## 局部验证

预览场景中的真实URP离屏相机，调用真实绑定代码，保留原始Albedo裁切。七项均提供960×540关图/开图；完整木架、闭合宝箱、诱导灯另提供1920×1080法线独立、表面属性独立、全部开启、旋转主光和中性光对照。`probe/batch_state.json`、各物件 `result.json` 和 `render_metrics.json` 是本次结果，派发成功不算通过。

只验证当前材质与Shader：未进入Play、未打开/聚焦窗口、未保存主场景、未跑游戏全旅程或性能基准。Shader初版按旧返回值形式调用LitPassFragment，发现工程锁定URP使用outColor参数后已修正；保留失败痕迹，不把C#编译通过当Shader通过。

正式数值贴图入库角色、完整场景密度、运动、正常游戏流程、性能和真实人工审美仍待补证。局部PASS不等于完整PBR、正式资产或八方旅人品质批准。

局部首轮还暴露配套纸板原几何法线背向镜头，导致错误的掠射角Fresnel及固有色泛白。仅对启用配套材质的七项纸板翻转网格法线、重算切线；位置、顶点、三角形、UV、Albedo Alpha与足底深度不变。源贴图不重着色。首次背向对照保留在failed_backface_r1，不作为最终品质证据。RGB与背景相等不能当作透明轮廓测量：暗物件可能恰好同色，因此仅保留颜色分割碰撞诊断，不伪称轮廓自动PASS。
