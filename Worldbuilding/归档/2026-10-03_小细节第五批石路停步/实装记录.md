# 第五批：石地停步细尘

范围：已批准清单49，肉鸽与剧情共用的战斗表现。玩家沿实际路线移动至少两格，抵达裸露石地时，足边出现四粒短促细尘；水面沿用既有踩水，不新增装饰文字、玩法或正式图片资产。交付目标是实际地图入口至一次合法移动的完整局部样板。

## 实现

- `CombatMovementPlayback.GroundStop` 只在实际最后路点发布一次，携带末段方向、真实路长和到达时间。失效终点、取消和未执行路线没有停步事件；迟到超过0.12秒不补播尘粒。
- `CombatStopDust` 只读表现数据，最多8个并发停步，同格替换，0.36秒寿命。四粒原生像素几何不使用游戏随机数、不写地形或存档。
- `FormalBattlefieldView` 在正式道路／庭院石地才渲染，识别实际 `academy_block_road_*` 与 `academy_block_court_*` 资源；水、火烟、有地形物件或战利品箱的格子不显示。几何位于单位、物件、范围和战术覆盖下方，不占射线，保留一原生像素格边。
- 动画0、反馈停用、战场显示组件停用与 ResetBattleFeedback 清除瞬态。主工程脚本接线，不修改场景、Prefab、Importer和正式图片。

## 验证范围

- Unity CLI 核对主工程 dataPath、CombatPrototype 场景未脏，再导入编译。
- `CombatMovementPlaybackTests` 本次9项通过，包括新增真实到达只发布一次、末段方向与时间、取消／位移失效不发布；已有绕障、连续移动、两级缩放及重置回归通过。`验证/tests.json` 保留原结果。
- 实际 Input System 虚拟鼠标从 `map.node.B1`、进入战斗按钮操作；等待入场演出自然结束，射线命中可见裸石格后实际移动，起点(1,4)，终点(2,2)。结算与可见主体到达目标，实际渲染网格为16顶点／四粒，峰值一个停步。
- 缓存28帧实机截图后编码，时间戳、实际格矩形与像素变化保留。GIF是实机裁剪放大，不是合成动画。足边自然有尘帧与消退帧对比证明可见变化；该对比不是隔离的尘粒材质差分，不以其像素数声称独立效果覆盖。
- 寿命、射线关闭、动画0、反馈停用、显示组件停用、ResetBattleFeedback均在局部验收中检查。清理用注入的表现记录验证中断，不冒充一次业务移动。
- 使用保护玩家存档的隔离内存旅程；没有完成战斗后正常结算返回地图，没有磁盘玩家档案旅程验收；水面排除是接线与资源条件检查，本轮未再次实际踩水录制。上述不记成全流程通过。

## 失败与修正

1. 验证脚本首编译使用了不可访问的内部指针类型及旧 CanvasRenderer.GetMesh 签名；改为实际射线父子关系与当前无参API。随后编译通过。
2. 首两次在固定等待后命中战斗入场遮罩。起初怀疑视口位置，完整命中记录证明格子在屏幕内，真正原因是演出未结束；改为等待遮罩自然收起，有上限，不跳过演出。
3. 第一可走格包含战利品箱。实际截图证明停步不等于接触裸石地；修正渲染条件排除地形物件与 LootTexture，验收目标相应选择裸石格。未改动箱子或玩法。
4. `PreviewUiCapturePage("map")` 与新建内存旅程均不足以将仍进行中的战斗隐藏；相关失败保留，未冒充离开战斗通过。以实际组件停用与明确 ResetBattleFeedback 验证相应清理，正常战后返回仍未验证。

当前完成清单49的局部实机样板。其余未完成清单维持原状态；下一批继续从已批准未完成项选择，不将本项扩大为所有地形脚步或全部战斗环境覆盖。技术通过与用户审美认可分别记录。
