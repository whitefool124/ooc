# 天穹熔炉：固定机位、无破坏版

2026-10-14用户认可九阶段战场概念图，明确移除地形破坏，授权实装其余内容。本记录覆盖本目录旧制作计划中的旋转镜头、22秒时长、破坏与碎石方案。概念方向认可不等于新实机资产正式晋升。

## 本次范围

独立Unity演出场景，7×7米作用舞台；火矢生位于左下。镜头固定俯角45度、水平偏角0度、视野34度、距离13.2米。全程不旋转、不绕镜、不推拉、不震屏。

所有地板、永久建筑与三组展示石障保持完整；没有破坏构件、碎石轨迹、落地碰撞、裂地或对应落石音效。原第七阶段改为火冠回落与尘烟分离。

作为剧情／肉鸽共用表现组件的独立样板，不登记正式职业能力、伤害、范围、卡牌或战斗等待时间。

## 16秒时间轴

| 时间 | 阶段 | 实装方式 |
|---|---|---|
| 0–1秒 | 起手 | 火矢生施术帧、脚边赤金小阵、杖端短受光 |
| 1–3秒 | 地阵通电 | 水平阵纹逐段闭合，八条地表导流向中央汇流 |
| 3–5秒 | 天炉成形 | 三层同轴像素阵带、独立炉腔火流、内部环流与暖受光 |
| 5–7秒 | 炉芯压缩 | 阵带压暗、宽火流退去、内部环流向13px小炉芯收束 |
| 7–7.4秒 | 贯穿接触 | 一条火柱垂直落向中央，小范围接触后再释放 |
| 7.4–9秒 | 主爆发 | 连续低位火冠带向外传播，少量翻卷峰与水平压力波 |
| 9–11.5秒 | 火冠回落 | 炉体退出，火层稀疏，地阵熄灭；障碍始终完整 |
| 11.5–14秒 | 烟尘余波 | 贴地尘浪外散，中央灰烟上升，余烬减少 |
| 14–16秒 | 退场终态 | 薄烟淡去，阵纹与火层关闭，恢复庭院主光，音轨结束 |

## 像素和空间

场景基准为32PPU，即世界像素间距1/32米。新阵带、炉腔火流、小炉芯与连续火冠带均使用独立内置生图原料，按主体网格无几何缩放解码；拒绝轮次保留。

透明安全边由运行时UV窗口定位，不拉伸主体。火冠改变半径时同步计算沿面的UV密度；像素卡保留固定世界尺寸，通过位置、发光包络与显隐产生变化。真实光、阴影和后期保持高清输出。

环境优先复用学院楼、树木、灯和花槽纸板；地板、墙、浅阶梯与石障使用简单模型及已有像素石材贴图。可见模型、源与世界缩放记录见fixed_construction.json与fixed_pixel_density.json。
