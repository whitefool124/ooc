# PC UI 分辨率适配验证

日期：2026-10-01；分支：`dev/ui`；Unity：`6000.5.2f1`。

本次沿用 1920×1080 设计尺寸、320×180 原生像素合同及地图75%/HUD25%分区。所有运行时 UI 共用居中的参考内容区，按原生像素的整数倍率显示；16:10、超宽屏和不能整除的窗口保留边缘区域。分辨率变化时同步更新画布、IMGUI 与战场鼠标坐标，避免 HUD 和战场缩放不一致。

## 改动范围

- `UiResolutionLayout` 统一缩放、屏幕内容区和 IMGUI 矩阵；`ReferenceResolutionCanvas` 管理固定设计尺寸与居中裁切。
- 菜单、HUD、战场、结算、悬浮提示、背包、开发控制台和战斗反馈采用同一坐标口径。
- 修正首页左侧背景使用纵向拉伸锚点时额外叠加1080高度的问题。
- 设置中补充2K、4K、16:10、超宽屏和1366×768选项，保留原有前三档的索引以兼容已保存偏好。
- 没有修改场景、Prefab、游戏规则或正式美术资产。

## 实际运行检查

使用 Unity Game View 的实际渲染分辨率进行验证，不以截图缩放代替分辨率切换；尚未在多台实体显示器上验证系统DPI与独占全屏。

正常流程：启动 → 首页/设置 → 新建档案 → 角色确认 → 学院地图 → B1简报 → 第一场战斗。2K完成上述流程；4K检查战斗与通过HUD按钮打开的背包。分辨率切换后读取所有活跃画布，确认共享缩放系数；检查布局、提示和按钮命中位置。

| 实际 Game View 尺寸 | 原生像素倍率 | 结果 |
| --- | ---: | --- |
| 960×540 | 3 | 战场/HUD完整 |
| 1366×768 | 4 | 1280×720内容区居中留边 |

1280×720、1600×900、2560×1600另有布局与倍率自动测试覆盖。
