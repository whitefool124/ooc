# 1. 游戏框架系统

## 1.1 模式与核心流程

启动后进入以太主界面。选择“开始新游戏”只进入角色选择，不创建存档；玩家在已开放角色中查看人物档案、核心特性与固定基础配置，确认“以此角色开始”后才创建存档并固定该档角色。选择“继续游戏”时不重新选择角色，而是按存档中的权威阻塞状态恢复。每个存档的第一场游戏固定进入该角色的教程阶段。教程阶段由前11个节点组成，包括1个开始节点和10个内容节点；节点、连线、遭遇、事件、奖励与服务均完全预设，不参与随机生成。完成第11个节点，也就是第一场精英战后的商店后，不创建新轮次、不重置资源，而是在同一轮次生成并接入后续常规学院地图；此后的常规节点以及该存档后续轮次的地图节点均按单轮种子随机生成。当前已完成并可选的角色只有维克多·维恩；其他角色的身份、基础配置与剧情入口必须在各自档案确认后才可开放。

> 以太主界面 → 开始新游戏 → 角色选择与固定基础配置预览 → 确认角色并创建存档 → 学院介绍 → 单轮介绍与出发整备 → 进入首轮固定教程地图 → 战斗或处理事件 → 领取奖励 → 工坊与医务室 → 第一场精英战 → 商店首次展开 → 生成并接续随机常规学院地图

进入节点前显示危险度、耗时、敌人、任务目标和奖励类型。完成节点后保留生命、魔力、道具消耗和获得的物品。

### 1.1.1 游戏模式

肉鸽模式：地图、敌群和奖励由种子生成。同一种子生成相同内容。生命归零后结束本轮。

剧情模式：使用玩家在新存档时选择的预设主角与该角色已开放章节。允许回访、补支线、调整装备和重复挑战。不设倒计时、拖延惩罚和永久错过。剧情存档与肉鸽存档分开保存；角色在存档创建后固定，切换角色需要建立另一份存档。

## 1.2 完整一局边界

### 1.2.1 一局边界

| 边界 | 定义 |
|-|-|
| 创建 | 确定模式、单轮种子、内容版本与初始状态；生成结果写入存档，读档不重新抽取。 |
| 开始 | 每个存档的第一场游戏以教程阶段作为当前轮次的前导段。前11个节点完全预设；完成教程后在同一轮次生成并接续随机常规学院地图，不重建角色或清空资源。当前生命、货币、学院贡献、装备与背包、术式与配置、法宝及剩余次数、有效餐食和已完成教程状态全部继承。 |
| 推进 | 选择可达节点，完成战斗、事件或服务，结算资源与奖励，再返回地图。已完成节点可回访但不重复结算。 |
| 首领进入 | 现行基准为学院时序达到 24 后进入首领阶段；完成 10 个随机阶段节点后允许提前挑战。第一阶段约30个节点中，玩家通常实际游玩约20–25个节点。 |
| 胜利 | 完成首领战及其奖励结算，生成本轮总结并结束单轮状态。 |
| 失败 | 肉鸽模式中主角生命归零，完成当前失败结算后结束单轮状态；不得继续开放未获得的节点或奖励。 |
| 中断恢复 | 只从已确认的保存点恢复。写入失败保留原存档；候选、事件结果、商店库存和节点内容不得因退出或读档刷新。 |

## 1.3 流程、存档与恢复

### 1.3.1 总体阶段

> 启动与存档选择 → 新存档首轮教程阶段（前11个完全预设节点，仅一次） → 同轮生成并接续随机常规学院地图循环 → 首领门槛 → 首领战 → 胜利结算；教程已完成且当前无活动轮次时，先执行单轮创建与出发整备，再进入随机常规学院地图循环；任一战斗失败或主动放弃 → 失败／放弃结算。

| 阶段 | 进入条件 | 阶段职责 | 唯一正常出口 |
|-|-|-|-|
| P0 存档入口 | 启动完成 | 新建、继续、设置、存档异常处理；新建后选择已开放角色 | 教程阶段或单轮创建 |
| P1 教程阶段 | 当前存档的第一场游戏且教程未完成 | 角色选择、固定基础配置，以及由1个开始节点和10个内容节点组成的完全预设教程段 | 标记教程完成；保留当前轮次状态，生成并接续随机常规学院地图 |
| P2 单轮创建 | 教程已完成且当前无活动单轮 | 写入模式、种子、版本、约19个随机常规节点和该轮初始资源；不用于教程结束后的首轮续接 | 出发整备 |
| P3 地图循环 | 单轮有效且未进入首领阶段 | 预览路线并处理战斗、事件和服务节点 | 继续循环、进入首领或失败 |
| P4 首领阶段 | 主动提前挑战或学院时序达到门槛 | 锁定普通路线，完成首领准备与战斗 | 胜利或失败结算 |
| P5 单轮结算 | 首领胜利、生命归零或主动放弃 | 生成总结，关闭活动单轮并保存最终结果 | 返回以太主界面 |

### 1.3.4 保存与恢复规则

- 持久状态包括单轮种子与内容版本、完整地图和节点内容、当前位置、节点状态、学院时序、资源、构筑、库存、事件选项与结果、服务使用记录、待领奖励、首领阶段标记和活动战斗状态。
- 界面页签、悬停、滚动、临时预览和未确认选择不作为玩法存档。继续游戏时，由活动战斗、待领奖励、强制首领或普通单轮等权威阻塞状态决定恢复页面。
- 战斗在创建时保存入口快照，并在每个完整命令结算后保存活动战斗状态。中途返回标题或进程关闭后恢复当前战斗，不把退出当作免费重开。
- 肉鸽模式按 Pixso 战斗结果页保留“重新挑战”，确认后完整恢复到本场开战前状态，不重复结算节点、资源或奖励；选择返回入口才结束本轮。剧情模式是否允许重试由任务配置决定。主动放弃肉鸽战斗等同放弃本轮，进入 F61。
- 节点确认前、节点结果确认后、事件选择、每次服务交易、奖励领取或放弃、背包处理、首领阶段切换及最终结算后保存。任何命令只有在玩法结果与对应保存同时成功后才离开当前阻塞状态。
- 保存失败时保留上一份有效存档和当前内存状态，显示 F71。玩家可以重试；不能通过返回地图绕过未保存的成本、结果或奖励。
- 加载时先验证内容版本和完整性。能够迁移时先建立安全副本再迁移；不能迁移时保留原文件并说明原因，不静默重建地图、刷新内容或覆盖单轮。

### 1.3.5 节点怎样算完成

| 节点 | 完成条件 | 学院时序 | 回访 |
|-|-|-|-|
| 普通战斗 | 任务目标完成且结果确认 | +2 | 只显示结果摘要并作为通路，不重开战斗或再领奖 |
| 精英战斗 | 任务目标完成且结果确认 | +3 | 只显示结果摘要，不刷新精英奖励 |
| 首领 | 首领任务完成且胜利结算 | 记录 +3 后结束单轮 | 不可在活动单轮内回访 |
| 事件 | 确认一个合法结束选项 | +1 | 显示已选结果，不再选择或领奖 |
| 工坊 | 首次到达即标记访问；交易分别结算 | 0 | 可回访；已用次数和库存不刷新 |
| 医务室 | 首次到达即标记访问；治疗与餐食分别结算 | 0 | 可回访；治疗、餐食选项与次数不刷新 |
| 商店 | 首次到达即标记访问；购买分别结算 | 0 | 可回访；库存、价格与售罄状态不刷新 |

在地图中单击节点只打开 F11。只有确认“前往”才改变当前位置。到达战斗节点后可以在 F20 暂不挑战并返回地图，但角色仍停留在该节点；再次进入不重抽敌人、地形或奖励。

### 1.3.6 卡住或失败时怎么办

| 情况 | 必须提供的恢复路径 | 禁止行为 |
|-|-|-|
| 背包空间不足 | 奖励留在待领取区；允许整理、装备、调整战术栏、确认丢弃或明确放弃奖励 | 自动丢弃、自动替换装备、退出后清除奖励 |
| 事件无力支付 | 至少保留一个不产生负余额的合法结束选项，可为空手离开 | 所有选项同时非法形成死路 |
| 服务货币不足 | 保留项目并显示不足原因，允许退出 | 负数资源、部分购买或隐藏价格 |
| 学院时序到达 24 | 先完成当前节点、奖励和背包，再进入 F50；普通节点随后锁定 | 在结算中途打断、吞掉奖励或允许再刷零时序收益 |
| 提前挑战首领 | 显示不可逆确认和当前未完成路线；取消仍可继续 | 误触直接锁图、确认后返回普通路线 |
| 战斗中退出 | 保存最后完整命令后的战斗并返回标题；继续时恢复 | 把退出当重开、结算未发生结果或刷新敌人 |
| 保存失败 | 停留在当前阻塞状态并重试；原存档可用 | 显示成功、继续跳转或覆盖原存档 |
| 版本不兼容 | 安全迁移或拒绝加载并保留原存档 | 静默重置、刷新单轮或删除内容 |

# 2. 地图推进系统

## 2.1 学院地图与节点

学院第一阶段地图以约30个节点为范围，包括现有11个固定教程节点和后续约19个随机常规学院节点，分为6个区域；实际总量允许随路线结构和内容验证上下浮动。

地图使用固定的学院区域结构，每个节点都有明确的区域归属。生成节点内容时，区域特色敌人和区域特色事件的出现概率高于通用内容，但不完全排除其他内容。抽取结果由单轮种子决定并写入存档。

区域只规定内容权重，不把敌人和事件锁死在单一区域。后续世界冒险继续使用同一规则：不同地区配置自己的敌人、事件和奖励权重，地图生成器按所在地区抽取内容。

- 只能前往与当前位置相连的节点。
- 地图显示区域、连线、当前位置、已完成节点和可达节点。
- 单击节点后打开摘要，不立即进入。
- 摘要显示名称、类型、危险度、耗时、奖励和进入按钮。
- 完成节点后更新当前位置和可达节点。
- 顶部显示生命、魔力、金币、学院贡献、阶段进度和已完成节点。

## 2.2 奖励、失败与存档

### 2.2.1 奖励

- 节点达到成功条件并完成结果确认后，才创建该节点的奖励状态。进入节点、打开战果或仅完成部分目标都不能提前发放奖励。
- 奖励来源包括金币、学院贡献、装备、术式、卷轴、法宝及节点配置声明的其他内容；普通战、精英、事件和 Boss 分别读取自己的奖励表，不能互相回退抽取。
- 需要抽取的候选由单轮种子、节点 ID、奖励表版本和既有抽取状态决定，生成后立即写入节点状态。重新打开页面或读档必须返回同一组候选，不能重抽。
- 奖励页必须显示来源、全部候选、精确效果、数量或使用次数、占用空间或栏位、与当前构筑的差异，以及不可领取的唯一原因。尚未确认的内容不进入奖励池，也不用临时条目占位。
- F40 统一承载战斗、事件、精英和首领奖励的“展示→选择→收集”流程：顶部固定显示来源与已结算结果，中部区分候选奖励和固定所得，底部显示当前收集进度与下一步；纯金币／学院贡献也走同一界面的紧凑收据态，不另造结算页。
- F40 的候选选择与收集是两个状态：先完成三选一或事件指定选择，再检查固定所得、资源和物品的合法去向；未完成选择时“确认领取”不可用，所有待处理物品解决后才允许提交。
- F40 显示本次事务的完整清单和收集进度；收集成功只播放一次入袋反馈并保留来源标签，重复点击、重开或读档不得重复显示为新的获得。
- 玩家完成配置要求的选择并确认后，系统一次性写入所得内容、奖励已领取状态与相关解锁。写入成功前不能清除候选或离开奖励流程；写入失败时保留原状态并允许重试。
- 背包或栏位不足时，奖励保留在待领取区并进入 F41。玩家必须为每项内容选择合法去向，或在该奖励允许放弃时明确确认放弃；不能自动丢弃、自动替换装备或因退出清除奖励。
- 教程阶段的三场普通战和第一场精英战均允许放弃奖励。放弃前必须二次确认；确认后记录放弃、清除待领取状态并继续流程，固定奖励与候选奖励一并放弃。其他奖励是否允许放弃由对应节点说明。
- 已完成节点回访时只显示历史结果，不重复生成或发放奖励。

### 2.2.2 失败与放弃

- 战斗命令结算后若主角生命降至 0，立即锁定战斗输入并进入失败流程；不再推进其他单位、行动条或未发生的触发，也不生成未获得的胜利奖励。
- 肉鸽模式的战败会进入 F61：保留本轮已发生的路线、战斗、资源和构筑记录并生成失败总结。玩家可重新挑战并恢复本场开战前状态；只有选择返回入口时才保存失败结算并关闭当前单轮状态。
- 玩家主动放弃战斗或单轮与战败进入同一结算出口，但总结必须分别记录“死亡”或“主动放弃”及发生位置，不能把两者混为同一原因。
- 剧情模式的失败出口由战前简报明确声明，可以是重伤、撤离或重试；剧情探索不得因失败附加未公开的倒计时、地点永久错过或拖延惩罚。
- 返回标题、暂停或正常关闭游戏只保存并中断当前流程，不等同于主动放弃。继续游戏必须从最近一个成功保存点恢复。
- 主动放弃、覆盖存档、放弃奖励和丢弃高价值物品必须先显示对象、不可逆后果及确认／取消；取消不改变状态。

### 2.2.3 阶段结算

- 阶段结算的输入是已锁定的节点或单轮结果；战斗、事件或服务仍有未完成命令、待领取奖励、待处理物品或保存请求时，不得提前结束阶段。
- 节点结算依次完成：锁定结果→结算节点耗时与资源变化→生成或确认奖励资格→处理奖励去向→写入节点完成状态与解锁→保存→返回地图或进入下一阶段。任何一步失败都保留当前阻塞状态，不重复扣费或重复发奖。
- 单轮结算记录模式、种子与版本、起始和最终路线、完成节点、战斗结果、最终装备与术式、资源变化、剩余物资、人物标签、胜利／死亡／放弃原因和未解锁内容。
- 结算页只读取已保存结果，不再修改玩法数值。玩家确认离开后才关闭活动单轮并返回以太主界面；保存失败时保留原单轮与结算页，允许重试。
- 同一结算请求必须幂等：重复点击、网络重试、重新打开或读档不能重复消耗学院时序、服务次数、货币、道具，也不能重复获得奖励或解锁。

# 3. 战斗系统

## 3.1 战斗基础

- 游戏结果只由当前状态、配置数据和玩家或 AI 提交的命令决定。
- 相同状态执行相同命令，必须得到相同结果。
- 肉鸽内容在创建单轮时由种子生成并写入存档。读取存档不重新生成地图、敌群、事件和奖励。
- 战斗不使用命中、闪避和暴击随机。允许效果从一个或多个合法目标中按种子抽取；抽取所需状态写入战斗存档，确保相同存档状态提交相同命令时得到相同目标与结果。
- 界面只读取状态、提交命令和显示结果，不直接修改游戏数值。

### 3.1.1 状态层级

| 层级 | 保存内容 | 规则 |
|-|-|-|
| 单轮状态 | 模式、种子、训练路线、当前位置、已访问节点、已完成节点、资源、生命、魔力、装备、术式、背包、待领奖励 | 贯穿本轮，节点之间持续保存 |
| 节点状态 | 节点类型、进入条件、敌群或事件、玩家选择、完成结果、奖励状态 | 每个节点只完成一次；回访不重复结算 |
| 战斗状态 | 地图与场景实例、单位实例、位置、行动点、行动条、状态实例、当前战斗效果、被动快照与触发计数、冷却与使用次数、任务目标实例、战斗日志 | 进入战斗时创建，战斗结束后按继承规则写回单轮状态 |
| 界面状态 | 当前页面、选中目标、预览、提示、弹窗 | 由前三层生成，不作为玩法结果来源 |

### 3.1.2 战斗数据原则

- 所有会改变结果的规则都有唯一的数据来源；预览、AI、实际结算、日志和读档读取同一份规则。
- 进入战斗时锁定本场所用内容。版本更新不能改变已经开始的战斗，读档必须恢复原结果。
- 界面文案负责解释规则，不参与结算。配置缺失或相互冲突时阻止进入战斗，并指出具体内容。

具体字段、ID、表间引用和导入校验见第7章所列的配置说明表，不在总案重复维护。

### 3.2.2 一次行动怎样结算

```mermaid
flowchart TD
```

- 命令通过全部检查后一次性写入，不允许部分执行；多段命中逐段结算。
- 效果按配置顺序处理；伤害后结算附带状态、位移与场地，最后检查胜负并刷新界面、日志和存档。

### 3.2.3 什么时候可以行动

| 检查 | 通过条件 |
|-|-|
| 行动单位 | 单位存活，轮到该单位行动，战斗尚未结束 |
| 资源 | [行动点](https://jcnlgassfnsm.feishu.cn/docx/Y1KydFPjMocJjYxMmFEcTblcnLf#doxcnotsNJZwSylkCxvyvE2c5Qd)、魔力、冷却和使用次数满足配置 |
| 空间 | 目标格在地图内，可到达，未被阻挡或占用 |
| 目标 | 阵营、目标类型、射程和攻击线满足配置 |
| 状态 | 束缚、破势等状态没有禁止该动作 |
| 内容 | 对应装备、术式、道具或交互物存在且可用 |

任何一项不通过，界面保留原按钮并直接显示原因。

## 3.3 回合与行动条

- 持续时间默认使用“回合”：场上任意一个单位开始行动一次，计数就推进 1；不是等所有单位都行动完才算 1 回合。按特定单位计时时必须明确写“自身回合”或“目标回合”，只有对应单位再次开始行动才推进计数。

技能、装备、法宝和状态的持续时间统一用回合表示；行动提前／延后仅在明确修改当前行动条时使用。

- 持续效果施加当下不扣次数；此后每次进入其声明的计时窗口时令剩余回合数减 1，归零后在该窗口的效果结算前移除。重复施加时采用刷新、叠加、替换或无效，必须由效果明确声明。
- 火场统一按公共回合计时：生成当下不扣次数，此后任意单位开始行动时先令所有火场的剩余回合数减 1；归零的火场先移除，再结算仍有效的脚下火场。旧内容的 4／6／8 行动条刻度分别换算为 2／3／4 回合；1 回合不作为标准火场持续值，避免火场在首个后续触发窗口前消失。

| 旧火场持续值 | 现行持续值 | 可覆盖的后续行动窗口 |
|-|-|-|
| 4 行动条刻度 | 2 回合 | 1 个 |
| 6 行动条刻度 | 3 回合 | 2 个 |
| 8 行动条刻度 | 4 回合 | 3 个 |

- 冷却默认按施法者的自身回合计数。技能成功施放后进入冷却，施法者此后每次开始行动时减 1；界面显示“冷却 N 自身回合”，不能只显示数字。
- 行动条范围 0～199；每个时间单位增加有效速度值，达到 100 获得回合。
- 单位行动时，战斗时间和其他单位的行动条暂停。
- 回合结束扣 100；溢出保留，但不能超过 199。
- 同时达到阈值时，依次比较行动条、有效速度和固定顺序。
- 加速／减速改变增长；行动提前／延后直接改变当前值，最低为 0。
- 回合开始：清旧护盾→结算新护盾与装备→状态→冷却→死亡／胜负→重置行动点。
- 主角可连续行动或主动结束；敌人执行一次公开意图后结束。结束时清空行动点。
- 死亡或退出的单位移出行动条；目标达成后立即结束战斗。
- 每次单位开始行动时，战场顶中短暂显示“第 N 回合 · 单位名的轮次”；N 使用本节定义的公共回合计数。当前轮次标志从上一行动者移动到新行动者时采用先加速、后减速的连续位移；首个行动者直接出现，不从无效位置飞入。

### 3.3.2 行动提前与延后

- 行动提前与行动延后都直接修改目标当前行动条：提前增加，延后减少；数值由动作、术式、装备或状态配置给出。
- 修改后行动条始终限制在 0～199。普通动作不会隐式改变行动条；只有配置明确写出的提前或延后效果才会修改。
- 单位已经获得当前回合后，行动延后不会中断或撤销这个回合，只影响回合结束后的剩余进度；结束回合仍按 3.3 扣除 100，结果最低为 0。
- 当前单位行动期间战斗时间暂停。其他单位若因直接提前效果达到 100，只进入待行动队列，必须等当前回合及其全部结算完成后再按行动条、有效速度、固定顺序裁决。
- 同一命令含有多个行动条效果时，严格按配置顺序逐项结算，每一步都执行 0～199 截断；预览必须显示最终行动条、是否进入待行动状态和预计顺序变化。只要预览导致某单位的预计出手顺位改变，就在该单位行右侧循环显示绿色上箭头或红色下箭头，不附解释文字；顺位未改变时隐藏箭头。实际数值在规则层立即生效，行动条长度与数字从当前显示值平滑过渡到新值。
- 死亡或退出战斗的单位不再接受行动条效果，并立即从待行动队列移除。

## 3.4 单位与动作

单位是战斗状态中的行动主体。每个单位必须具有稳定单位 ID、阵营、所在格、存活状态、属性、可用动作和当前战斗内效果；界面、AI、预览与结算必须读取同一份单位状态，不能各自维护另一套数值。

### 3.4.1 基础属性

| 属性 | 定义与边界 |
|-|-|
| 生命 | 分为当前生命与生命上限。正式版主角基础生命上限为 50，创建新角色或新存档时当前生命为 50；装备、餐食、状态或模式配置可以显式修改当前上限。当前生命降至 0 时单位死亡，立即失去占位、目标资格和后续回合。治疗不能超过当前生命上限。 |
| 个人魔力 | 分为当前值与当前上限，用于支付术式成本。进入战斗时恢复到当前上限；战斗中不足时对应术式不可提交。统一称为“个人魔力”，不使用“蓝量”。 |
| 护盾 | 只在当前战斗内存在，按伤害结算顺序先于生命承受伤害；生命周期与回合刷新见 3.6.2。 |
| 行动点 | 单位在当前自身回合内支付动作费用的资源。获得回合时重置为 3，结束回合时清空；不能跨回合储存。 |
| 行动条 | 当前战斗中的行动进度，范围为 0～199；达到 100 时进入待行动状态。增长、溢出、排序和移除规则见 3.3。 |
| 速度 | 决定行动条随战斗时间增长的速率。有效速度由基础值和当前修正共同得到，排序与增长均读取有效速度。 |
| 步数 | 一次移动行动最多可经过的路径格数。基础为 5 格；迟缓时为 3 格；临时加成只影响其声明的移动行动。 |

属性统一按“角色基础配置→出身与装备的持续修正→当前战斗临时修正→上下限截断”读取有效值。出身、装备和临时效果不得直接覆盖角色基础配置；预览、AI、结算和界面必须调用同一条有效属性计算链。

- 生命、个人魔力、行动点和行动条均不得低于 0；有上限的属性不得超过当前上限。
- 动作结算、状态变化或装备变化导致属性改变时，先完成该命令的全部结算，再统一刷新单位状态、可选动作和界面。
- 当前不投放会在战斗中改变生命上限的装备效果；以后若加入，必须先明确当前生命如何随上限变化。

### 3.4.2 玩家可提交的动作

| 动作 | 合法性与费用 | 结算结果 |
|-|-|-|
| 移动 | 当前单位可行动、至少有 1 行动点、目标格可达；消耗 1 行动点 | 沿预览路径移动至目标格，逐格处理进入、经过与邻接触发；实际路径不得超过当前步数。 |
| 武器动作 | 满足武器配置的行动点、射程、攻击线、目标和装备条件；不消耗个人魔力 | 按当前装备武器的动作配置结算。没有统一的“四格范围”或固定伤害。 |
| 术式 | 满足术式配置的行动点、个人魔力、冷却、射程、攻击线和目标条件 | 一次性扣除已预览费用，再按配置结算伤害、护盾、位移、状态或场地效果。 |
| 战术道具 | 道具已装入战术栏，使用次数、射程、攻击线和目标均满足该道具配置 | 当前法宝统一不消耗行动点；成功提交后扣除一次使用次数，并结算条目写明的生命、护盾、魔力、延后等其他代价与效果。 |
| 搜刮／互动 | 目标是正交相邻且可交互的容器、设备或任务物；满足其配置费用 | 搜索容器默认消耗 1 行动点；揭示内容后，拿取本次已揭示物品不再重复扣行动点。空间不足时进入待处理状态。其他互动按对象配置结算。 |
| 战斗中整理 | 主角正在行动且至少有 1 行动点 | 消耗 1 行动点后打开整理界面，可调整装备与战术栏；关闭界面不返还费用。 |
| 结束回合 | 当前单位拥有回合且没有未完成的命令或阻塞结算 | 清空剩余行动点，执行回合结束流程并交还行动权。 |

- 玩家只控制主角。临时友军与敌人由 AI 控制，但使用与玩家相同的移动、目标、费用、场地和伤害规则，不获得隐藏豁免。

#### 3.4.2.1 位移类型

| 类型 | 地形与阻挡 | 路径和触发 | 固定定义 |
|-|-|-|-|
| 移动 | 受地形可通行性和移动消耗影响；不能越过阻挡单位、阻挡物或封闭墙边 | 逐格形成路径；触发主动移动、离开格、进入格和路径经过事件 | 消耗移动能力完成的常规逐格位移 |
| 突进 | 受可通行性影响，但不支付沿途地形移动消耗；默认不能越过阻挡单位、阻挡物或封闭墙边 | 沿连续路径逐格检查；触发主动移动、离开格、进入格和路径经过事件，但不触发“消耗移动距离”事件 | 由技能驱动的快速主动位移 |
| 跳跃 | 落点必须可站立；不支付中间格地形消耗；可越过普通单位和普通物块，不能越过明确标为不可跳越的墙边或物块 | 只结算起点离开和落点进入，不触发中间格事件 | 从起点直接到落点的越障位移 |
| 强制位移 | 不支付地形移动消耗，每一步仍须可通过；默认不能穿越阻挡单位、阻挡物或封闭墙边 | 逐格检查；触发离开格、进入格和场地效果，不触发主动移动条件 | 推、拉等由外部效果造成的位移 |
| 传送／移相 | 不检查中间路径，只检查目标是否在允许范围且可站立；能否跨越封闭墙边由效果明确声明 | 只触发起点离开和落点进入，不触发中间格，也不算移动、突进或跳跃 | 直接改变所在格 |

位移技能必须同时配置位移类型、范围形状和距离、选点规则、地形消耗、沿途阻挡、落点合法性及路径事件。单项技能可以明确覆盖默认值，但不能由运行时猜测。

#### 3.4.2.2 每场战斗使用次数

- 每个主动术式和法宝都必须声明每场战斗使用次数；没有次数限制时明确写“无限”，不能留空。
- 次数只在动作通过合法性检查并成功提交后扣除；预览、取消、非法目标和支付失败不消耗次数。
- 次数在进入新战斗时重置；战斗内存档与读档保留剩余次数，卸下再装备或移出再放回栏位不刷新次数。
- 冷却和次数同时存在时，两项都满足才能施放；次数归零后本场战斗不可再次施放。

#### 3.4.2.3 动作共用规则

武器、术式、战术道具、法宝、互动和 AI 技能都按同一流程处理：确认当前可用、选择目标或路径、预览费用与结果、确认提交、按顺序结算。来源不同不会改变移动、攻击、阻、防护、状态或场地规则。

- 预览和取消不消耗资源；提交前若战场状态已经变化，旧预览立即失效并重新计算。
- 多段或多目标动作按卡片写明的顺序结算，界面逐项显示实际发生的结果。

### 3.4.3 敌人与友军 AI

- 每个 AI 单位在获得回合前公开本回合的一条完整意图，包括动作类型、目标或目标规则、主要效果和可见费用。
- AI 只从当前合法动作中选择，并按该单位配置的确定性优先级裁决；相同战斗状态与随机种子必须得到相同选择。
- 敌人任一动作结算后耗尽全部剩余行动点并结束自身回合，因此不能先移动再追加攻击。临时友军按已预览意图执行；其每回合动作次数必须由友军配置明确声明，不能沿用敌人规则或由运行时猜测。
- 原意图变得不合法时，AI 按公开的备用优先级重新选择；不存在合法动作时执行停留并结束回合。AI 不得读取玩家未公开的信息，也不能绕过阻挡、射程、攻击线、资源或目标检查。

AI 的意图只决定它准备使用的技能和目标；伤害、射程、费用和状态效果仍遵守对应技能的公开规则。首选行动不可用时，AI 按已公开的备用顺序选择其他合法行动。

## 3.5 战场与空间

战场由遭遇决定尺寸、边界、初始单位、目标、地形与交互物。教程阶段的三场普通战和第一场精英战均为 12×9 格；其他战场使用各自的遭遇规格。

### 3.5.1 空间与运行规则

- 战场使用正交方格。移动只连接上、下、左、右相邻格；路径长度与无特殊说明的射程均按横纵格距离计算，斜向不视为相邻。
- 边界外坐标始终无效，不能成为移动、放置、生成或目标格。
- 每格固定包含 1 个瓦片层、至多 1 个玩法物块、至多 1 个单位和独立的可见效果层。
- 瓦片层表示地表材料，例如普通地面、水面及其他可进入代价；玩法物块表示轻掩体、重掩体、灯藤、水晶、容器、设备和任务物；单位层只保存主角、友军或敌人的占位；效果层显示火场、警示区等效果，不能替代瓦片或物块。
- 现行规则不允许同格叠放多个玩法物块。一个格子最多一个单位；被阻挡或已被单位占用的格不能穿过，也不能成为主动移动终点。
- 移动与攻击线先读取瓦片，再读取玩法物块并合并结果。轻掩体可进入且不阻挡攻击线；重掩体不可进入并阻挡移动和攻击线。重掩体只使要求攻击线的动作不合法，不会隐藏后方单位。其他对象是否阻挡、可破坏或可互动由其配置明确声明。
- 遭遇开始前必须验证地图尺寸、出生格、单位占位、目标格和必需交互物。出生格不得越界、阻挡或重叠；配置无合法落点时不得进入战斗，并报告具体对象与原因。
- 初始位置、任务目标、敌群和地形由任务配置。开战后显示全部敌人、任务目标、地形、交互物和敌方公开意图；本规则不引入战争迷雾或隐藏陷阱。
- 玩家只控制主角；临时友军由 AI 控制，其预定目标、路径和主要结果在结算前可预览。
- 地形或物块被创建、破坏、点燃、熄灭或改变后，移动、攻击线、目标合法性、掩体与交互查询立即读取新状态；已经失效的旧高亮和旧预览必须清除。
- 目标格、撤离格与出生格是配置语义，不额外占用单位层；若需要实体物件，必须另以玩法物块配置，并同时满足占位规则。

#### 3.5.1.1 攻击方式与范围形状

每个造成攻击伤害的动作必须声明近战、发射或投射，并配置范围形状与距离、是否要求攻击线、是否穿墙、是否穿过阻挡物以及是否会被单位拦截。

| 方式 | 攻击线 | 穿墙与阻挡 | 单位拦截 |
|-|-|-|-|
| 近战 | 起点与目标须直接邻接或符合动作声明的近战形状 | 默认不穿墙、不穿阻挡物 | 不适用 |
| 发射 | 从起点到目标逐格建立直线攻击线，例如射线、喷流或瞬时束流 | 默认不穿墙、不穿阻挡物 | 默认不被单位截断；会被截断时必须明写 |
| 投射 | 投射物沿声明轨迹抵达目标，例如箭矢、弹丸或抛射物 | 默认不穿墙、不穿阻挡物；越墙抛射必须明写 | 默认由轨迹上第一个可受击单位拦截 |

“可见”只说明目标能否被选中，不能代替攻击线和阻挡声明。每个术式分别记录“选取范围”和“作用范围”：前者决定目标或锚点能放在哪里，后者决定实际影响哪些格。范围统一写成“形状＋距离”，不用裸射程数字。

| 玩家名称 | 固定几何定义 | 常用写法 |
|-|-|-|
| 直线 | 从锚点朝选择的上、下、左、右一个方向延伸 N 格，包含沿途格 | 直线范围 3 格 |
| 十字 | 从锚点同时向四个正交方向各延伸 N 格，包含四条轴线沿途格 | 十字范围 2 格 |
| X 形 | 从锚点同时向四个对角方向各延伸 N 格，包含四条斜线沿途格 | X 形范围 2 格 |
| 菱形 | 横向距离与纵向距离之和不超过 N | 菱形范围 4 格 |
| 方形 | 横向距离和纵向距离都不超过 N | 方形范围 1 格 |
| 锥形 | 先选主轴方向；第 d 层位于前方 d 格，横向宽度为 2d−1，直到第 N 层 | 锥形范围 3 格 |
| 环形 | 只收录与锚点曼哈顿距离正好为 N 的最外圈 | 环形范围 3 格 |

“含中心”表示锚点也受影响；“不含中心”为默认，可省略；“沿路径”表示作用格由本次实际合法路径产生。“自身”和“单点”不带距离。范围预览必须与实际结算使用同一套几何结果，并在地图边界裁切；墙体只能截断或禁止投递，不能暗中改变范围形状。

#### 3.5.1.2 场地效果层

- 每格最多存在一个场地效果；浅水等瓦片不是场地效果，不占用该槽位。
- 场地效果必须配置优先级、持续回合、触发窗口、伤害或状态、覆盖规则及来源。新效果优先级更高时覆盖旧效果；优先级相同时由后生成者覆盖；更低时生成失败且不消耗费用。
- 覆盖会完整移除旧效果，双方的伤害、状态和持续时间不合并。生成、覆盖、失败和移除都必须进入预览与战斗日志。
- 单位进入带有效果的格时，先完成位移和进入格事件，再按效果配置结算；效果在单位脚下生成时是否立即触发必须由该效果明确声明。
- 燃烧地格优先级为 1；进入有效燃烧地格或在公共回合开始时仍站在其上，会按来源配置受到 8 或 12 点火焰伤害。同一单位在一次行动中至多触发一次火场伤害；火场在单位脚下生成时不立即伤害该单位。重复生成同级燃烧地格时以新来源覆盖，并按新来源刷新伤害与完整持续回合。

### 3.5.2 单位可见、攻击线与灯藤藏身

- 战场没有朝向、正面、背面或视野锥。除进入完整灯藤的敌对单位外，场上所有单位始终互相可见，所在格也始终公开。浅水、轻掩体、晶簇、碎晶、焦痕、重物块和其他单位都不会让单位消失；重物块只阻挡要求攻击线的动作。
- 单位从非灯藤格进入一片正交相连的完整灯藤时，对方记录它进入的第一格为“已知灯藤格”。藤内继续移动不更新已知格。主角进入后仍在己方画面显示，但敌人不得读取其藤内真实格；敌人进入后从玩家画面隐藏，只保留已知灯藤格。
- 搜索方先把已知灯藤格当作候选目标：距离不足时接近，能够攻击时对该格执行一次正常攻击。搜查不是额外技能，沿用该动作原有的射程、攻击线、费用、冷却和伤害，每次只结算一个正常动作。
- 搜查攻击命中后摧毁目标灯藤。若藏身单位仍在该格，同一伤害包同时命中单位，单位显形并结束搜索；若该格为空，则从已搜索区域上下左右相邻、仍完整且未搜索的灯藤中，按当前战斗种子随机选择下一候选格。分支到头时从整个已搜索边界继续，不重复攻击已毁灯藤；结果写入存档，读档不刷新。
- 单位离开完整灯藤、走入已毁灯藤格或脚下灯藤被毁时立即显形。搜索在找到单位、单位显形或该相连藤丛搜完时结束。多名藏身单位各自记录已知格和搜索状态。
- 灯藤原有攻击规则保持不变：完整灯藤阻挡穿过它的攻击线，藤内单位只能攻击正交相邻目标。攻击命中灯藤及其中单位时，同一伤害包按 3.6.1 对二者等值结算；不再配置“只毁藤、不伤单位”的伤害分支。

### 3.5.3 教程特色地块与关卡路径规则

- 教程的特色地块按战斗逐场冻结：战斗1使用浅水与灯藤，战斗2使用灯藤与蓄能晶簇，战斗3使用浅水与封门晶簇，第一场精英战同时使用浅水、灯藤与精英稳压晶簇；三种材料沿用各自稳定规则，组合只改变空间与行动窗口。
- 特色地块可以由攻击、单位靠近、单位进入、移动经过、消耗行动点交互、受击或被破坏等公开条件触发。触发条件与结果必须由配置定义，不在命令执行过程中临时猜测。
- 特色地块对所有单位遵循同一套规则。玩家可以主动利用，也可以引诱敌人触发；系统不得只对主角生效或为敌人提供隐藏豁免。
- 特色地块不是通关钥匙。忽略特色地块时关卡仍须可完成；利用机制只提供更优解、资源优势或更低战损。
- 每张教程战场至少配置 3 条可验证的理想通关路径。路径需要说明入口、关键决策点、利用的机制、风险和预期收益，而不是只记录一条最短路。
- 第二、第三场普通战必须让玩家立即试用刚获得的术式或装备。战斗2固定验证第一组奖励、轻装传令衣、导位罗盘与苗床回流芯；战斗3固定验证第二组奖励、增幅专精、截击铃与学院储能芯；精英战集中验证第三组奖励和两条完整构筑。
- 教程地图保持低复杂度：每张普通战只组合两种特色机制，触发条件必须一看就懂，规则说明默认隐藏并可通过悬停查看。
- 悬停说明采用“短标题＋主要效果＋必要关键词解释”的分层结构。敌人公开意图、状态、特色地块和资源术语使用相同的信息密度，不长期占用战斗 HUD。
- 敌人的意图、人设、外观、技能表现与技能效果必须由同一内容身份关联；允许配置战斗台词增强代入感，但台词不得代替公开意图或规则提示。

### 3.5.4 关卡场地设计规则

- 先确定场地是什么地方、原本做什么、材料从哪里来，再设计敌人和玩法。不能先放一个效果再替它补故事。
- 每种特色材料先只给一条最容易凭常识理解的规则。材料的流动、燃烧、脆裂、遮挡或重量变化必须有可见来源和结果。
- 敌人必须因场地而改变行动：创造、寻找、穿行、改变、利用或避开材料都可以；把材料移走后，其优先路线、攻击几何或威胁时机应发生变化。
- 玩家和敌人使用同一套场地规则。玩家的反制必须能说清楚物理理由，例如绕开、引开、烧掉、灭火、打碎、隔断或利用同一条路线。
- 教程不使用隐藏陷阱、随机命中或敌人全知来制造压力。灯藤藏身时，双方只能依据公开的已知灯藤格和已结算搜查状态行动；除当前候选格与本回合意图外，不显示藏身单位真实格或未来搜索路线。

### 3.5.5 紧凑空间动作链风格

OCC 战斗以“紧凑空间、连续动作链、可利用的占位与环境”为主导体验。参考对象只用于吸收空间控制、动作序列和构筑取舍的设计语法；不引入现代格斗题材、抽牌、弃牌、手牌随机性或随机禁用。现行八术式槽、战斗外编组、个人魔力、冷却、每回合 3 点行动点和行动条仍是根结构。

- 一次主角回合的价值首先来自结束时的局面：自身站位、敌方占位、攻击线、场地触发与下一次公开意图；直接伤害是达成或扩大这一局面的结果，而不是唯一目标。
- 每个主动术式应优先提供一个清晰的空间动词：接近、脱离、穿越、推开、拉近、换位、封线、架势、截击、破障或利用既有场地。允许一个与主动作具因果关系的附带结果，例如突进后的落点冲击、推位后的火场触发或破坏后的空间打开；不得把无关的高伤、硬控、资源回复和行动条变化堆叠成万能动作。
- 单位、物块与边界共同构成可读的身体阻挡。敌人可以互相堵塞路线、挡住攻击线或被引入危险格；玩家也能以推、拉、换位、诱导和占格改变这种关系。非法强制位移仍沿用统一规则：只取消位移，已声明且合法的伤害或其他步骤照常结算；不暗加碰撞伤害或坠落即死。
- 遭遇应有一个紧凑的有效对抗区：入口、可绕行的普通路径、至少一个争夺格和至少一种双方都能改变的材料或物块。较大的 12×9 地图可以保留，但不得把所有格都设计成等价空地；压力来自窄道、掩体、距离、公开攻击几何、占位和有限行动资源，不来自隐藏信息、随机命中或倒计时。
- 敌方意图必须让玩家能在本回合构造动作链：预览除目标和伤害外，还显示实际路径、会被阻挡的单位或物块、推拉终点、场地触发、消失或生成的物块，以及行动结束后的预计站位。任一步造成状态、占位、场地或攻击线变化时，后续预览立即失效并重算。
- 构筑以“空间问题的不同解法”区分，而非只比较面板伤害。八槽直用术式通常应至少包含接敌或脱离、改变敌我相对位置、处理物块或场地、承受一次公开风险中的若干类；不要求固定配比，也不得使某一类成为所有遭遇的唯一合法解。
- 法宝保持与术式不同的职责：术式是可重复使用的构筑语言，法宝以战术栏、行动点和有限次数承担更特化的破局、部署、救援、环境清除或行动条调度。法宝不能取代地图规则或成为必需钥匙。

每张新地图与术式在进入正式数据前，均须完成“局面问题”检查：删除其直接伤害后，是否仍能说明它如何改变路线、占位、攻击几何或敌方下一意图；删除其空间效果后，是否只剩更高数值的普通攻击。两项皆为否时，优先重做效果或场地关系。每场战斗仍保留非机制的合法完成路线，利用动作链只换取节奏、战损、资源或奖励优势。

### 3.5.6 术式词条与构筑迁移

玩家术式不再以燃烧的建立、维持、消费或燃烧条件终结构成流派。燃烧仍可作为敌方动作、场地事故和浅水冷却教学的独立状态或环境规则存在，但玩家主动术式不得把它当作构筑前置、回报或跨卡循环。当前两条玩家主构筑为“地块破坏回流”与“突进穿刺”；交叉编组合法，但不得退回以纯火伤或燃烧层数为核心的第三流派。

#### 3.5.6.1 词条字典

| 核心词条 | 固定语义 | 作用 |
|-|-|-|
| 突进 | 沿声明的连续路径主动移至合法空格；逐格检查阻挡和场地，不支付沿途地形移动消耗。 | 定义突进穿刺构筑的移动路径。 |
| 穿刺 | 附着于一次突进；对本次实际路径正交邻接的声明目标逐一结算卡面伤害。 | 把突进路径转成攻击线。 |
| 破障 | 所有术式伤害均会使作用几何内的可破坏物扣减同值耐久；带有破障的伤害使物块扣减双倍耐久。物块摧毁后立即重算通路、攻击线和占位。 | 让同一次攻击优先打开关键路线。 |
| 裂痕 | 带有裂痕的术式，其伤害几何命中可破坏物时对该物施加临时标记；该物在持续期间被摧毁时触发回流。 | 建立“先用攻击线命中、后改变地形”的构筑顺序。 |
| 回流 | 带有裂痕的物块被摧毁后，恢复 2 点个人魔力并获得 4 点普通护盾。 | 把正确破障转成有限续航。 |
| 破势 | 清空目标当前护盾；目标至下一次自身回合结束前不能获得护盾。 | 压制守点单位，兑现已获得的攻击窗口。 |

推离、换位、震步、护盾、反击、截击、脱险、行动点奖励和场地生成不是词条；它们直接写入术式效果正文，并按卡面声明的目标、数值、持续时间和结算顺序执行。词条只处理跨多张卡复用、需要统一规则解释和预览的构筑关系。

#### 3.5.6.2 直接效果库

首期玩家术式正文只使用以下 16 类直接效果。名称不作为词条徽记；卡面必须补全目标、数值、范围、时点和持续时间。新增正文效果须先补入本表，不得由单张术式临时创造规则。

| 直接效果 | 固定句式与结算 |
|-|-|
| 伤害 | 对声明单位、路径、落点或区域内目标造成 N 点伤害；作用几何内的单位扣减生命，物块扣减 N 点耐久。带有破障的伤害使物块扣减 2N 点耐久。 |
| 获得护盾 | 声明单位获得 N 点普通护盾。 |
| 恢复魔力 | 施放者恢复 N 点个人魔力，不超过个人魔力上限。 |
| 推离 | 目标沿声明方向移动 N 格；下一格不合法时立即停止。 |
| 牵引 | 目标沿朝向施放者的声明方向移动 N 格；下一格不合法时立即停止。 |
| 换位 | 施放者与声明单位交换所在格；两个落点均须合法。 |
| 震步 | 施放者完成突进后，对落点正交相邻的声明目标各造成 N 点伤害。 |
| 续步 | 声明结算完成后，施放者额外移动 N 格；逐格遵守正常移动和阻挡规则。 |
| 获得行动点 | 施放者在声明时点获得 N 点行动点；跨回合奖励必须写为“下一次自身回合开始时”。 |
| 调整行动条 | 声明单位当前行动值按卡面标注的正负数变更 N；结算后按行动条规则重新排序。 |
| 清除状态 | 从声明单位移除卡面指定的一种状态。 |
| 生成场地 | 在声明格生成卡面指定的场地效果；卡面写明持续时间和同格叠放规则。 |
| 清除场地 | 从声明格移除卡面指定的场地效果。 |
| 格挡 | 至下一次自身回合开始前，施放者第一次受到卡面指定的伤害时，先获得 N 点普通护盾，再结算该次伤害。 |
| 反击 | 至下一次自身回合开始前，施放者第一次受到相邻敌方攻击后，对该攻击者造成 N 点伤害。 |
| 截击 | 在声明空格建立截击点，持续至下一次自身回合开始；第一名敌方单位进入该格时，受到 N 点伤害并沿卡面方向推离 1 格。 |

可破坏物不是术式的选定目标。所有术式伤害先按已声明攻击几何处理单位和物块；破障只把其中物块承受的耐久伤害翻倍。裂痕、回流和破势只按词条字典结算，正文不得重复书写其固定结果。突进和穿刺的路径、邻接目标判定也只按词条字典结算。

#### 3.5.6.3 OCC 术式状态词条

术式状态词条置于名称旁，不计入主词条和附带词条。它们基于固定八槽、公开敌方意图和实际移动路径定义术式本战可用性、施放风险或多段结算，不引入抽牌、手牌、弃牌或随机失效。

| 术式状态词条 | 卡面短述 | 固定语义 | 使用边界 |
|-|-|-|-|
| 断链 | 施放后本战锁定 | 成功施放并完整结算后，本战锁定该术式；术式仍占原槽位，下一场战斗恢复可用。 | 表示以太回路完成一次不可逆放电；只用于高价值破局，施放失败不锁定。 |
| 抢隙 | 错过战机本战锁定 | 当前自身回合结束时，该术式本回合曾存在合法目标或合法路径却未施放，本战锁定。 | 表示公开战机已错过；只用于首轮窗口已完整预览的术式，不用于基础术式。 |
| 承线 | 身处敌方攻击区可用 | 施放确认时，施放者当前格必须处于至少一个公开敌方伤害几何内。 | 表示顶着已知风险执行反制；预览必须显示满足条件的敌方攻击线。 |
| 越线 | 穿越敌方攻击区可用 | 声明移动路径必须进入一个公开敌方伤害几何，并在终点离开该同一伤害几何。 | 只用于突进和续步术式；预览高亮进入格、离开格及对应敌方意图。 |
| 复振 | 追加一次声明伤害 | 首次伤害包完整结算后，对同一批仍存活的实际目标再结算一次卡面声明的复振伤害包；不重新选目标，不再次触发裂痕、回流或其他施放后效果。 | 表示回路的二次振荡；卡面必须分别写明首次与复振伤害数值。 |

冷却、次数和行动条变化继续写入费用或正文，不设同义状态词条。遭遇临时赋予的指令属于遭遇机制，不伪装成玩家术式词条。

#### 3.5.6.4 两条构筑链

| 构筑 | 核心链 | 玩家问题 | 不可越过的边界 |
|-|-|-|-|
| 地块破坏回流 | 破障 → 裂痕 → 摧毁物块与触发其材料结果 → 开线／改变占位 → 回流 | 此刻是先拆开路线、引爆对象，还是保留物块继续遮挡或诱导敌人？ | 必须存在不拆物块的完成路线；回流不能由空打、攻击单位或重复标记无限产生。 |
| 突进穿刺 | 突进 → 穿刺路径邻接目标 → 震步／推离改变阵形 → 脱险或架势承接下一窗口 | 怎样穿过狭道、从哪一侧切入、把谁推向物块或危险格、又在哪里结束回合？ | 突进不能穿模、越界或无视阻挡；穿刺与震步不能靠无条件高伤替代实际走位。 |

使用词条的主动术式固定记录一个主词条、至多一个附带词条、目标／几何、触发条件、结算顺序、回报和反制；无词条术式必须是位移、反应、场地处理或行动条调度，纯数值增幅不能作为独立奖励术式投放。遭遇应有一个紧凑的有效对抗区：入口、可绕行的普通路径、至少一个争夺格和至少一种双方都能改变的材料或物块。敌方意图须预览实际路径、阻挡单位或物块、推离终点、场地触发、物块变化和行动结束后的预计站位。

## 3.6 伤害、防护与状态

### 3.6.1 命中与伤害

- 攻击默认命中。
- 不使用命中率、闪避率和暴击率。
- 所有敌我技能、武器和法宝使用同一套伤害尺度。同一个伤害包命中单位时扣减等量生命，作用几何内的可破坏物扣减等量耐久；带有破障的术式伤害对物块耐久翻倍。除破障倍率外，不因目标类型获得额外倍率、额外伤害或减伤。
- 术式的选定目标是敌方单位、路径、落点或区域，不能把可破坏物作为术式唯一选定目标；伤害几何内的物块随同结算。范围伤害是否波及友军必须由效果明确声明。非伤害动作不会因此自动获得伤害或扩大目标范围。
- 伤害类型、目标阵营、范围位置、状态附加和摧毁触发仍按效果声明；中心与溅射可以配置不同伤害，但同一个位置产生的伤害不能再按单位／物件分成两套数值。
- 同一次命中的伤害合并成一个伤害包。
- 多次命中分别结算。
- 百分比减伤先于护盾结算。同类取最高，异类相乘，总上限 50%，结果向上取整。
- 伤害默认先扣护盾，再扣生命。
- 确认攻击前显示目标、伤害、状态、消耗和行动顺序变化。

可破坏物使用与单位伤害同一尺度的耐久梯度：

| 物件层级 | 耐久 | 典型对象 |
|-|-|-|
| 易碎 | 6 | 灯藤等脆弱植物 |
| 轻型 | 8 | 轻掩体、普通小型设备 |
| 标准 | 16 | 蓄能晶簇、封门晶簇 |
| 重型 | 24 | 重掩体、精英稳压晶簇 |

不可破坏的永久墙体和边界物块没有耐久，也不是合法受击目标。敌方动作同样遵守统一伤害；例如同一次冲撞不能对单位造成一个数值、对物件再改用另一个数值。

### 3.6.2 护盾与掩体

- 普通护盾只在当前战斗有效。
- 自身回合开始时清除旧护盾，再结算新护盾。
- 不同来源的护盾可以叠加。
- 同一来源在同一次本单位回合开始结算中只触发一次。
- 轻掩体可进入，不阻挡攻击线；本单位回合开始时，若位于轻掩体格，获得 2 点护盾。
- 重掩体不可进入，阻挡移动和攻击线；本单位回合开始时，若位于重掩体的正交相邻格，获得 4 点护盾。
- 掩体护盾只在本单位回合开始时统一检查一次；回合内换位和折返不会触发或补发。
- 破势会清空护盾，并阻止目标获得新护盾，持续到目标下一次自身回合结束。

### 3.6.3 状态

当前单位状态只有燃烧、迟缓、束缚和破势。火场、烟尘、水面、冰面、强光、暗区、导电路径和任务地形属于战场环境，不是单位状态；环境仍可按自身规则施加或移除单位状态。

状态栏显示两类信息：单位状态说明正在承受的伤害、限制或防护；蓄备效果说明尚未兑现、将在之后触发的结果，例如“本回合下次武器命中额外造成 4 点火焰伤害”。出身天赋、装备特效和被动术式本身不是可驱散状态，只有它们产生的临时结果才进入状态栏。

| 状态 | 固定语义 | 可由具体技能调整 |
|-|-|-|
| 燃烧 | 在声明的触发窗口对单位造成伤害 | 每次伤害、触发窗口、持续时间、重复施加规则 |
| 迟缓 | 生效期间步数变为 3 格 | 持续时间、重复施加规则 |
| 束缚 | 生效期间不能主动移动 | 持续时间、重复施加规则；是否限制特定强制位移必须由效果另行声明 |
| 破势 | 施加时清空护盾，并禁止获得新护盾，持续到目标下一次自身回合结束 | 来源与施加条件 |

- 重复施加必须明确选择刷新持续时间、增加持续时间、替换、独立并存或无效之一。没有显式规则时不默认叠层，也不默认刷新。
- 持续量只在状态声明的窗口扣减。触发效果、扣减持续量、移除状态与死亡检查的先后顺序必须固定，并同时用于预览和实际结算。
- 状态或当前战斗效果的施加、蓄备、触发、消耗、移除、到期和抵抗结果都写入战斗日志。单位信息与动作预览显示名称、主要效果、剩余持续量或触发窗口、来源以及会阻止当前动作的原因；状态栏优先显示会改变当前决策的临时效果，悬停展开完整被动来源。
- 普通状态在战斗结束时清除，不带入下一场战斗。需要跨战斗持续的餐食或其他效果属于单轮增益，必须使用独立数据，不伪装成普通战斗状态。

### 3.6.4 多段效果

- 一个动作同时造成伤害、位移、状态或场地变化时，按照卡片显示的顺序逐步结算；后一步读取前一步已经改变的战场状态。
- 某一步因目标失效或条件不满足而跳过、缩减或失败时，必须使用技能预先写明的处理方式，并向玩家显示实际结果。
- 属性变化统一按基础值、直接设定、加法、乘法、上下限的顺序计算；例外必须在具体效果中明说。

## 3.7 战斗结束与节点结算

- 达成任务目标后结算，不要求默认清场。
- 肉鸽模式中，主角生命归零后结束本轮。
- 剧情模式按任务配置进入重伤、撤离或重试。
- 选择节点只更新当前位置。节点耗时、奖励和进度在节点结果确认后统一结算。
- 学院时序是肉鸽模式记录节点推进程度的进度值。普通战斗消耗 2，精英战斗和首领战消耗 3，事件消耗 1，其他节点不消耗。
- 学院时序不提供生命自然恢复；生命只能通过治疗、餐食或其他明确公开的效果恢复。
- [学院时序](https://jcnlgassfnsm.feishu.cn/docx/Y1KydFPjMocJjYxMmFEcTblcnLf#doxcnttYlL4FS4wO15V6AQkYiSf)达到 24 时，完整结算当前节点后进入首领阶段。提前挑战首领需要完成 10 个随机阶段节点；第一阶段约30个节点中，玩家通常实际游玩约20–25个节点。地图通行与首领进入不再检查额外进度凭证；普通节点按连通关系开放。
- 已完成节点可以回访，但不重复消耗[学院时序](https://jcnlgassfnsm.feishu.cn/docx/Y1KydFPjMocJjYxMmFEcTblcnLf#doxcnttYlL4FS4wO15V6AQkYiSf)，不重复获得奖励。
- 战斗结束后保存生命、魔力、道具消耗、背包、装备、术式和战利品；下一场战斗开始时魔力恢复到当前上限。[行动点](https://jcnlgassfnsm.feishu.cn/docx/Y1KydFPjMocJjYxMmFEcTblcnLf#doxcnotsNJZwSylkCxvyvE2c5Qd)、行动条、冷却、普通状态和护盾不带入下一场战斗。
- 创建单轮、选择节点、确认事件选择、战斗结算、领取奖励和修改装备或背包后自动保存。
- 存档写入前必须通过完整性检查。写入失败时保留原存档并提示玩家。

## 4.2 装备、术式与背包

### 4.2.1 装备

角色有 9 个装备位：头 1、胸 1、鞋 1、背包 1、戒指 2、项链 1、武器 1、施法单元 1。

- 武器位只能装备一件武器。
- 背包位决定背包容量和背包被动。
- 施法单元负责个人魔力上限、术式成本和术式触发效果。
- 副手、手部、腿部、魔导核心和独立导具不属于当前装备位；不符合现行栏位的装备保持停用。

装备没有耐久度。装备配置包括动作、射程、伤害、消耗、状态、词条和使用条件。

#### 4.2.1.1 被动效果

出身天赋、装备、被动术式、餐食和遭遇规则可以在明确时机自动触发，不需要玩家点击指令，也不能当作普通状态驱散。

- 界面必须让玩家看见触发条件、将要发生的结果和每回合或每场战斗的次数限制。
- 预览不会消耗次数；只有条件真正满足并产生结果时才计数。
- 战斗中更换装备不会刷新“每场第一次”等限制。已经产生的蓄备效果按自身规则继续存在，除非效果明确要求原装备仍在使用。

#### 4.2.1.2 确定性锻造

装备有主体位和回路位。玩家只能在工坊选择装备、部件位和背包内的材料，确认前显示唯一结果。锻造不随机，不重掷。

| 装备栏位 | 主体位：承力合金 | 回路位：导能晶片 |
|-|-|-|
| 武器 | 基础武器伤害 +2 | 每个自己回合第一次武器命中后获得 2 护盾 |
| 头、胸、鞋 | 自己回合开始获得 2 护盾 | 每场战斗第一次受到负面状态时，持续时间 -1 回合，最低 1 回合 |
| 背包 | 容量增加 1 行 | 每场战斗第一次打开背包不消耗行动点 |
| 施法单元 | 个人魔力上限 +1 | 每场战斗第一次施放术式时魔力成本 -1，最低 0 |

- 教程阶段中，每件装备最多锻造一次，只能安装一个部件，安装后不能更换。
- 学院第一阶段保留戒指和项链栏位，但当前不投放对应装备，也不开放这两个栏位的锻造。
- 材料占用背包格，锻造后消耗。

### 4.2.2 术式

- 学院阶段有 8 个术式槽。
- 装备后的术式可直接使用，不抽牌、不弃牌、不建立手牌，也不随机禁用；“卡片”只表示固定术式详情，不是抽取或消耗式牌库。
- 术式只能在战斗外更换。
- 进入战斗后锁定当前配置。
- 术式显示行动点、魔力、冷却、每战次数、选取范围、作用范围、目标和效果。卡片不使用“延时”字段，范围统一写成形状和距离。
- 当前主动术式若没有次数限制，仍须在数据中明确写“无限”；卡片只在存在限制时显示“每战 N 次”。
- 玩家卡片中的“回合”采用 3.3 的默认公共计时；只有按特定单位计时时才写“自身回合”或“目标回合”。
- 当前火系术式共 60 个：近战 20、通用 20、远程 20。

#### 4.2.2.1 术式专精

玩家只能在工坊选择术式和背包内的专精材料，确认前显示唯一结果。专精不随机，不重掷。教程阶段中，每个术式只能选择一种专精，安装后不能更换。

| 术式 | 增幅刻墨 | 节流刻墨 |
|-|-|-|
| 灼触 | 伤害 8→10 | 魔力 1→0 |
| 火花 | 伤害 6→8 | 魔力 2→1 |
| 以太护幕 | 护盾 6→8 | 魔力 2→1 |
| 回路调息 | 恢复魔力 2→3 | 冷却 1→0 |
| 热脉增压 | 追加火伤 8→10 | 魔力 3→2 |
| 熔势贯击 | 下次近战命中额外造成 2 点火焰伤害 | 魔力 3→2 |
| 火弹 | 伤害 12→14 | 魔力 2→1 |
| 焦痕跃进 | 路径邻接伤害 8→10；起点火场采用自身配置，不受本增幅影响 | 当前不开放 |
| 熔障爆点 | 中心伤害 16→20；邻格 8 点火焰伤害不变 | 当前不开放 |
| 熔障校准 | 伤害 8→10；标记奖励不变 | 当前不开放 |
| 脱线疾行 | 最大突进距离 3→4 格；行动力奖励不变 | 魔力 3→2 |
| 炉压震步 | 落地冲击伤害 8→10；推位距离不变 | 当前不开放 |

#### 4.2.2.2 被动术式

被动术式与主动术式共用 8 个术式槽。装备一项被动术式占用 1 个术式槽，行动点与魔力消耗均为 0，不生成可点击的战斗指令；进入战斗后随当前配置持续生效，战斗中不能更换。触发次数按每个自己回合分别记录，多目标或多段结算不能重复触发同一次上限。

| 被动术式 | 固定效果 | 边界 |
|-|-|-|
| 回火导流 | 每个自己回合第一次由个人术式对至少一个可受击目标造成火焰伤害后，恢复 1 个人魔力。 | 单位与物件均可触发；同一伤害包、多目标与多段只触发一次；法宝、武器附加伤害和地形伤害不触发。 |
| 动势点火 | 一次主动移动沿实际路径移动至少 3 格后，本回合下一次武器命中额外造成 4 点火焰伤害。 | 每个自己回合最多一次；强制位移、直接传送和原地失败移动不计，未命中则在回合结束时失效。 |
| 缓冲覆层 | 自己回合开始清除旧普通护盾后，若当前护盾为 0，获得 3 普通护盾。 | 每个自己回合最多一次；遵守普通护盾生命周期，不治疗生命且不在敌方回合补发；与其他“自己回合开始获得普通护盾”效果同时结算时只取最高值，不叠加。 |

### 4.2.3 道具与背包

- 战术栏有 4 格。
- 卷轴通常使用 1 次后销毁。
- 法宝配置独立使用次数和启动方式。
- 当前全部法宝主动使用统一不消耗行动点；次数及条目写明的生命、护盾、魔力、行动延后等其他代价照常结算。若实测显示强度过高，再按单件法宝重新评估行动点费用，不预先削弱其空间与构筑作用。
- 未装备背包时使用 6 列×4 行基础容量；装备背包后，容量由该背包的列数与行数属性决定。列数上限为 10，行数按具体背包配置。学院第一阶段当前已登记的勘验背架与快挂整备架均为 6 列×10 行。
- 装备、更换或卸下背包前，必须用变更后的容量检查全部现有物品和被换下的背包。任一物品超界、重叠或没有合法落位时，整次操作失败并保留原装备与摆放，不自动丢弃或挪走物品。
- 空间不足时进入整理界面。整理完成后才能离开节点。
- 战斗中可以消耗 1 点行动点进入整理界面。
- 整理界面允许更换装备和战术栏内容。
- 背包只负责存放装备和材料。装备锻造和术式专精只能在工坊完成。
- 法宝获得时即为完整形态，不存在等级、强化位或强化材料。

- **跑通闭环：**典型首次玩家约 17 分钟经历地图、战斗、奖励、事件、构筑、精英与商店。
- **分段学习：**新概念先单独认识，再尽快放进真实战斗复用；每段只引入少数新认知。
- **形成构筑：**三次奖励与事件至少形成两条可辨认的战斗解法，但不成为通关的唯一钥匙。
- **稳定复盘：**候选、敌方行为、保存点、失败后果与重试入口均可预期，不靠隐藏随机制造失败。

2. **战斗2后：**开放事件3与工坊；事件3结算后开放战斗3。工坊可在战斗3前后访问。

### 6.1.6 确定性与存档

- **建档冻结：**写入首轮版本、地图、节点、事件、候选、敌人脚本与服务库存。
- **操作即存：**节点选择、事件确认、加工、治疗／餐食、战斗结算、奖励领取与购买后立即保存。
- **读档不刷新：**候选、材料、法宝、敌人、服务次数、商品及节点状态保持不变。
- **迁移有边界：**旧存档必须区分“尚未开始”与“已处于旧版流程”，不得静默覆盖进行中的轮次。

### 6.2.2 普通战计时范围

- 三场普通战的快速操作时间均为 65–75 秒，基准值最大差不超过 10 秒。
- 从首次开放战斗输入计至目标达成后的必要演出结束；包含命令、移动、攻击、敌方行动与强制演出，排除加载、教学、思考、悬停、暂停、战前准备、战果与奖励。
- 固定合法命令序列不得用空等、倒计时或无玩法意义的动画补时。快速玩家全流程约 10 分钟，典型首次玩家约 17 分钟。

#### 6.2.3.2 FR-04｜战斗1战果与第一组奖励

战斗1胜利后依次经过只读战果、第一组固定三选一与物品去向处理，然后返回地图。第一组奖励不是提前锁定完整流派，而是让玩家在战斗2立刻获得三种不同解法。

**设计目的：**把战后选择立即转化为战斗2可观察的路线差异，让玩家在突进搜刮、破坏引爆与稳健承伤之间作出第一次战术偏好，但不在此时锁死完整流派。

| 固定候选 | 稀有度 | 效果与战斗2用途 |
|-|-|-|
| 焦痕跃进 | 少见 | 2 点行动点、4魔力、冷却2自身回合、每战无限；沿主轴直线突进最多3格，起点产生每次造成8点火焰伤害、持续2回合的火场，并对路径邻接的敌方单位与可破坏物各造成8点武器伤害。火场按3.3与3.5.1.2结算；可越过灯藤增加的移动距离，第一回合进入中央藤圈。 |
| 熔障爆点 | 少见 | 2 点行动点、4魔力、冷却2自身回合、每战无限；选择菱形4格内一个可见可受击目标，对目标造成16点火焰伤害，并对其正交邻接1格内所有可受击目标各造成8点火焰伤害，可伤友军。中心与邻格均不区分单位或物件。用于等待敌人贴晶后引爆环境。 |
| 炉温护持 | 普通 | 1 点行动点、3魔力、冷却2、射程3；令自身或可见友军获得12护盾。不打开捷径，但提供承受侧锋、晶簇误伤与普通长路线的稳健解法。 |

#### 6.2.3.3 FR-05A｜事件1：受阻的温室传令

负责向旧温室送交检修单的传令生被雨水和失控植被耽搁，请主角接下下一段勤务。事件固定交付轻装传令衣和承力合金，承担第一次战斗外背包与装备比较教学。

**设计目的：**先在无战斗压力的环境中教学占格、旋转、装备比较与是否换装，降低战斗2首次搜刮时同时理解行动点和背包操作的认知负担。

| 交付 | 固定效果 | 玩家操作与去向 |
|-|-|-|
| 轻装传令衣 | 蓝色胸部装备，2×3、负荷1；不提供回合盾，每个自己回合第一次移动行动的步数+1。 | 必须查看2×3占格并放入当前勘验背架的6列×10行背包；允许旋转。紧邻显示它与已装备夹棉练习衣“失去本单位回合开始时的2盾、获得首次移动+1”的差异。玩家可立即装备，也可保留在背包。 |
| 承力合金×1 | 装备主体位的固定锻造材料。 | 放入背包；后续工坊锻造时消耗。确认全部去向后保存事件结果。 |

#### 6.2.3.4 FR-05B｜事件2：温室勤务签领

学院后勤为即将进入温室的学生发放现场工具、餐食和勤务报酬。该事件承担第一次有限次数法宝、战术栏和资源去向教学。

**设计目的：**把有限次数法宝、战术栏和资源取舍拆成独立学习单元；导位罗盘提前展示“改变敌人与环境相对位置”的可能性，但不成为战斗2的必需钥匙。

| 交付或选择 | 固定内容 | 玩家操作与去向 |
|-|-|-|
| 导位罗盘 | 不消耗行动点、完整3次；选择菱形4格内一个可见友军或敌人，目标必须能沿四向主轴建立通向使用者的逐格路径；将目标拉近最多2格，逐格结算，遇边界、阻挡或占用格立即停止，不造成伤害。 | 固定获得并放入一个战术栏格；完整显示剩余次数。战斗2可用于调整敌人与晶簇的相对位置，但不是唯一解。 |
| 学院食材×1 | 首轮餐食的固定材料。 | 作为资源保存，留到精英战前的医务室餐食选择。 |
| 勤务报酬二选一 | 学院贡献+1，或金币+3。 | 贡献可支付一次医务室治疗；3金币达到精英后商店最低商品价格。确认后不能重选或通过读档刷新。 |

事件1和事件2在战斗1奖励结算后同时开放，访问顺序自由；任一事件不得假定另一事件已完成。每个事件独立保存，两者都完成后开放战斗2。

#### 6.2.3.5 FR-06｜战斗2：温室藏品间（已确认设计）

本节为已确认的战斗2设计口径。场景由旧温室调整为学院温室藏品间：中央检修备件箱被失控灯藤包围，两枚蓄能晶簇位于敌方接近路线。任务仍为击倒承压检验偶与高年级陪练生·侧锋；玩家可以抢先进入藤圈搜刮、等待敌人贴晶后引爆，或沿南侧普通路线稳健推进。

##### 贯阵承压机·楔角

![贯阵承压机·楔角：待机、蓄压、锁线、撞击物块与干地卸压姿态参考｜独立美术原料，QA_PENDING，不代表正式资产审批](https://feishu.cn/file/NMx1bN5XQoHcrpxCG3Wcb9RUnse)

> 美术状态：独立原料，`QA_PENDING`，用于设定与姿态参考，不代表正式资产审批。

- 基础：36生命、初始8盾、速度9；自身回合开始获得4盾。普通撞击对相邻目标造成4点物理伤害。表现为单格精英构装体，正面楔形承压头、侧面稳压环与背部泄压阀构成识别轮廓；蓄压、锁线、撞击物块、浅水冷却和干地卸压必须使用不同且可预览的姿态或灯色。
- **锁线：**贯场冲压可用时，在意图生成阶段锁定主角当前公开格；主角藏身时只锁定该相连藤丛的已知入口格。锁定目标不因玩家之后移动而暗中更换；地形或占位变化会立即刷新实际可行路线、终点与预览。
- 贯场冲压：敌方全回合动作、冷却2自身回合、正交最低成本路径预算5。锁定目标格保持不变，但路线按当前公开地形与占位重算；逐格支付浅水与灯藤移动代价。遇到第一个可受击目标时停止并造成8点物理伤害；目标为单位时再沿最后一步方向推1格，推位终点非法时只取消位移，伤害照常结算。单位与物件使用同一伤害值。
- **干地卸压：**冲压在非浅水格结束后，楔角立即清空护盾，并在下一次自身回合结束前不能获得新护盾。冲压在浅水格结束则由冷却沟泄压，不进入该弱点状态。

这套机制使双方共同改写战场：玩家位置决定楔角锁线，楔角会损伤晶簇或摧毁灯藤；玩家再利用已改变的耐久、藏身边界和卸压状态反击。摧毁回流可标记晶簇或楔角，并以熔障爆点和统一伤害完成摧毁；突进控位可从E6沿藤带使用焦痕跃进、脱线疾行或炉压震步，在避开中央冲压线的同时输出或调整站位。普通路线可从D9绕行，等待公开的干地卸压窗口。

**固定回合演示：**开战即公开楔角从H5锁定B5的首条冲压路线，G5稳压晶簇在路线中使冲压停止并承受8点伤害，剩余16耐久。若玩家先毁晶，楔角承受爆裂；若保留晶簇，玩家可在碰撞后用一次16伤或两次8伤补刀。玩家进入E3–G3或E6–G6灯藤时，后续锁线只读取已知入口，楔角撞到该格时按统一伤害同时处理灯藤与藤内单位；冲压进入D列浅水会消耗更多路径预算并取消干地卸压。每次意图生成、路线重算、碰撞和终点状态都必须公开。

| 验证路线 | 关键动作 | 收益与风险 | 失败后的合法续行 |
|-|-|-|-|
| 摧毁回流 | 用熔障爆点的16点中心伤害配合其他伤害摧毁G5，或等楔角碰撞后以一次16伤或两次8伤补刀；爆裂对邻接楔角造成8点以太伤害。 | 最快打开中央线并削盾削血；提前清空晶簇后失去诱导楔角碰撞的机会。 | 转入D9干路，等待公开的干地卸压窗口继续输出。 |
| 突进控位 | 进入E6后沿藤带使用焦痕跃进、脱线疾行或炉压震步接近H5楔角，在避开中央冲压线的同时输出、推位或为下一回合获得额外行动力。 | 把灯藤的高移动代价转成直达侧翼；若入口被撞毁，藏身空间缩小但格位仍可通行。 | 沿南侧外圈撤到D9，重新等待锁线或卸压。 |

**验收规格：**删除浅水、灯藤或晶簇中的任一类都会改变楔角的路线、碰撞对象或弱点窗口；否则该地形不算真正参与战斗。三条路线均不得要求唯一奖励，锁定目标不得暗换，路线变化必须即时刷新预览，非法推位只取消位移而保留伤害。胜利条件只有击倒楔角，D9始终保留非机制通关路线。

精英胜利后先处理只读战果，再进入固定奖励包。玩家从回火导流、动势点火、缓冲覆层三个被动术式中选择一项，同时固定获得低压回路护额×1、定锚支架×1（完整4次实例）和金币6。被动选择只增加3条分支，不回算到前三场普通战的3×3×3基础路径。

**结算与界面：**奖励页只把三项被动作为候选卡，固定装备、法宝与金币放在固定获得区；整包作为同一待领取事务处理。精英奖励不新增教学层。共用选择、去向与原子保存规则见第6.2.5节，精英胜败转换按第1.3节 F61 执行，商店与首轮固定教程段结束见第6.2.9节。

**验收规格：**每次只能确定一个被动术式，同时准确发放低压回路护额、完整4次定锚支架和金币6；任一装备、背包或战术栏去向未解决时整包保持待领取，不部分发放、不重复发放、不开放商店。保存失败保留当前选择与整包内容；读档恢复同一被动候选、选择状态和未完成去向。整包成功写入后再次提交不产生第二份奖励，随后转入常规学院流程时全部已获内容与剩余次数保持不变。

**设计目的：**被动术式以1个术式槽换取无行动消耗的持续收益，为后续正常战斗增加构筑层；固定装备与法宝让精英胜利有可见的物质回报，6金币则保证商店教学不是只能观看。

### A.2.1 主要地图美术参考与视角约束

经用户确认，地图美术主要参考《赛菲莉娅》（Sephiria）的地图表现：地面与地图物件共享统一的斜俯视网格相机，物件可见顶面并按屏幕水平／垂直方向对齐；顶面比例、前立面、轮廓粗细、像素簇尺度与光源方向不得按物件单独改变。该参考只用于提炼地图组织、材质分层和像素密度，不复制具体素材或角色设计。战场单位是唯一例外，单位 Sprite 保留横版游戏纯侧视身体角度，并通过统一脚底基线、占格和遮挡层级落入地图空间；任何地图物件不得斜放或使用 3⁄4 身体角度。

地图场地与物件采用低频到高频的固定阅读层级：先以低对比的大块地表色面建立可行走空间，再以可见顶面、朝屏幕下方的前沿／立面和深色外缘表达墙体、悬崖与掩体厚度，最后只添加稀疏成簇的材质痕迹。小型物件以一个主剪影和一个识别特征为主；大型场景依靠多个简单模块组合，不把单个占格 Sprite 做成徽记、旗帜、铆钉与多层框架同时竞争的微缩建筑。透明物件使用黑色外轮廓与场地分离，内部材质缝优先使用同材质深色而非纯黑；地面不描整格黑框。生图原料阶段就必须采用明显的粗颗粒像素语言：像素块大而清楚，以少量连续的大块明暗塑造体积，不用密集裂纹、苔痕、铆钉、散点、高频抖色或细碎渐变填满表面；不得依赖后续缩小把高分辨率细节碰巧压成像素感。主题批量生产主要替换材质故事与一处识别特征，视角轴向、轮廓复杂度、顶面与前沿关系、光源和阅读密度保持统一。生图内容描述只明确物品是什么、应用场景、玩法占格及整体地图视角，不规定具体部件数量、位置或目标像素；目标尺寸、硬 Alpha、调色板、锚点及单像素外轮廓由后处理合同负责。所有候选必须在自适应原生画布的1×／4×、灰阶、棋盘格与场地接触图中审阅；远距离读取失败或出现暗碎噪声即淘汰。

当前战场玩法物件默认均为单格逻辑占格，但不等于统一使用32×32视觉画布：透明物件保持32 PPU，并按主体无损容纳所需将画布宽高分别向32倍数取整；此前2×2拼接图仅用于验证相邻地块的材质连续性与组合效果，不改变单件物件的逻辑占格。需要多格实体时必须另行确认逻辑占格后再建立多格资产。

人物单位与透明背景的战场物件在解码到主体自身原生像素格并放入最终自适应画布后，将其现有不透明剪影的最外侧一圈像素直接替换为纯黑，形成一个原生像素宽的连续外轮廓；不得向外扩张 Alpha、叠加第二圈深色边或给内部材质缝逐层描黑。铺满逻辑格的地面底图不描整圈黑边，避免每格呈现为按钮框。生图必须从提示词阶段采用明显的32px级粗颗粒信息密度和大像素簇；后处理只允许确定性的背景移除、主体像素格解码、硬 Alpha、源色聚类、锚点与单像素轮廓处理，不得几何缩放、插值、抖色、添加新噪点，也不得以人工或程序重绘修补主体结构。

### A.2.2 统一像素资产生产流程

OCC 后续所有像素资产统一使用“独立内置生图原料→主体像素格自动诊断→无缩放解码→角色规格画布→机器与人工审核”的生产方案。图片原料只使用 Codex 内置 `image_gen`，每项资产独立生成；提示词明确物品或人物身份、游戏用途、视角、材质故事和统一大像素簇语言，但不微观规定部件数量、部件位置或生成图的精确目标尺寸。生成图必须让完整主体使用同一套方形宏像素格；背景棋盘格或透明底不得参与主体像素间距判断。

解码器从主体轮廓与内部色块边界推断像素间距和相位，网格置信度低于1.2、主体内部混用多种像素尺度或轮廓不符合声明用途时直接拒绝，不得降低阈值或以插值缩放掩盖失败。单项最多进行三轮独立原料生成；重试只修正已识别的失败维度，优先强调单一统一像素格、降低细碎结构或收紧单格物件剪影，已通过的维度不得随意重做。普通单格透明物件的视觉画布原则上不超过64×64；超过时必须作为占格与可读性问题重新审核，而不是自动扩大为任意尺寸。

通过网格诊断后，一个宏像素只解码为一个原生像素，不进行任何几何缩放或插值；背景清理不得破坏主体 Alpha，颜色只允许合并到原料中实际观察到的代表色，不新增颜色、不抖色。最终画布按角色规格确定：固定尺寸的地面、图标和界面资产保持各自合同尺寸；单位与透明战场物件保持32 PPU，按主体无损容纳所需向32倍数取整并与逻辑占格分离。随后执行硬 Alpha、调色板上限、锚点和适用资产的一原生像素黑色外轮廓，并生成 manifest、1×／4×／灰阶／棋盘格／实际场地接触证据。自动检查通过只能进入人工审美；人工确认后为 `FORMAL_CANDIDATE`，完成稳定 GUID、Importer 与运行时复核后才为 `FORMAL`。

2026-09-14 的学院维护混合批次作为稳定性基线：6项资产共11次独立生图，首轮主体网格技术通过2/6，经一次针对“统一像素格与剪影复杂度”的定向重试后达到6/6无缩放解码及6/6 manifest机器验证。该结果证明“自动拒绝＋定向重试”是正式流程组成部分，不得把单次生成成功率当作无人值守量产能力。

## A.3 审核与演出边界

表现只消费真实结算；关闭或跳过动画不得改变生命、魔力、行动点、位置、状态、AI或存档。新美术须依次通过独立原料、manifest、1×／4×／灰阶／棋盘格、实际应用、人工审美、稳定 GUID 与 Importer、运行时复核后才能成为正式资产。机器检查或代码完成不能替代人工审美与实机验收。

## A.4 右侧信息栏安全区

右侧信息栏参考坐标为（1456，80），尺寸448×768，底边与底部指令栏之间保留16px。行动值、英雄概况是两张彼此分离的卡片，分别为（16，16，416，480）、（16，508，416，244），各自使用不透明底色和2px细框，卡间保留12px空隙，不新增第三块常驻战斗记录区。两区各有独立翻面按钮，当前战斗内分别保持自己的正反面状态；Tab 同时翻转两区，无论两区此前是否同步。英雄概况正面保留生命、护盾、个人魔力与状态；背面为“玩家状态／被动效果”两栏，左栏显示行动、资源、护盾与当前状态，右栏显示当前生效的被动及来源，无内容时显示明确空态。行动值正面显示0／100／199轴、全局进度和最多五名单位的速度、当前值及预览变化；背面按最新在前读取真实战斗事件记录，内容超出时可滚动查看。翻面采用不受时间缩放影响的水平收拢—中点换面—水平展开动画；动画期间锁住对应按钮，重复输入不得造成中间态或改变玩法状态。每次行动值变化时，数字与条形长度都从当前显示值平滑过渡；预览改变预计出手顺位时，只在对应行右侧循环显示绿色上箭头或红色下箭头，顺位不变时隐藏，不增加解释文字。战斗抬头左侧固定显示生命、金币、学院贡献和当前学期时间，右侧为彼此留有间距的背包、重开、离开按钮；抬头不显示角色名、当前阶段或长操作说明。行动点使用战场左下96×96菱形徽章显示真实当前值与本回合基础上限，不以固定三格表示。

## A.5 结算来源与延迟触发表现

火术反馈读取结算保存的来源单位、结算前来源格与主动／延迟标记，不从受影响对象或结算后位置反推来源。主动施法播放起手；武器附着、反击、标记追击和入格触发只表现触发结果，不重复起手。状态卡为240×48，伤害反馈区域为168×104；字形保持不透明，只以透明度淡入淡出。反馈全程保留8px视口边距，位置对齐2px参考网格。

## A.6 多段特效时序

特效只表现已经发生的伤害、护盾、状态与地形变化。主动起手120ms；投射、接触、命中、状态和地形余效按格依次播放，每段180ms。只挂载触发器时不得提前播放爆炸；延迟触发不得重复起手。新能力只替换重叠格上的旧能力序列；关闭动画、离开战斗、重开或停用组件时清空待播与运行实例。

## A.7 实际移动路径与单位信息随行

移动表现使用已结算命令中的真实逐格相邻路径，不从终点重新寻路，也不显示敌人未来搜索路线。参考时长为每格80ms，总长限制在120–350ms；连续移动从当前视觉位置接续。路径缺失或发生强制位移时直接对齐最终状态，不编造穿越障碍的路线。角色、生命、护盾、状态共用同一位移；单位按视觉足底排序。

## A.8 动作命中与镜头衔接

命令即时结算，表现层保存结算前显示快照：等待移动结束后播放出手与投射，并在命中时刻更新血盾、状态、死亡和地形。普通攻击接触点约160ms，普通技能约180ms，火术采用第 A.6 节时序。非移动动作期间禁止新的战斗操作、AI推进和结算页覆盖；关闭动画时立即对齐最终状态并保留结果反馈。放大视图只随角色当前视觉位置作最小平移，全场视图保持稳定。法宝反馈必须逐项使用实际生命、护盾、魔力与状态变化，不以合计量替代具体结果。

## A.9 底栏指令可读性

底栏为术式、战术栏、结束回合三组：术式组1292×196，4×2共8张316×76卡片，列距4；战术栏360×172，4个168×54快捷槽按2×2排列；结束回合组204×172，内置204×140主按钮。术式通过数字键1–8直接选择。移动、攻击、搜刮与互动不在底栏常驻：左击己方角色只进入移动模式，不立即移动；右键任意地块或单位打开该位置的情境行动菜单，菜单只显示当前合法的移动、攻击、搜刮、互动和术式。空战术槽显示槽号与“空”；占用槽分别显示32px图标、槽号和剩余次数，完整名称通过悬停读取。全部布局对齐2px参考网格，并在1920×1080与960×540下保持整数倍率。

## A.10 行动摘要字形边界

战场左下仅保留96×96行动点菱形徽章，显示真实当前行动点与本回合基础上限。取消常驻的战场决策提示条：移动、攻击、目标合法性和即时结算原因不再以占位文本占据画面；玩家需要完整原因时，通过对应操作或目标的悬停说明读取。行动点数字使用24px FusionPixel12正常字形；禁止自动额外文本、缩小字号、假粗体和文字阴影。徽章不得遮挡底栏或右侧信息栏。

## A.11 当前轮次标志与敌情避让

当前行动者使用不分阵营的黑白轮次标志：角色主体下层显示外包64px格的四角框，参考外框72×72、黑色承托线宽6、白色上层线宽2、每角边长16；角色顶部居中显示16×14白色下指针并带黑色外轮廓。四角框和指针只占角色轮廓外缘，不遮挡角色主体、生命护盾、敌人意图或交互热点，也不接收输入。行动者变化时，整组标志沿屏幕空间从上一行动者先加速、后减速地移动到新行动者；首个行动者直接出现，行动者离开视口时隐藏。顶部短时反馈只保留一类：回合横幅（464×52）；资源变化、行动成功与拒绝反馈移至非顶部位置，常驻抬头只显示状态而不作为通知。敌情徽记与角色主体、血盾状态区或其他徽记重叠时，在视口内就近避让，并用不接收输入的短正交引线指回所属格；空间不足时保留信息并选择遮挡最小的位置。

## A.12 步数与实际路径一致

## A.13 灯藤前后景接触

单格中空灯藤分为后部与前沿：后部位于地形层；前沿与单位按所属格足底深度排序，位于同格角色之后、南侧更近角色之前。空格合成须与原图一致，不拉伸或重复加深；前沿固定在地块上，不随单位移动，并在烧毁或结算显示时刻移除。点击透传至格位。地面附属物位于地板之后、环境和玩法物件之前，不得覆盖灯藤或浮在水面上。

## A.14 越格角色的输入归属

角色已绘制的非透明像素接收悬停、左键和右键，并映射到其玩法格；透明边角穿透至后方角色或地块，重叠角色按绘制深度选择前者。左击己方角色身体进入移动模式，不立即移动，也不切换攻击模式；右键仍打开该格情境行动菜单。命中区域随当前显示矩形、UV、移动和缩放变化，不得用整张透明画布抢占输入；纹理不可读时退回格位操作。

## A.15 战棋遮挡与点选可读性
