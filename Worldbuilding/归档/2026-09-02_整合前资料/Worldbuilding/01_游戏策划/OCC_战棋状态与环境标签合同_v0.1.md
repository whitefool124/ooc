# OCC 战棋状态与环境标签合同 v0.1

> **肉鸽模式覆盖声明（2026-08-15）：** 肉鸽已经用“破势”取代“破甲”：立即移除当前护盾，并持续到目标下一次自己回合结束，期间禁止获得护盾；无盾目标仍被禁盾但不追加伤害。下文“破甲”只保留为剧情模式／旧实现语义，肉鸽内容必须写“破势”。

## 0. 文档定位

- 状态：单位状态、即时效果、地格/环境标签及完整生命周期合同已冻结。
- 归属：两模式共用生命周期框架；正式状态枚举按模式分流，剧情可保留破甲，肉鸽使用破势。
- 上位依据：`OCC_魔法技能与道具内容合同_v0.1.md`、`OCC_八元素术式设计语法_v0.1.md` 与 `OCC_游戏策划案.md`。
- 范围：只定义策划词汇与结算语义，不修改 Unity 现有状态实现或数值。

## 1. 设计原则

1. 单位状态数量少而稳定，元素、武器、敌人和道具复用同一词汇。
2. 单位状态、即时效果、地格/环境标签三者分离。
3. 不使用隐藏命中率、随机抵抗、随机驱散或随机持续时间。
4. 每项结果在提交前显示状态、持续、触发、清除与环境变化。
5. 剧情与肉鸽复用确定性、计时、重复施加、清除和存档框架；具体状态枚举与防御对象可由模式上位合同覆盖。

## 2. 六种正式单位状态

| 状态 | 唯一语义 | 不允许承担的效果 |
| --- | --- | --- |
| 燃烧 | 在固定时点受到确定性持续伤害 | 不同时承担破甲、恐惧或随机蔓延 |
| 迟缓 | 确定性降低移动范围 | 不改变行动条；行动条延后属于即时效果，也不使用闪避率、未命中率或随机跳过行动 |
| 束缚 | 不能主动移动，但仍可攻击、施术或使用道具 | 不等同眩晕、沉默或完整失去回合 |
| 破甲（仅剧情／历史） | 固定降低剧情模式定义的护甲 | 不得进入肉鸽内容 |
| 破势（仅肉鸽） | 立即移除当前护盾，并持续到目标下一次自己回合结束，期间禁止获得护盾 | 无盾目标不追加伤害；不降低不存在的护甲值 |
| 眩目 | 限制有效视距、远程目标或视觉类能力 | 不制造命中率；不同时等同失明、眩晕和沉默 |
| 显形 | 取消隐匿、暗幕和虚假影像保护，使目标可正常锁定 | 不自动增加伤害或降低防御 |

任何新增单位状态都需要产品决定，不能仅因新增元素、技能或敌人而创建。

## 3. 即时效果

以下效果直接结算，不占状态栏：

- 推、拉、击退和位置交换。
- 伤害、治疗、护盾和修复。
- 打断、行动条延后或提前。
- 设备过载、熄火和一次性破坏。
- 清洗、灭火和驱散。
- 方向改变与强制转向。

即时效果仍须填写确切数值、合法目标、时序、反制和预览文本，不能借“不占状态栏”隐藏结果。

## 4. 八类地格/环境标签

| 标签 | 表达内容 | 基本边界 |
| --- | --- | --- |
| 燃烧地格 | 持续火焰与热区 | 进入/停留效果公开；不随机蔓延 |
| 水面 | 可利用的水体或积水 | 可供水系利用并形成导电条件；不是单位“潮湿”状态 |
| 冰面 | 结冰地面或冰制构造 | 移动与破坏规则公开；离开后不保留冰状态 |
| 烟尘 | 烟、雾、粉尘造成的光学遮挡 | 只影响明确视线与光学规则，不等同暗系 |
| 强光区 | 持续照明或强光压制区域 | 与暗区按后续互斥规则结算 |
| 暗区 | 光线被吸收或削弱的区域 | 不消除声音、气味、热量、足迹和实体接触 |
| 导电路径 | 水、导体或设备连接形成的可见传导路线 | 雷系连锁只能沿提交前可预览路径传播 |
| 障碍/掩体 | 土石、冰、法宝或普通物件形成的空间结构 | 阻挡、耐久、破坏与解除结果必须明确 |

单位站在地格上时即时受到公开规则影响；离开后通常不保留对应标签。例外必须由具体条目明确写出，不能暗中转化为新单位状态。

## 5. 八元素默认映射

- 火：燃烧、燃烧地格。
- 水：即时位移、灭火、水面与清洗。
- 风：即时位移、烟尘生成与消散。
- 土：束缚、障碍与掩体；剧情可使用破甲，肉鸽攻坚条目统一使用破势。
- 雷：即时打断、行动条变化、设备过载、沿导电路径传播。
- 冰：迟缓、束缚、冰面。
- 光：眩目、显形、强光区。
- 暗：暗区、隐匿与光学遮蔽；不新增诅咒、恐惧或精神控制状态。

该映射是默认生产语法，不是元素专属权。非元素武器、装置和环境也可以按其实际原理使用同一状态与标签。

## 6. 待决定

### 6.1 单位状态持续计时

- 状态施加后立即生效。
- 燃烧等回合触发效果在受影响单位回合开始时结算。
- 状态在受影响单位回合结束时减少 1 回合。
- 若状态在目标当前回合中施加，本回合结束时不立即倒数，保证至少完整影响目标下一次行动。
- 持续时间按受影响单位的回合计算，不按施术者速度或回合计算。

### 6.2 重复施加

- 同一单位的同一种状态只保留一个实例，不按来源分别保存。
- 重复施加时强度取较高值，剩余时间取较长值；伤害、剧情破甲、肉鸽破势和迟缓数值不相加。破势重复施加不叠层或增加强度，只把截止点刷新为从最近一次施加起的目标下一次自己回合结束；若目标仍无盾，不产生额外伤害或补偿。
- 状态升级必须明确写成另一项“转化”规则，不能隐藏在普通叠加中。

### 6.3 免疫、抗性与弱点

- 免疫会确定性拒绝状态，提交前显示结果。
- 抗性固定降低强度或持续时间；弱点固定提高强度或持续时间。
- 同一抗性/弱点条目只能影响强度或时间之一，不能同时重复修正。
- 不使用概率抵抗、概率免疫或随机持续时间。

### 6.4 定向清除

- 不设置能够清除所有状态的通用净化；每个能力必须列出可清除状态。
- 灭火清除燃烧；解缚清除束缚；剧情中的修复清除破甲；肉鸽中的稳势／解除干扰类条目可清除破势；视觉恢复清除眩目。
- 迟缓由对应治疗、加速或条目明确清除。
- 显形通常等待持续结束，或由明确的重新隐匿效果覆盖。

### 6.5 战斗与存档边界

- 单位死亡或离场时清除全部战斗状态。
- 战斗结束时当前模式的正式单位状态全部清除，不跨节点继承。
- 伤病、污染、生命、个人魔力、设备储能和消耗品是独立长期数据，不能借单位状态跨战斗保存；肉鸽普通护盾也在战斗结束时清零。
- 存档/读档必须精确恢复状态 ID、强度、剩余时间、施加时点和本回合是否已触发。

### 6.6 尚待决定

无。本合同后续只在具体状态数值、表现映射或实现对接立项时扩展，不自动增加新状态或标签。

## 7. 地格标签持续、覆盖与转化

### 7.1 持续方式

- 地格标签只有两种持续方式：持久标签与临时标签。
- 持久标签存在到被清除、转化、摧毁或战斗结束。水面、冰面、导电路径、障碍/掩体默认为持久标签。
- 临时标签在行动条上拥有公开的消失标记；行动条到达标记时解除，不依赖施术者是否仍存活。燃烧地格、烟尘、强光区、暗区默认为临时标签。
- 具体技能可以改变默认持续方式，但必须在提交前显示解除条件或行动条消失标记。
- 同一格同一种标签不叠加为多个实例；重复施加只延后消失标记或保留较高强度，不累加隐藏层数。

### 7.2 基础转化

| 已有标签与新作用 | 确定性结果 |
| --- | --- |
| 燃烧地格 + 水面 | 两者消失，生成烟尘/蒸汽区 |
| 冰作用于水面 | 水面转化为冰面 |
| 火作用于冰面 | 冰面转化为水面 |
| 强光区与暗区 | 互斥；后施加者覆盖前者，不进行随机强度对抗 |
| 风的驱散作用于烟尘 | 清除烟尘 |
| 水面与雷 | 水面提供可见导电条件，雷只沿预览路径传播 |

- 燃烧地格不会随机向相邻格蔓延；需要具体技能明确指定格子与结果。
- 烟尘只影响光学视线，不自动清除强光区或暗区。
- 障碍/掩体可以与水面、冰面、烟尘、强光区或暗区共存。
- 未列入表中的组合不会自动产生新反应；具体技能若要增加转化，必须把输入标签和结果完整写入内容合同。

### 7.3 战斗与存档边界

- 所有战斗地格标签在战斗结束时清除，不跨节点继承。
- 战斗存档必须精确恢复标签 ID、强度、来源、持续方式和行动条消失标记。
- 技能预览必须显示标签创建、清除、覆盖、转化和消失时点。
- 任务中的永久地形变化属于任务/地图状态，不能借战斗地格标签跨战斗保存。

## 8. 可自主补全

可自主补全状态图标、颜色、短标签、日志用语和表现资源映射，但不得改变机械语义。任何新单位状态、隐藏概率或新环境标签类别必须退回产品决定。
