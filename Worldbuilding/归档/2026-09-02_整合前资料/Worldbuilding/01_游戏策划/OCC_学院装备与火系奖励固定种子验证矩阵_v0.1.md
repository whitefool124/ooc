# OCC 学院装备与火系奖励固定种子验证矩阵 v0.1

> 状态：首轮运行时自动化样本已完成（2026-08-16）；18/18 固定种子轮廓与 60/60 奖励资格通过。该证据验证运行时合同与确定性，仍不替代后续真人长局的路线／经济独立测试。
> 归属：仅肉鸽模式学院阶段。
> 证据：`../03_开发管理/OCC_肉鸽运行时M7固定种子验证记录_2026-08-16.md`。

## 1. 验证目标

同时验证以下三件事：

1. 60 项火系术式全部有奖励资格时，等价组和职责抽取仍能给出有区别的选择。
2. 无盾功能装、单胸甲和专门盾装都存在合法胜法，没有一种装备轮廓跨构筑严格占优。
3. 装备、生命／魔力跨战、公开时间恢复和地图路线共同产生取舍，而不是用免费换装、刷回蓝或堆盾消除战损。

## 2. 首轮最小样本

采用 6 个固定种子，每个种子运行三种装备轮廓，共 **18 局**。六个种子分别绑定近战、远程、混合武器各两局，并覆盖下列路线语境：

| 种子代号 | 武器方向 | 路线语境 | 必测装备／机制 |
| --- | --- | --- | --- |
| `ACA-S01` | 近战 | 开放地普通战 → 商店 → 精英 | 接敌、长枪死区、移动装 |
| `ACA-S02` | 近战 | 狭路守备 → 工坊 → 破坏任务 | 战锤物件伤害、盾具、破势 |
| `ACA-S03` | 远程 | 石路巡哨 → 事件 → 重弩线 | 短弓／重弩持续输出、上弦 |
| `ACA-S04` | 远程 | 传讯任务 → 宝藏 → 精英 | 射程装、任务互动装、R 线奖励 |
| `ACA-S05` | 混合 | 搜索容器 → 商店 → 封存外环 | 背包装备、快捷栏、U 线附着 |
| `ACA-S06` | 混合 | 高风险事件 → 双战 → 首领前工坊 | 跨战生命／魔力、重铸、盾构筑 |

三种装备轮廓：

- `LOADOUT-O` 无盾输出／功能装：CH04 或 CH05，其他槽优先攻击、移动、互动或魔力。
- `LOADOUT-C` 常规防御装：当前阶段标准胸甲 2／4／6，不额外追求非胸部盾。
- `LOADOUT-S` 专门盾装：胸甲加 2–3 件合法固定／随机盾装备，目标装备盾合计 6–8（中期）或 10–12（后期），主动牺牲同级输出／机动／功能。

除装备轮廓外，相同种子使用相同入学渠道、事件选择、节点路线和奖励候选；若候选不支持目标轮廓，用调试注入记录替代重掷，不能改变后续种子序列。

## 3. 记录字段

### 每次奖励

`seed`、`node_id`、`reward_table`、三个候选 ID／稀有度／职责／等价组、过滤与重抽原因、已拥有术式数、当前 8 槽、选择 ID、选择耗时。

### 每场战斗

`health_in/out`、`mana_in/out`、回合数、目标完成／失败、武器攻击次数、术式施放次数、主动盾使用次数、装备盾获得／吸收／浪费／被破势阻止、燃烧建立／消费、物件伤害、任务互动 AP、战术道具次数消耗。

### 每个节点后

金币、学院贡献、背包占格、装备轮廓、商店／工坊支出、游戏时间推进、生命／魔力自然恢复、两个可达节点内功能装备是否存在用途。

## 4. 判据

| Hypothesis | Baseline | Pass | Guardrail／Rollback |
| --- | --- | --- | --- |
| 全 60 项不会造成同次奖励重复 | 无等价组过滤 | 等价组同屏 0 次；两个个人术式候选不全部同主要职责 | 若重抽频繁导致候选生成失败，细分职责权重，不缩减总池 |
| 常规胸甲降低战损但不是必穿 | LOADOUT-O | LOADOUT-C 平均生命损失降低约 10%–25%，主动防御仍有施放 | 若选择胸甲后主动盾几乎不使用，先降胸甲盾值或提高功能装价值 |
| 专门盾装是可行专精而非全面最优 | LOADOUT-C | LOADOUT-S 生命损失再降 15%–35%，但伤害、回合数、移动或目标效率至少一项恶化 10% 以上 | 若各项都不差，先移除非胸部盾装附带效果，再降盾值 |
| 无盾功能装能补偿额外战损 | LOADOUT-C | 在对应任务中，LOADOUT-O 至少多完成一次关键互动、搜索或路线收益，且死亡率不过度上升 | 若只有战损没有收益，修正地图投放或功能效果，不补免费盾 |
| 60 项池仍可启动构筑 | 指定术式保底 | 每条核心轴在正常首领节奏前至少出现一个启动件，但不保证具体 ID | 若长期无法启动，增加职责保底或奖励次数，不关闭合法条目 |
| 魔力装备不能换装刷资源 | 空核心 | 任意换装序列都不能使当前魔力净增加；超上限截断可预览 | 出现净增加立即阻断实现，禁止用经济成本掩盖漏洞 |

百分比阈值只用于首轮找异常，不作为正式上线 KPI。样本不足时标记 `INSUFFICIENT EVIDENCE`，不得据此永久删除装备或法术。

## 5. 必测边界案例

1. CH04 + LG01 首次移动达到基础 5 +2，检查狭路、侧翼、重掩体和撤离目标是否仍有位置成本。
2. CH03 + HD02 + HN02 + AC03 与紫／金随机盾词条混搭，验证同件互斥、不同来源相加和破势全阻止。
3. 重弩射击后未上弦时，所有射击预览拒绝；上弦只消耗 1 AP，不产生攻击或免费转向。
4. CR01／CR03 装卸时不恢复当前魔力，超上限部分截断且确认前显示。
5. DG01 对单体 R 线射程 +1、成本 +1，但不扩大锥形、直线或区域形状。
6. 双手武器锁定副手；卸下双手武器前检查背包合法落点，不能凭切换复制或丢失物品。
7. 同一等价组条目不得同时出现在一次奖励，但同局先后获得合法。
8. 所有 60 项至少能从一个合法奖励表被抽到；稀有条目不得错误进入普通战个人术式席位。
