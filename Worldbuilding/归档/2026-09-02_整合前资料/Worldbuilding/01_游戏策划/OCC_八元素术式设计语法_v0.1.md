# OCC 八元素术式设计语法 v0.1

> **模式边界（2026-08-15）：** 本文件中的“护甲”指世界观里的实体防护、材料结构与剧情模式可能使用的表现语义，不等于肉鸽战斗中的可堆叠数值。肉鸽模式没有护甲值、装备固定减伤或旧破甲状态；实体防护在肉鸽内必须落为射线／锁定规则、临时护盾、破势或少数明确且受 50% 总上限约束的百分比减伤。

## 0. 文档定位

- 状态：八元素七维语法已冻结；状态词汇、叠加/互斥和少数双元素组合另立后续任务。
- 归属：剧情模式与肉鸽模式共用。
- 上位依据：`../00_项目管理/以太_世界观与魔法体系圣经_v0.1.md` 第 0 节与 `OCC_魔法技能与道具内容合同_v0.1.md`。
- 用途：判断新术式的主元素、禁止越界，并为后续个人术式、卷轴、现代/远古来源法宝提供生产语法。
- 旧七系及 112 条术式只能逐条迁移，不能覆盖本文件。

## 1. 已决定的共同语法

### 1.1 魔力可以外化为物质

- 魔力可以外化为物质；“不能无中生有”不是现行禁则。
- 外化仍消耗魔力并需要媒介、定式、释放和收束，不能写成无成本能力。

#### 持续与成本

- 维持型：施术者持续供能；停止后迅速消散。
- 定时型：通过定式或锚定媒介维持明确的回合、小时或天数。
- 永久型：需要远高于战斗施术的魔力、稳定材料、长时间收束和专业许可。
- 质量越大、密度越高、形状越精细、维持越久，魔力与媒介成本越高。
- 外化物的燃烧、落差、水压等二次利用均有损耗，可回收能量不能超过投入魔力。
- 战棋条目必须公开生成格数、持续时间、解除时点和解除结果。

#### 复杂度、生命与稀有材料

- 可以形成水、冰、空气、土、石、普通矿物、简单陶质等均质物质，以及墙、柱、刺、平台、容器等简单结构。
- 不能一步生成枪械、钟表、复杂回路、文字文件或完成品药物；精密制品仍须工匠加工。
- 不能创造灵魂、生命、完整生物、可移植活体组织、血液或营养完整的粮食。
- 水可以经净化/稳定术式成为安全饮水；简单无机盐、冷却液等仍需要正确配方和专业媒介。
- 不能稳定外化贵金属、魔力储能晶体、遗迹材料或具有特殊术式性质的稀有物质。
- 永久外化普通原料通常比开采和运输更昂贵，只在救灾、孤立地点、战场工事或高价值精密场景中具有优势。
- 所有外化物保留可检测的相位痕迹；痕迹不是污染，但可用于鉴定、许可管理和犯罪取证。永久建筑或商品化造物需要专业级以上许可和稳定性检验。

### 1.2 不设无属性万能魔法

- 未定向以太只用于感知、校准、储能、干扰和基础防护。
- 未定向以太不能成为同时承担伤害、治疗、推拉、传送与控场的第九元素。
- 通用护盾必须注明元素、材料、法宝或结构原理。

### 1.3 医疗是跨元素工程

- 水：止血、循环与冲洗。
- 冰：降温与抑制肿胀。
- 雷：神经与心律刺激。
- 光：成像、照明与消毒辅助。
- 土：固定与支撑。
- 火：烧灼与器械处理。
- 战斗内以止血、稳定、临时恢复和状态处理为主；严重组织损伤仍需资源、手术与休息。

### 1.4 统一施法装备：法杖、法宝、魔法石、元素石

- 法杖服务魔法师的个人术式，引导个人魔力并改善射程、精度或效率；不内置固定术式，不能让普通人施法。
- 法宝封装固定术式与有限使用次数；现代法宝经操作培训后可由普通人使用，远古法宝需要适配与鉴定；两者次数耗尽后均失效，不能普通充能恢复。
- 魔法石是无元素倾向的通用储能石，可有限补充或代付个人术式消耗，也可作为法宝制造材料，但不能给成品法宝补充次数。
- 元素石是单一元素的稀有催化石，强化、稳定或改变对应元素效果；不作通用电池，也不替代元素训练。
- 魔法石需要充能；元素石在越限时会损坏或失稳。元素石可装入法杖或在制造时封入法宝。
- 法杖、魔法石、元素石是导具/组件，法宝是个人术式、卷轴、法宝三层之一，不增加其他魔法层级。
- 个人施术的身体通道默认隐含，不再逐元素枚举呼吸、手势、盐水、铜线等媒介。只有真实消耗、场地锚定或可反制条件才进入具体术式合同。

### 1.5 身体强化、武装施术与魔法锻造

- 以太素可以短时强化使用者自身的局部身体机能，包括肌肉供能、神经响应、关节稳定、动态视觉与心肺输出；不能无代价整体提高全部属性，也不能以“强化”为名直接控制他人的身体。
- 身体强化的正常代价是疲劳、脱水、热负荷或对应元素的身体压力；严重伤病只在明确越限时固定结算。强化不能代替护甲，也不能让肉体直接抵挡枪弹或强术式。
- 个人术式可通过身体、近战武器或远程武器完成释放。该差异属于个人术式内部的 `combat_affinity / delivery_mode / weapon_requirement`，不构成第四种魔法层级。
- 魔法锻造可制造吸能、导流、偏转与局部场结构，使护甲提高对远程投射物和离体术式的抗性；护甲容量、散热、纹路与维护均须可测量、可损坏、可修复。
- 接触式导能因耦合距离短，可以更高效率使魔锻结构饱和、脆化或断路。远程重火力仍可穿甲，但通常需要集火、专用弹药、蓄能或更高能耗。
- 武器附着必须注明作用于下一次攻击、一次行动或维持时段，并写明合法攻击失败时是否消费；不得用一次普通施法永久附魔整场战斗。

## 2. 八元素第一版边界

| 元素 | 已决定能做 | 已决定不能做 | 核心战棋动词 |
| --- | --- | --- | --- |
| 火 | 加热、点燃、爆燃、熔切、热压、自身局部机能增压、武器热载 | 无条件无限燃烧；控制他人生命力或血液；无代价全面强化身体；代表正义 | 灼伤、点燃、破势、接敌、武器附着、封路、爆破 |
| 水 | 操纵或外化液体、压强、雾、冲洗、灭火 | 直接造冰；操纵血液控制人体 | 推拉、冲洗、湿润、灭火、压制 |
| 风 | 气流、压差、动量、声波、烟尘扩散 | 产生雷电；廉价自由飞行；无视质量拖动重物 | 推移、聚拢、偏转、消散、静音 |
| 土 | 操纵或外化土石、矿物、陶瓷、地基、结构承重与震动 | 直接控制精炼金属；制造生命；任意改变重力 | 掩体、筑墙、破障、锚定、震荡 |
| 雷 | 电荷、电流、导电、神经刺激、设备干扰 | 控风；直接操纵金属；无导电路径无限连锁 | 传导、打断、过载、加速、瘫痪设备 |
| 冰 | 抽取热量、凝结、结晶、外化冰、冻结水分 | 等同水系；停止时间或生命 | 减速、冻结地面、定身、脆化、隔热 |
| 光 | 发光、反射、折射、成像、显影、眩目 | 神圣净化；治疗一切；真实预言或读心 | 照明、标记、揭露、眩目、制造可识破影像 |
| 暗 | 吸收/削弱光、制造遮蔽、轮廓隐匿、干扰光学感知 | 等同邪恶、死亡、灵魂、诅咒或精神控制 | 遮蔽、隐匿、熄光、干扰瞄准、制造暗区 |

## 3. 已决定的补充限制

- 土只直接作用于天然土石、矿物和陶瓷；精炼金属依靠普通机械、雷系导电效应或现代法宝处理，旧“金属系”不得借土系恢复。
- 水不得直接操纵活体内部液体；医疗必须经过接触、器材与专业流程。
- 雷对人体只能形成明确的刺激、痉挛、节律调整或行动打断，不能完整操纵他人身体。
- 光与暗共享光学基础：光偏向发射、反射与信息显现，暗偏向吸收、削弱与信息隐藏；二者都不代表善恶。
- 风可以辅助跳跃、减速坠落或短距滑翔，不能提供廉价自由飞行。
- 冰的脆化只作用于明确材料、护甲或状态，不能作为对所有目标的通用增伤。

## 4. 统一代价、事故与环境规则

- 正常施术只消耗个人魔力。魔力不足时拒绝施放，不随机失败。
- 连续过度施术统一累积“疲劳”；严重越限才造成伤病。元素只决定伤病表现，不增加八种独立负荷条。
- 法宝统一管理剩余次数与确定故障；元素只决定物品失控或制造事故的表现，不建立八套设备资源。
- 不设固定元素克制倍率。反制来自位置、装备、环境、状态和技能公开条件。
- 现场存在对应物质或有利环境时成本较低；缺少时可以用额外魔力外化。环境只有在具体技能明确注明时才是硬条件。

| 元素 | 过度施术的典型伤病 | 法宝/制造事故表现 | 环境依赖与明确反制 |
| --- | --- | --- | --- |
| 火 | 脱水、灼伤、热衰竭 | 火灾、过热、爆裂 | 现场燃料可降低维持成本；冷却、隔热与切断燃料可反制持续燃烧 |
| 水 | 痉挛、眩晕、压力伤 | 泄漏、腐蚀、超压 | 现有水体可降低外化成本；排水、密封和切断连续水路可限制流场 |
| 风 | 耳压伤、眩晕、呼吸紊乱 | 强噪声、飞散物、压差破坏 | 开阔气流有利；锚定、增加质量和实体隔墙可抵抗位移与偏转 |
| 土 | 关节伤、脊柱负担、震动伤 | 塌方、沉降、地基开裂 | 固定构造必须依附承重表面；离开作用面、破坏锚点或绕开工事可反制 |
| 雷 | 神经痛、震颤、心律异常 | 短路、电弧、储能连锁 | 连锁必须沿预览可见的导电路径；绝缘、接地和断路可反制 |
| 冰 | 失温、麻木、冻伤 | 材料脆裂、结冰、管道爆裂 | 水分与低温降低成本；加热、破冰、防滑和干燥环境可反制 |
| 光 | 眼疲劳、偏头痛、视网膜伤 | 强眩光、聚焦起火、信号泄露 | 需要有效视线；不透明掩体、滤镜、烟尘和改变观察角度可反制 |
| 暗 | 夜盲、方向错乱、昼夜节律紊乱 | 吸光积热、光学设备失效、碰撞 | 受视线与现场照明影响；多向照明、持续标记、声音和触觉探测可反制 |

暗系只能削弱光学信息，不能消除声音、气味、热量、足迹或实体接触。光系影像可由触碰、不同观察角度或遮挡关系识破。
