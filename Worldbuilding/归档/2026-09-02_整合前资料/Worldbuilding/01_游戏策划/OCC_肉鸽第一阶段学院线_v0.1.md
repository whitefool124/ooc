# OCC 肉鸽第一阶段学院线 v0.1

> 状态：学院阶段现行策划基线，2026-08-15；方向规则已整合，事件内容与数值仍需生产／验证。
> 归属：仅肉鸽模式。当前学院背景、人物经历与阶段事件全部用于支撑肉鸽单局，不建立剧情模式主角线。
> 上位依据：`OCC_肉鸽模式玩法定义_v0.1.md`、`OCC_肉鸽核心体验循环与资源系统_v0.1.md`、`OCC_肉鸽学院首区地图系统_v0.1.md`、`OCC_学院首区地图拓扑与内容生产_v0.1.md`、`OCC_学院首区节点内容包_v0.1.md`；世界观圣经只提供时代、学院、魔法与社会规则，不把固定剧情主角的正史经历移入肉鸽。

## 1. 任务合同

- **目标：** 将“14 岁进入世界第一学院”做成肉鸽角色人生的第一阶段，使学院背景直接解释节点、构筑、许可、资源、敌群和首领，而不是成为独立剧情或生活模拟。
- **涉及系统：** 40 节点学院地图、学院时序、战斗／事件／服务／宝藏节点、核心许可、角色档案、构筑成长、阶段转入和独立存档。
- **验收标准：** 每个主要背景设定至少对应一个局内决策；战斗仍是核心成长来源；学院事件只产生战斗、构筑、资源或路线取舍；阶段压力始终公开；不存在隐藏概率、无预警关门或剧情模式状态写入。
- **完成后解锁：** 第一阶段角色档案包、事件池扩展、阶段结算与第二人生阶段转入合同。

## 2. 第一阶段定位

玩家控制的不是剧情正史主角，而是一名由本局档案生成的学院新生。角色在 14 岁左右进入学院，其出身、元素、入学渠道、初始债务和异常特征共同形成开局构筑。

第一阶段的核心幻想是：

> 一个资源有限、背景各异的年轻施术者，在学院的训练、委托和事故中证明自己，取得足够许可与装备，处理封存塔危机，并把这段经历带入下一人生阶段。

学院不是可长期经营的校园模拟，而是一张组织战斗和构筑选择的可回访冒险区域。玩家不安排课表、不刷好感、不管理饥饿或宿舍生活；课程、导师、同学、学院机构和城邦居民均作为节点语义、奖励来源或风险条件出现。

## 3. 世界背景如何服务一局

| 学院背景 | 肉鸽玩法作用 | 玩家看到的信息 |
| --- | --- | --- |
| 学院是跨国中立城邦 | 允许同一角色池出现不同国家、阶层和机构背景 | 档案来源、节点文案、奖励渠道和事件立场 |
| 学院只接收具备基础魔法能力者 | 解释所有角色都有一个可战斗的主元素起点 | 开局元素、基础术式和对应奖励权重 |
| 前两年学习通识与安全规范 | 解释第一阶段从基础构筑开始，并逐步取得操作资格 | 普通战、考核、训练许可和基础奖励 |
| 特殊天赋者会得到个别培养 | 为稀有角色特征、缺陷与专属事件提供来源 | 档案特征、公开代价和专属节点变体 |
| 学院保存危险遗物和古代知识 | 支撑宝藏、封存区、精英和首领节点 | 风险等级、许可需求、有限次数法宝 |
| 储能技术仍处于试点 | 支撑个人魔力、消耗道具次数、校准、设备过载和构筑代价 | 次数、成本、故障条件和收益预览；养成装备不损耗 |
| 学院周边仍有魔法生物与遗迹风险 | 支撑郊野战斗与非人敌群，不必伪装成现代战争 | 生物习性、环境规则和战斗目标 |
| 学院内部存在赞助、家族与机构竞争 | 支撑公开的资源取舍，而不是长篇阵营剧情 | 不同奖励池、价格、许可或追加战斗 |
| 学院中立并不等于没有秘密 | 支撑封存异常逐步升级为首领危机 | 跨节点线索、异常等级和阶段结算摘要 |

## 4. 单局开场：学院新生档案

首个可玩切片只开放火元素。开局由玩家选择入学渠道，并从固定种子生成的三组“优势 + 困境”绑定组合中选择一组；不允许跨组拼接或重掷。

### 4.1 玩家选择

1. **主元素：** 首个切片固定为火。其他七元素只显示为后续内容，不提供不可用的空壳选项。
2. **入学渠道：** 首版只启用 3 个，决定初始资源和第一个可见路线优势。

| 候选入学渠道 | 起始优势 | 起始代价 | 首个路线倾向 |
| --- | --- | --- | --- |
| 地方学校推荐 | 额外基础术式候选 | 装备普通 | 教学区／考核 |
| 教会救济名额 | 1 件有 `3–4` 次使用量级的医疗道具 | 金币较少 | 医务／居民委托 |
| 家族或国家赞助 | 额外金币与一件学院库存工具 | 带一项公开债务事件 | 工坊／行政节点 |
| 猎头发现 | 1 件有次数的侦测器 | 初始战术道具次数较少 | 郊野／异常传闻 |
| 事故后特别录取 | 1 个稀有特征 | 初始带轻度公开负面状态 | 封存／校准节点 |

上表是 5 个候选内容，不等于首版同时启用 5 个。首版数量已冻结为 3；具体保留哪三项仍须在事件支持和严格优势检查后写入开局配置，未入选项保留为后续轮换候选。

### 4.2 种子生成

- 种子生成三组合法的“一个小型优势 + 一个小型困境”绑定组合。
- 玩家三选一；组合展示完整效果和关联事件，不允许把不同组的优势与困境自由拼接，也不允许重掷刷开局。

优势和困境必须同时满足：效果确定、开局可见、至少有两种处理路径、不会使某个入学渠道严格优于其他渠道。它们不生成固定人物主线，只进入本局档案、事件权重和结算摘要。

## 5. 第一阶段推进结构

第一阶段沿用 40 节点正交网络和公开学院时序，不改为线性章节。

| 时序 | 世界语义 | 玩法状态 |
| --- | --- | --- |
| 0–6 | 入学与基础训练 | 建立主元素构筑；普通节点和服务节点占主导 |
| 7–12 | 设施见习与外环实训 | 精英、区域门和第一批核心许可来源出现 |
| 13–20 | 封存异常扩大 | 玩家应形成至少一个明确构筑方向；首领可在满足 `12 节点 + 2 许可` 后进入 |
| 21–24 | 学期收束 | 继续探索仍合法，但 UI 持续显示阶段已进入收束 |
| 25–27 | 首领阶段预警 | 每场战斗与每个事件选项显示最终时序、恢复预估、未处理内容和进入首领阶段的结果 |
| 达到或跨过 28 | 强制首领阶段 | 已确认节点按完整成本结算，允许一次自然超出；随后关闭其他耗时节点并直接开放首领，不再以 `12 节点 + 2 许可` 阻塞 |
| 首领胜利后 | 阶段转入 | 先提醒并提供一次学院贡献消费／背包整理机会，玩家确认后清空贡献并进入下一人生阶段 |

学院时序不是剧情模式时间规则，而是肉鸽的一局压力：只有战斗和事件按公开成本推进，并同时驱动生命／个人魔力自然恢复；回访、地图移动、查看、配装、商店、工坊、休整和宝藏均为零时间。

## 6. 一局中的三条成长线

### 6.1 构筑成长

- 普通战斗是金币、学院贡献和三选一奖励的主要来源；武器与养成装备不产生耐久损耗，只结算实际使用的战术道具次数。
- 精英提供稀有装备、术式、法宝或高价值校准机会。
- 宝藏提供一次高价值选择，但不得稳定优于精英战；其优势是低即时战斗风险，代价是路线与机会成本。
- 服务只转换、强化、补充或购买资源，不能创造无限净收益。

### 6.2 学院许可

许可是首领路线资源，不是剧情身份等级。

- 核心许可至少来自精英、事件和宝藏三类节点。
- 任意两枚满足首领许可门槛，不要求固定许可组合。
- 取得许可的节点必须在进入前公开风险和奖励。
- 已取得许可不可因后续事件被随机没收。
- 多余许可只进入本局档案记录；学院阶段结束时全部到期，不转换为下一阶段资源、选择或战力。

### 6.3 生存与运营

- 生命、个人魔力、无耐久养成装备、战术道具剩余次数和明确允许跨战的负面状态跨节点继承；普通护盾在战斗结束时清零，不跨节点。
- 生命与个人魔力按公开游戏内时间自然恢复；已清节点回访、菜单停留和现实时间等待不产生恢复。护盾与战术道具次数不自然恢复。
- 生命在战斗中归零立即结束整局，不等待节点结算或自然恢复，也不能从本场战斗重开或继续。
- 已清战斗节点永久安全；回访不会重新生成敌人或奖励。
- 医务、休整、补给和校准均使用公开金币／学院贡献价格或战术道具次数，不按隐藏概率结算。
- 角色可以因资源不足选择较早挑战首领，也可以继续探索换取更完整构筑，同时承担公开的阶段转入机会成本。
- 武器、防具、导具和其他养成装备无耐久；常规医疗容器、侦测器和工具通常只有 `3–4` 次，卷轴与高强度消耗型法宝可按效果规模更少。

## 7. 节点事件规则

事件是一次公开取舍，不是分支剧情树。每个事件最多包含三步：**读懂情况 → 比较选项 → 立即结算或进入预览战斗**。

每个事件选项必须显示：

- 支付的资源或状态；
- 获得的资源、许可、情报或战斗增益；
- 是否进入战斗；
- 战斗目标、敌人摘要与失败后果；
- 消耗多少学院时序，以及结算时预计恢复多少生命／个人魔力。

允许的事件结果：

- 资源交换；
- 揭示节点；
- 打开捷径或区域门；
- 获得一次性战斗增益；
- 进入已预览的追加战斗；
- 获得许可、卷轴、法宝或构筑候选；
- 将一项开局困境转换为另一项明确代价。

禁止的事件结果：

- 隐藏随机扣血或随机失去装备；
- 因未及时访问而消失；
- 增加需要长期经营的课程、好感、饥饿、心情或日程数值；
- 直接给出永久局外数值强化；
- 让单一入学渠道无条件取得所有收益。

战斗目标失败但主角仍存活时，节点按失败档关闭并继续本局：战斗消耗、时间推进、生命／魔力与已消耗的战术道具次数全部保留，装备不受损；金币和学院贡献首轮按基础值 `50%` 向下取整，取消三选一、附加奖励、核心许可和唯一物品。失败节点不能重试；生命归零仍立即结束整局。

## 8. 角色与关系的首轮边界

首轮不制作人物标签、导师抽取、同学关系、联系人或帮助／拒绝／冲突记录。导师、同学、管理员和居民只作为节点文本、任务 NPC、救援目标或场外说明出现，不形成好感、人物池、跨事件标签或结算变量。人物系统只有在战斗循环验证完成后才能另立任务。

## 9. 背景线索与跨节点叙事

第一阶段可以使用三层异常主题组织信息，但不建立线索计数或固定主角身世谜案：

1. **表层：** 实战训练、器材登记和设施见习中出现不一致记录。
2. **中层：** 工坊、郊野导能柱和封存外环共享同一种异常回路痕迹。
3. **终层：** 玩家确认封存塔维护链已被旧试验或违规操作影响，并在首领节点处理其当前危机。

每条异常信息独立预告一项首领机制、揭示一个高价值节点或改变一段阶段结算文字；不记录“已收集 X／Y”、不设任意两条阈值、不因缺少线索隐藏基础首领信息，也不替代 `12 节点 + 2 许可` 的公开条件。

## 10. 首领与阶段结算

学院封存塔核心是第一阶段唯一固定首领，不按种子切换为第二名监工或战斗变体。首领危机必须由本局已经出现的战斗语言构成：维护链、少量护盾、破势、显影、束缚、导能地格和有限环境失稳，不在终点突然加入全新随机机制。

进入条件：

- 时序低于 28 时自愿提前挑战：至少处理 12 个节点并取得 2 枚核心许可；
- 时序达到或跨过 28 时：当前节点完整结算后强制进入首领阶段，直接开放首领，不再检查提前挑战门槛；
- 入口显示当前值、目标值、缺口、首领原型、已知机制和当前阶段状态。

结算记录：

- 主元素与最终构筑；
- 入学渠道、优势与困境如何被处理；
- 处理节点数、取得许可数和已揭示的独立异常信息；
- 关键战斗与事件取舍；不记录人物标签；
- 生命、伤病、污染、装备和法宝余量；
- 下一人生阶段启用时提供 3 个特殊构筑改造选一项；不直接增加生命、伤害或术式槽。下一阶段内容当前暂缓。

第一阶段胜利不代表毕业或解决学院全部秘密，只表示角色完成入学阶段的核心危机并具备进入下一人生阶段的资格。

## 11. 阶段转入规则

下一人生阶段必须继承构筑身份，但不能把第一阶段探索数量直接滚成无上限优势。

- 必继承：主元素、已装备核心构筑、角色档案、伤病／污染等明确长期状态。
- 限量继承：金币、所有无耐久养成装备、术式和仍存在的战术道具实例按基础 6×10 网格背包容量保留，不按金币／贡献购买或战利品来源区分；已装备物品不占背包格，战术道具保留当前次数，超出容量部分在转入前由玩家处理。
- 不继承：学院贡献、学院地图访问状态、一次性节点增益、学院许可和未使用的阶段情报。物品不会因为来自学院或由贡献购买而自动到期。
- 转入窗口：首领胜利后先显示贡献清零提醒，并提供一次购买、即时服务、装备强化、道具补充和背包整理机会；贡献购买物可继承，但本窗口不能出售、拆解或折算金币。进入下一阶段后可按同类物品的正常金币规则出售，不因贡献来源打折。
- 档案继承：多余核心许可只记录数量并到期；独立异常信息可进入结算文字，但不转换成金币、阶段贡献、道具或基础战力。首轮没有人物标签可继承。
- 未处理节点进入“未处理档案”，只影响结算记录与后续事件池，不追溯惩罚玩家。

## 12. 边界与优势解检查

| 检查 | 主要风险 | 当前约束 |
| --- | --- | --- |
| 战斗与事件的收益 | 玩家绕开战斗只跑安全节点 | 战斗垄断经验与常规三选一；事件只改变风险、路线或有限资源 |
| 宝藏与精英 | 宝藏成为无伤精英奖励 | 宝藏价值高但数量固定、路线成本明确，且不稳定提供核心许可 |
| 许可来源 | 某一类节点成为必选 | 精英、事件、宝藏至少三类来源，任意两枚即可 |
| 过度探索 | 40 节点清图成为唯一正确选择 | 21 后公开收束；达到或跨过 28 后立即锁定其他耗时节点并进入首领阶段 |
| 提前首领 | 12 节点速通严格优于探索 | 速通构筑较薄；额外探索增加构筑完整度和机制情报，但 28 点后会被强制送入首领阶段 |
| 任务失败 | 故意失败刷时间恢复或重复奖励 | 节点失败后关闭、奖励降档且所有状态与已消耗道具次数保留，装备不受损，不能重试 |
| 入学渠道 | 资源型渠道严格更强 | 每项优势绑定代价与路线倾向；不得同时获得资源、情报和许可优势 |
| 人物标签 | 人物系统挤压战斗生产 | 首轮完全不制作人物标签或好感变量 |
| 异常信息 | 变成隐藏收集门槛 | 每条独立揭示，不计数、不设阈值，基础首领信息始终公开 |

## 13. 最小可逆验证

**假设：** 在现有 40 节点首区中加入“3 个入学渠道 + 三组绑定优势／困境 + 独立异常信息”，能让学院背景影响路线和构筑，同时不稀释战斗核心。

**方法：** 使用固定种子测试首版 3 种入学渠道，各运行一条 12 节点速通路线、一条约 20 节点标准路线和一条 25 节点以上探索路线；记录首领前构筑、资源、许可来源、异常信息和事件／战斗比例。

**通过：** 每种渠道至少改变一次真实路线或资源决策；不存在同时在首领准备、剩余资源和许可获取上全面领先的渠道；标准路线仍以战斗为主要成长来源；玩家在进入首领前能说明至少一项学院背景如何影响了构筑。

**回滚：** 若渠道只增加开局数值，则删除数值加成，改为首个节点揭示或奖励权重；若线索不影响决策，则只保留首领机制预览，不继续扩展收集系统。

## 14. 一致性审查结论

本稿已按最新产品决定完成方向整合，结论仍为 **PLAYTEST REQUIRED**。`40 节点`、`12 节点 + 2 许可`、`21 收束／28 强制首领`、火系首切片、3 个入学渠道、三组绑定优势／困境、取消人物标签、取消线索计数、固定单首领和 16–20 条事件池均不再作为方向问题重复询问。进入数据生产前只剩内容落地：从 5 个渠道候选中选出首版 3 个，并为每个渠道配置至少 2 个相关事件。
