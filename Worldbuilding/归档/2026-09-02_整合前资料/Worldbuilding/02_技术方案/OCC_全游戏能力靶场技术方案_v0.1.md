# OCC 全游戏能力靶场技术方案 v0.1

## 定位

靶场是开发验证基础设施，不属于剧情或肉鸽正式关卡。它复用真实 `CombatState`、目标预览、结算器、HUD 与表现层，但不写入存档、不推进任务、不触发胜负结算，也不自动执行敌方回合。

## 分层

1. **能力目录层**：向控制台提供统一的 ID、名称、家族、分组、成本、范围、目标与说明。目录不承担执行规则。
2. **测试案例层**：每种能力家族提供标准场景准备、推荐目标、预览、执行与确定性签名。火元素适配器当前覆盖 F-P01–F-P50；后续元素、武器、道具和敌方能力按同一合同注册。
3. **标准场景层**：运行时生成固定 12×9 棋盘，提供英雄、友军、普通/护盾/重甲/术师/机动敌人，以及轻掩体、重掩体、设备、水面和任务核心样本。
4. **会话层**：保存当前能力、页码、最近预览、最近执行步骤与巡检摘要；所有状态仅存在于当前 Play Mode。
5. **控制台层**：F1 打开开发控制台，F2 直接进入靶场；进入后显示能力浏览、自动准备、预览、执行、重置与全量巡检。控制台只调用会话接口，不包含能力 ID 特判。

## 不变量

- 每次“自动准备”从相同基础场景重建独立状态，避免前一术式污染下一术式。
- 全量巡检对同一案例执行两份克隆，比较预览与结果步骤签名；任何失败必须返回具体能力 ID 与原因。
- 靶场中的任务核心只用于验证“不可作为普通可破坏物”的目标掩码，不承担胜利目标。
- 不修改或保存场景 YAML；不写肉鸽/剧情存档；不生产或替换人物资产。
- 正式战斗继续保持 75% 棋盘/25% HUD；调试控制台为可关闭覆盖层，关闭后不遮挡正式 HUD。

## 当前接入

- 火元素个人术式：F-P01–F-P50，完整预览/执行/确定性审计。
- 通用战斗技能：`RogueliteSkillCatalog` 现有 27 项，覆盖敌方/友方/自身/地格/可破坏物、直接/投射/范围投送与移动、恢复、状态、物体伤害。
- 通用能力扩展点：当前 77 项由两个案例提供器注册；能力描述符、测试案例提供器与会话接口不绑定火系目录，下一阶段可继续添加武器、道具和敌方能力适配器。

## 验收

- 单元测试验证标准场景资产、50 项目录连续性、每项合法案例、前置自动准备与两次执行签名一致。
- Play Mode 验证进入/选择/准备/预览/执行/巡检/退出路径。
- 1920×1080 与 960×540 目视验证控制台文字、分页、结果区域与棋盘/HUD 的关系。
- Unity 编译 0 错误/警告、Console 空、默认场景 `isDirty=false`。
