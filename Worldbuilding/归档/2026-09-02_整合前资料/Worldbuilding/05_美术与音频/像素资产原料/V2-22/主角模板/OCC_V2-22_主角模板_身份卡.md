# V2-22 主角模板身份卡

## 用途与范围

- **角色 ID：** `hero_industrial_scout_template`
- **定位：** 工业区出身的年轻成人侦察步枪手；用于验证 A 战棋形象、B 角色立绘、C 演出形象是否能保持同一身份。
- **范围：** 视觉样本，不改变当前角色生成、剧情、Unity 场景或正式主角资源。

## 不可变身份锚点

| 类别 | 锁定内容 |
| --- | --- |
| 体态/年龄 | 年轻成人、瘦削实用的体态、非英雄化的疲惫感。 |
| 头部 | 短炭黑发、暖中等肤色、右眉横向旧伤、左鬓冷青导体发夹。 |
| 服装 | 煤灰短战术外套、左肩钢制护甲、工装背带与高领内层。 |
| 装备 | 长步枪斜背/持用；腰间小型维护级以太中继导具。 |
| 色彩 | 煤灰/铁黑为主；仅在导体发夹和导具使用小面积冷青。 |
| 禁忌 | 不使用法袍、圣光、悬浮符文、华丽英雄甲或 AI 伪文字。 |
