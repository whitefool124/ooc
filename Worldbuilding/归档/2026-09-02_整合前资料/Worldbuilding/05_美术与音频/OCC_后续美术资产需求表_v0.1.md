## 2. 状态和优先级

| 状态 | 含义 |
| --- | --- |
| `READY_FOR_TRIAL` | 用途与规范足够明确，可以先做 1 件独立试验品 |
| `REWORK_TRIAL` | 已有产品否决稿，仅允许针对明确失败点做 1 件返修样品 |
| `CONTENT_BLOCKED` | 内容 ID、角色身份、地区或玩法未冻结；只做匿名方向探索，不批量生产 |
| `NOT_NEEDED_NOW` | 现有正式资产已覆盖；没有真实页面／关卡误读时不生产 |

| 优先级 | 含义 |
| --- | --- |
| `P0` | 当前可消除明确缺口或验证下一批生产方法 |
| `P1` | 下一个内容包一旦冻结就会立即需要 |
| `P2` | 剧情章节、地区或外部发行目标冻结后需要 |

## 5. 生产前必须补齐的决定

1. **角色：** 固定主角姓名、性别／自定义边界、14 岁入学形象、元素选择如何影响外观，以及首批反复 NPC 名单。
2. **地区：** 下一地区已选择外环农地／猎径；M-A43 起按 `REG-ORH-01` 扩成非 Unity 素材包。真实关卡拓扑、碰撞与章节落点仍未冻结。
3. **元素：** 非火元素的内容池应逐元素冻结；样品只验证水系视觉边界，不能据此批量画技能。
4. **物品：** 外环调查证物已冻结 `ORH-Q01`–`ORH-Q04` 与 1×1 占格；其他任务物和装备仍须先有稳定内容 ID、占格、获取来源和用途。
5. **VFX：** 产品先审核 T09 的形状、亮度和遮挡，再决定是否扩成完整 4–6 帧组；单帧通过不等于整组通过。

## 6. 明确“不生产”规则

- 不为现有 8 张通用页面背景、6 页边装饰、6 空状态、5 横幅、6 角标继续堆同类变体。
- 不重画已完成的学院装备 32、法宝 20、火系图标／VFX、核心战斗语义和学院敌人，除非出现可复现的实机误读。
- 不提前生产 7×50 张非火术式图标、完整 NPC 立绘池、通用粒子库或无关宣传图。
- 不把后期铁路、电气化、连续工厂语言带进入 14 岁入学期学院城邦。
- 不把本轮任何 `CONCEPT`／`REVIEW_READY` 原料复制到 `UnityProject/Assets/`；产品批准后另立正式批次，从独立原料和完整 QA 重新晋级。
