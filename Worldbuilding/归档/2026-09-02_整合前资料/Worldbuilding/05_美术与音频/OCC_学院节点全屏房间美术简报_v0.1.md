# OCC 学院节点全屏房间美术简报 v0.1

**状态：ACTIVE / SUBORDINATE（2026-08-24）。** 本简报只定义学院第一层全屏节点房间的应用组合；资产规格、来源和状态晋级服从 `OCC_美术规范_v0.1.md`，页面材质服从 `OCC_UI学院档案视觉规范_v0.1.md`。

## 1. 角色与玩家阅读

- **资产角色：** 地图节点进入后的独立全屏交互页，不是叙事插画或战场背景。
- **一秒阅读：** 先读节点类型、当前／可进入／已完成状态和主要行动，再读风险、时序、恢复与奖励。
- **应用环境：** 参考画布 1920×1080；主卡 1760×820，左侧 500px 身份页，右侧 1164px 交互页；960×540 等比缩放后仍保留完整标题、主要按钮和退出按钮。
- **材质前提：** 学院档案暖纸、档案卡、布面夹、炭墨与少量氧化黄铜；冷青只表示当前／可执行，红只表示精英／首领危险，灰绿只表示医务恢复，安全黄只表示补给／工坊／宝藏。

## 2. 锁定组合

本阶段不新增未经审美批准的 raster。直接复用已经处于 `FORMAL` 的九类节点图标、风险／时序／生命资源图标，以及 continue／confirm／back／close 导航图标。节点类型图标原生 32×32，在 1920×1080 页面以严格 4×显示为 128px 图版，在 960×540 以严格 2×显示为 64px；禁止插值、描边放大或改色替代。

| 节点类型 | 一秒轮廓 | 页面语义色 | 材质提示 |
|---|---|---|---|
| 起点 | 登记入口 | 冷青／中性 | 布面档案夹与路线签 |
| 普通战 | 训练兵器 | 冷青 | 炭墨阵位与行动签 |
| 精英 | 尖角考核印 | 封存红 | 教官印记与警示封条 |
| 事件 | 折角文书 | 冷青 | 公开批注与事件记录 |
| 工坊 | 校准工具 | 氧化黄铜 | 木制导具与黄铜工单 |
| 商店 | 补给袋 | 氧化黄铜 | 物资票据与计价签 |
| 医务 | 医疗十字 | 医务绿 | 恢复签与药剂登记栏 |
| 宝藏 | 锁匣 | 安全黄 | 领取封签与封存编号 |
| 首领 | 封存尖塔 | 封存红 | 权限警示与塔心记录 |

## 3. 页面不变量

- 所有类型共享“左身份、右决策”的位置记忆，但标题、图标、语义色和材质文案必须随节点类型变化。
- 未抵达页必须同时有“进入节点”和“返回学院地图”；抵达未结算页必须有公开选项和“暂不结算，退出节点”；完成页只保留安全回访／整备入口与返回地图。
- 不用 AI 伪文字、背景插画或无来源发光承担信息；新增插画若未来确有需要，必须逐类型独立生产并从 `CONCEPT` 开始，不得从一张九宫格切图。

## 4. 验收

1. 九类节点图标均能由 `FormalArtRegistry.NodeTypePath` 严格加载，不允许 fallback。
2. continue／confirm／back／close 四类操作图标均能严格加载。
3. 1920×1080 与 960×540 下，节点图标、主要行动、成本／结果和退出按钮无裁切。
4. 灰阶下仍可凭布局、文字与轮廓区分操作；颜色不作为唯一状态信息。
