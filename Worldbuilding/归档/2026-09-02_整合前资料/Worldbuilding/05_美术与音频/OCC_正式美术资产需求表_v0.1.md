# OCC 正式美术资产需求表 v0.1

> 历史说明（2026-08-30）：本文保留首批正式资产的生产追溯，不再作为“当前缺口”清单。后续尚未完成、内容阻塞和试验生产需求统一以 `OCC_后续美术资产需求表_v0.1.md` 为准；不得把本文已完成条目重复列入新批次。
>
> 状态：生产规划基线，2026-08-07。  
> 目标：在批量生成或绘制前，冻结首批正式美术的范围、规格、依赖和验收口径。  
> 归属：战斗规则与基础表现为剧情/肉鸽共用；节点运营界面归肉鸽；角色立绘与剧情演出归剧情。  
> 不包含：音频、未批准双元素、未定义地区/阵营/命名 NPC，以及直接修改 Unity 或替换运行时资产。

## 1. 状态、优先级与硬规则

| 状态 | 含义 |
| --- | --- |
| `EXISTING_FORMAL` | 已有独立原料、像素 QA 和 Unity 导入记录；新制作前仍需同屏风格复核 |
| `BASELINE_APPROVED` | 已通过技术 QA 和产品目视审查，作为后续全部正式资产不可回退的生产基准 |
| `QA_PENDING` | 已有完整生产输出并通过自动/目视技术检查，等待产品审查后冻结为正式基准 |
| `NEEDS_PRODUCTION` | 玩法与用途已锁定，可进入身份卡、线稿或单图原料制作 |
| `NEEDS_REWORK` | 已有占位/复用资产，但不满足唯一轮廓、状态段或交付完整度 |
| `BLOCKED_CONTENT` | 内容身份尚未冻结；只可做风格探索，不得批量生产 |
| `CONCEPT_ONLY` | 只作构图、色彩或材质参考，不可切图或验收 |

| 优先级 | 用途 | 完成定义 |
| --- | --- | --- |
| `P0` | 正式战斗垂直切片 | 12×9 中继站、首区敌群、基础 HUD 和反馈完全脱离占位图 |
| `P1` | 肉鸽首区与火系内容 | 20 节点、11 种敌人（含 2 名首领）、火系 50 项术式和运营界面有唯一美术语义 |
| `P2` | 剧情与后续地区 | 角色身份卡、章节地点、地区包和后续元素内容冻结后启动 |

- 战斗基准 `1920×1080`：左战场 `1440×1080`（75%），右 HUD `480×1080`（25%）；另以 `960×540` 验证缩放。
- 地块、对象、图标为 `32×32`；单位为 `64×64`、中心线 `X=32`、脚底 `Y=58`；硬 alpha、Point、Clamp、无 mipmap、整数缩放。
- 单位采用近顶视三分之四角，保持 `64×64` 画布与 `X=32`/`Y=58`，但标准主体有效高度收束为约 `32–38 px`、精英/首领约 `38–44 px`，相对旧接触表平均缩小约 30%。正式朝向至少覆盖左右两个战术方向；明显非对称武器、徽记或伤势必须独立绘制；禁止在 Unity 中直接使用 `0.7` 非整数缩放。
- UI 使用黑/近黑/暖白或冷白的极简工业细线框架。冷青=可执行/友方以太，锈红=威胁/伤害，安全黄橙=交互/战利品。
- AI 结果只作独立原料，必须经过规范化、调色板、硬边界、1×/4×、灰阶和透明背景 QA；禁止从拼板或概念图硬切。
- 八元素为火、水、风、土、雷、冰、光、暗。以太须表现为可维护、可损坏的导管、线圈、容器或设备；禁止中世纪法袍、神圣金光和无来源漂浮符文。
