# OCC M-A33 港区与通用内容首轮生产简报 v0.1

> 状态：`IN PRODUCTION / NON-UNITY`，2026-08-30。  
> 授权：产品已批准 M-A32 T01–T12 全部方向进入生产。  
> 范围：18 件独立资产；港区地块 4、港区物件／结构 6、剧情语义 4、通用材料 4。

## 1. 应用环境与屏幕占位

- 港区地图资产服务未来 `12×9` 正交战场；地面每格原生 `32×32`，高度物使用俯视 3/4 投影，多格物严格使用 `(W×32)×(H×32)` 透明画布。
- 16px 语义图服务剧情对话／调查动作，只表达功能，不绘制完整物件或材质；在 UI 中仅按整数 `2×/4×` 显示。
- 材料拾取物保留原生 `24×24`，再以 `(4,4)` 无缩放嵌入 `32×32` 交付画布；只用于库存积累，不绑定尚未冻结的数值、配方或掉落表。
- 本批不导入 Unity，因此最高只形成非 Unity 审核资产；运行时 GUID、Importer 和正式地图接触不在本批伪造。

## 2. 共同美术方向

- 玩家一秒阅读：低技术学院港区由盐蚀石材、旧木、绳索、陶器、锻铁与少量旧铜构成；它是人工维护的港务空间，不是铁路货站、蒸汽工厂或科幻码头。
- 轮廓：地块先读成一块完整石板；设备先读碰撞体和人工操作部件；语义图先读一个动作；材料先读一种物质结构。
- 调色板：港区以灰褐石、旧木棕、炭黑铁和麻绳灰为主；黄铜只作小面积结构线索，冷青仅在真实主动以太存在时使用，本批港务设备不启用冷青。
- 光值：固定左上弱光，暗部服从体积；禁止柔光、环境投影、渐变、抗锯齿和随机单像素噪点。
- 密度：每件最多三个主形体、一个材料线索、一个受控功能点；不能靠碎屑和装饰填满画布。

## 4. 排除项

- 铁路、公共电网、连续流水线、电机、屏幕、LED、科幻电池、蒸汽朋克管线堆叠。
- 中世纪城堡门、港闸吊桥、神圣符号、无来源漂浮魔法、整屏冷青。
- 伪文字、数字、Logo、水印、完整 UI 面板、地面投影、柔边透明。
- 从拼板切图、把高分辨率插画直接缩小充数、用脚本几何补画主体。

## 5. 验收

1. 每件先有 `occ-art-manifest-v1` 和最终提示词，再独立生成。
2. 每件通过目标尺寸、硬 Alpha、色数和可见边界检查。
3. 每件生成 1×／4×／灰阶／棋盘格证据；各组再生成接触表。
4. 地面追加四变体并排与 `12×9` 铺设接触；物件追加 32px 地格与 64px 单位尺度接触。
5. 机器 PASS 只代表技术合格；本批新图仍需产品逐批审美，不自动进入 Unity。
