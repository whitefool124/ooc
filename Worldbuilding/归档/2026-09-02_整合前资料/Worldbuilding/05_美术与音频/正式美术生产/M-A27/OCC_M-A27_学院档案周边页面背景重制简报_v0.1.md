# OCC M-A27 学院档案周边页面背景重制简报 v0.1

## 应用环境与屏幕占位

- 运行时背景原生 `480×270`，在 1920×1080 与 960×540 分别以最近邻 `4×`／`2×` 全屏显示。
- 真实标题、正文、按钮、节点、背包格与数值全部由 UGUI 覆盖；背景不得承担信息，不得包含文字、按钮或完整 UI。
- 玩家一秒先读当前页面标题与主要行动；背景只负责区分页面气质，并以边缘叙事物和大面积安静纸面承托信息。

## 锁定方向

- **材质：** 暖纸、硬纸卡、布面档案夹、学院石材、旧木、锻铁、少量氧化黄铜。
- **构图：** 16:9 正视或轻俯视；中央 55% 保持低对比，叙事锚点分布于页脊、桌沿、远景或四角。
- **色彩：** 暖纸白／档案米／炭墨为主；黄铜、医务绿、封存红按页面职责少量使用；冷青仅表示真实激活的以太回路。
- **像素：** 原生 480×270，至多 24 色，硬边离散像素簇，无抗锯齿、渐变、柔光与随机噪点。

## 八张背景

| ID | 页面阅读 | 视觉锚点 |
|---|---|---|
| startup | 学院行动档案启动 | 合拢的布面卷宗、纸签与旧铜压条 |
| landing | 进入学院与本局入口 | 学院门廊、远处封存塔、晨光纸面 |
| map | 路线与节点决策 | 摊开的学院总图、木尺与登记夹 |
| briefing | 任务目标与风险 | 夹板上的空白调度纸、封存红边签 |
| inventory | 整备与物品管理 | 旧木工坊桌、布垫、锻铁夹具 |
| settlement | 本场结果归档 | 结算卷宗、印台、归档托盘 |
| archive | 历史与存档查阅 | 档案架、索引抽屉、翻开的登记簿 |
| settings | 选项与可访问性校准 | 校准卡、机械旋钮、灯光测试片 |

## 排除项

蓝黑整屏、冰蓝描边、扫描线、终端网格、全息 HUD、雷达、示波器、科幻控制台、齿轮管线堆叠、中世纪卷轴卷边、蜡封滥用、神圣金光、人物、文字、数字、按钮、图标槽、完整 UI 截图、水印。

## QA

每项先建 `occ-art-manifest-v1`；检查 1×／2×／4×、灰阶、完全不透明硬 Alpha、≤24 色、稳定 GUID、Importer、Resources、1920×1080／960×540 实际页面接触与人工审美，最后才晋级 `FORMAL`。
