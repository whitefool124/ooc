# OCC M-A18 P0 样张分镜与审核表 v0.1

**用途：** 锁定学院战斗地块、敌人动作与首发火系 VFX 的正式生产语言。此表是出图与评审依据，不代表任何资产已经生成、通过 QA 或接入 Unity。

## 1. P0 交付边界

| 样张 | 交付物 | 验证问题 |
| --- | --- | --- |
| `academy_courtyard_a` | 1 张独立 32×32 地块；1×、4×、四向平铺接触表 | 不靠标签能否读成学院石庭；四边是否无接缝；是否误读成工业钢板或室内瓷砖 |
| `core_overseer` | 1 张独立 64×64 静帧；1×、4×、灰阶、轮廓、锚点图 | 是否比先锋更具首领体量；封印锤与背负护障匣是否同时可读 |
| `purifier_overseer` | 1 张独立 64×64 静帧；同上 | 是否读成净化／维护型首领；是否避开神官、现代防化服和喷火兵轮廓 |
| 三种敌人标志动作 | 每种 6 张独立 64×64 帧；动画 GIF 与锚点叠帧图 | 人形重击、人形支援、四足扑击能否共用同一时长而保持身份和脚底稳定 |
| `fire_cast` | 6 张独立 32×32 帧；动画 GIF 与四背景叠加图 | 是否明确读成“受控起手”，且不误读成命中、爆炸或燃烧地面 |

禁止把接触表、GIF 或拼板切割为正式帧。所有正式帧必须独立生产并经过硬 Alpha、尺寸、色数和锚点检查。

## 2. 地块样张构图

### `academy_courtyard_a`

- 三块大石板承担主形，灰浆缝只占一至两像素宽；仅允许一个小型手工补角作为叙事细节。
- 四边接缝必须延续，旋转或平铺后不得出现十字黑缝、孤立亮边和重复污点。
- 明度落在战场背景档，角色脚部、选格线、伤害数字与火芯在其上必须保持更高对比。
- 不加入校徽、文字、散落工具、草丛、发光刻阵或投影；这些属于其他变体或独立叠加资产。

## 3. 敌人静帧审核点

### `core_overseer`

- 轮廓顺序：宽肩石甲 > 双手封印锤 > 背部分体护障匣 > 人脸。
- 左右不对称来自维修与职责，不来自随机尖刺；锈红只作敌方监管束带，冷青只在护障匣内部。
- 透明画布 64×64；身体中心 `X=29–35`，脚底 `Y=57–59`，有效高度目标 42–44 px。

### `purifier_overseer`

- 轮廓顺序：高位净化杖 > 半圆铜导架 > 侧挂滤瓶 > 人脸。
- 灰白是耐热维护外衣，不得形成圣职长袍或医疗白大褂；玻璃瓶必须有硬质支架保护。
- 与 `pyromancer` 区分：体态更稳定、导架更宽、火焰色不是主识别色；与 `core_overseer` 区分：窄体态、竖向工具、无重锤。

## 4. 三种敌人动作六帧分镜

所有动作暂按 `6 × 0.07s = 0.42s` 评审。若后续玩法需要更长前摇或停顿，由运行时重用帧或调整时长，不在本批复制近似帧凑节奏。

### `sigil_mauler_signature`

| 帧 | 动作 | 必须保留 |
| ---: | --- | --- |
| 00 | 常态压低重心，锤头靠后 | 脚底、面向与静帧一致 |
| 01 | 双手提锤，锤首暗红刻印点亮 | 火光不越过头肩 |
| 02 | 锤头达到最高点，躯干后仰一格感 | 双脚仍着地，不漂浮 |
| 03 | 向目标方向重砸，锤首先触地 | 最大轮廓帧；不可像挥剑 |
| 04 | 地面出现短促红热裂纹，人物承受回震 | 裂纹只作动作附属，不替代独立 VFX |
| 05 | 锤头回收，刻印熄暗 | 回到可无缝接常态的位置 |

### `barrier_mender_signature`

| 帧 | 动作 | 必须保留 |
| ---: | --- | --- |
| 00 | 常态持杖，线轴收拢 | 杖、符片、线轴三者可辨 |
| 01 | 空手抽出一张硬边符片 | 不增加第二根法杖 |
| 02 | 符片接上线轴，冷青细线建立 | 冷青面积受控，不画大光环 |
| 03 | 杖端朝友军方向送出方形护障脉冲 | 方向明确，不像攻击弹体 |
| 04 | 线轴回卷，符片失光 | 脉冲离体但不占满画布 |
| 05 | 恢复常态，保留一像素余热 | 脚底与中心不得跳动 |

### `tether_hound_signature`

| 帧 | 动作 | 必须保留 |
| ---: | --- | --- |
| 00 | 四足常态，头部朝目标 | 项圈与缚环清晰 |
| 01 | 前肢压低、后腿蓄力 | 脊线收紧，不拉长身体 |
| 02 | 向前扑出，前肢离地 | 身体允许前移，脚底参考线仍标注 |
| 03 | 咬合／缚环达到最前端 | 最大前伸帧；不能出现机械爪 |
| 04 | 前肢落地、环带收紧 | 保持生物重量感，无烟尘团遮挡 |
| 05 | 后腿跟进并回常态 | 可无缝衔接静帧 |

## 5. `fire_cast` 六帧分镜

| 帧 | 火芯状态 | 占用范围 | 禁止误读 |
| ---: | --- | ---: | --- |
| 00 | 2–3 个暗红余烬向中心靠拢 | 6×6 | 燃烧地面 |
| 01 | 橙色内弯火钩形成导向轴 | 10×10 | 圆形法阵 |
| 02 | 中心出现小型热黄火芯 | 14×14 | 命中闪光 |
| 03 | 黄白火芯达到峰值，两侧火钩收束 | 18×18 | 全格爆炸 |
| 04 | 火芯沿施术方向压成短梭形 | 15×12 | 已离体投射物 |
| 05 | 中心释放，只余三处暗红余烬 | 8×8 | 常驻火场 |

每帧透明 32×32、最多 12 个可见 RGB 色、二值 Alpha。必须分别叠加在浅石地、深色废墟、友方单位和伤害数字下检查：单位脸部、脚底、选格边界与数字均不可被大面积火光吞没。

## 6. P0 放行门槛

| 检查 | PASS 条件 |
| --- | --- |
| 时代与世界观 | 无铁路、枪械、现代机械接口、电子屏、现代防化服、无来源法阵或中世纪宗教符号 |
| 一秒语义 | 五类样张在 1× 下不看文件名仍可被正确归类 |
| 像素技术 | 尺寸正确、无半透明、无抗锯齿、无渐变和随机单像素噪声；色数不超预算 |
| 动作稳定 | 敌人中心线与脚底无无意抖动；主装备没有逐帧变形或换手 |
| 战场遮挡 | 地块低对比；VFX 不遮单位、选格、路线和数值；首领透明边界不侵占相邻格的点击判读 |
| 系列可扩展 | 样张能自然扩展到 48 张地块、12 组敌人动作和 14 组火系模块，无需推翻形状／材质／调色板合同 |

任一项 `FAIL` 时只返修对应资产族，不得用后期缩小、模糊、自动减色或统一染色掩盖结构问题。
