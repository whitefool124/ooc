# OCC M-A18 学院庭院主地块返工简报 v0.2

**状态：RUNTIME_COMPLETE（2026-08-21，无痕原生 32×32 v07）。** 当前战斗画面直接消费的 `academy_courtyard_a/b/c/d` 已定稿为原生 `32×32` 低密度学院方石；石面无矿物斑、磨痕、旧修补或污渍，格界只来自贴图下沿／右沿的低对比铺装接缝。原生 24×24 v06 已结束实装并归档，正式尺寸与 `64/96/128/160` 格宽重新形成 `2×/3×/4×/5×` 整数倍率。

## 1. 玩家阅读目标

- 一秒内先读为“学院庭院的可行走石质地面”，再读出每格占地范围。
- 每个战斗格对应一块完整的学院铺地模块，而不是在一格内部再画多块板材；格界必须属于这块铺地模块本身，由浅灰缝、轻微倒角和离散明暗形成，不得像 UI 网格、棋盘墨线或覆盖在画面上的矢量框。
- A／B／C／D 是同一处庭院的铺法变化，不是四种不同材质；随机铺设时不得形成明暗棋盘。

## 2. 锁定美术方向

采用“学院旧庭院的手工切石”：近代前工业学院长期维护的暖灰石灰岩／板岩，石块规整但不机械完美，局部有补缝、磨损和轻微色差。整体克制、低饱和，不使用铁路、现代混凝土标线、金属甲板、电路板、霓虹或中世纪符文。

### 材质与色板

- 逻辑画布 `16×16`，正交俯视，完全不透明；最近邻 `2×` 输出到运行时 `32×32` 交付画布。
- 全族共用 5–7 个离散颜色：深灰缝、暗面、中灰基底、暖灰石面、浅色磨边，可选一个低饱和棕灰修补色。
- 大面积基底保持中低对比；最深色只用于短灰缝和局部凹口，不得沿四边连续围成近黑方框。
- 每格内部至少 75% 保持安静连续石面；单张最多一个旧修补点和一个轻磨损／缺口。禁止圆斑、对称脸谱、徽记式色块和为了“丰富”而添加的碎纹理。
- 禁止平滑渐变、半透明、抗锯齿、柔光、投影、环境泛光与随机单像素噪点。

### 原生边缘合同

- 每边的接触结构必须在独立源稿中直接画出，再由纯技术规范化保留下来；禁止规范化脚本补画、扩边或生成格界。
- 每边通过 1–2 像素的阶梯式石条／灰缝结构读出接触界面；允许亮倒角与暗灰缝交替，禁止近黑单色直线贯穿整条边。
- 四角使用错位石块或断续灰缝收口，避免形成锐利 UI 矩形。
- 相邻两格接触后应形成一条自然石缝或双石条接缝；在 1× 下可辨，在 4× 下仍是清楚像素簇。
- 临时选中、移动、攻击与敌人意图仍由语义覆盖层承担；地块本身不烘焙冷青、锈红或安全黄状态色。

## 3. 四个独立变体

| ID | 大形设计 | 允许的小差异 | 禁止事项 |

| `academy_courtyard_a` | 一块完整暖灰石质铺地模块 | 左上轻磨边 | 亮度显著高于其余变体 |

## 4. 交付与验收

- 正式输出保持现有稳定路径与 ID：`UnityProject/Assets/Game/Resources/Art/FormalAcademyCombat32/academy_courtyard_[a-d].png`。
- 原始生成稿、规范化中间稿、色板、统计报告、四张接触表与 `12×9` 平铺模拟保存在 M-A18 本轮返工目录，禁止把未经 QA 的原图直接导入 Unity；规范化脚本不得新增美术结构。
- 自动门禁：尺寸严格 `32×32`、RGBA／硬 Alpha、全不透明、色数 5–7、无重复哈希；四张平均明度最大差建议不超过 `10`。
- 人工门禁：1× 能分格但不读成描边；4× 无抗锯齿和碎噪；四变体随机平铺不出现棋盘、粗十字、重复长线或明显亮暗斑块；单位与范围覆盖层仍优先于地面细节。
- Unity 门禁：Sprite、Point、Clamp、无 mipmap、无压缩；编译与 Console 无新增异常，活动场景保持 `dirty=false`。除非另有明确授权，本轮不保存场景、不进入 Play Mode。

## 5. 失败判定

出现以下任一项即退回 `REWORK`：仅 2–3 色；依靠一两根贯穿直线表示石板；四边连续近黑框；A／B／C／D 平均明度明显跳变；生成图缩小后产生抗锯齿或糊边；用运行时描线、统一染色或后处理掩盖贴图问题。
