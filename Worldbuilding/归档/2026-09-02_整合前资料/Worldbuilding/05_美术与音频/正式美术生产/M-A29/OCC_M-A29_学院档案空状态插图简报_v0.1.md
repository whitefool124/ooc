# OCC M-A29 学院档案空状态插图简报 v0.1

> 从属 `OCC_美术规范_v0.1.md`；总规范与机器合同优先。本批只生产透明 UI 表现层，不改变任何空状态判定。

## 目标与边界

- 六件独立、可跨页面复用的 `64×64` 空状态器物：空档案托盘、空补给袋、闭合测绘筒、空奖励浅箱、空器材挂架、封存文书袋。
- 固定左上光；暖纸、旧木、锻铁、灰绿布为主，少量旧铜作结构点，封存红只用于约束带。
- 不使用蓝晶、通用冷青能量、霓虹、文字、数字、徽章、按钮、槽位底板、柔光、渐变、蒸汽朋克齿轮或中世纪卷轴卷边。
- 每件必须单独调用 Codex 内建 imagegen；禁止拼板切图、本地生图工作台、localhost、私有 relay 与自动回退。

## 资产表

| ID | 器物语义 | 推荐接触 |
|---|---|---|
| `empty_archive_tray` | 空档案归还托盘 | 暂无行动记录／章节留白 |
| `empty_inventory_pouch` | 摊开的空学院补给袋 | 空库存／未装入 |
| `empty_route_case` | 闭合测绘筒与素木定位钉 | 路线未开放／暂无地图记录 |

| `empty_loadout_rack` | 空锻铁器材挂架 | 空装备／术式槽 |
| `locked_document_satchel` | 灰绿布文书袋与封存红约束带 | 未解锁／封存章节 |

## 交付门禁

- 原生 `64×64`、硬 Alpha、≤12 色、四边 ≥2px 透明安全边，PPU32、Point、Clamp、无 Mipmap、无压缩。
- 每项先有 `occ-art-manifest-v1`，再生成 source；通过 1×／4×／灰阶／棋盘格、实际 1920×1080／960×540 接触、人工审美、稳定 GUID、Importer 与 Resources 后才可晋级 `FORMAL`。
- 只接到既有空／锁定分支；有内容时隐藏。不得改变玩法、数值、地图、存档、页面结构或交互条件。
