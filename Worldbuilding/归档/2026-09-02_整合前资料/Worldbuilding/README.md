# OCC

`OCC` 是“魔法战争人生战棋肉鸽”的项目代号。本项目基于“以太”世界观的以太素、近代魔法文明与战争设定开发；游戏策划、技术和制作资料在此目录内独立维护。

## 目录

| 目录 | 用途 |
| --- | --- |
| `00_项目管理` | 项目入口、调查、会议结论、风险与版本记录 |
| `01_游戏策划` | 核心玩法、战斗、战区、角色、敌人和内容策划 |
| `02_技术方案` | 引擎、架构、存档、数据结构和原型技术方案 |
| `03_开发管理` | 开发计划、里程碑、任务拆分和测试记录 |
| `04_数据设计` | 技能、物品、单位、任务、数值和掉落的配置源 |
| `05_美术与音频` | 视觉规范、像素资产、UI、音频和特效资料 |
| `06_构建与发布` | 构建、版本、发布、反馈和兼容性资料 |

## 维护规则

- 世界观底层设定以 `00_项目管理/以太_世界观与魔法体系圣经_v0.1.md` 为 OCC 的游戏使用基准；新增玩法不可绕过其中的以太素、元素与战争硬规则。
- 游戏规则、数值和实现选择优先写入 OCC，不反向污染世界观总纲。
- 完成重要设计决策时，先更新策划案，再同步技术规划、数据设计或开发计划。
