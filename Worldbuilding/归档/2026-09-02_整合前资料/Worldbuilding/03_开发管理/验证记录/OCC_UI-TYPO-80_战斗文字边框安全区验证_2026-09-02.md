# OCC UI-TYPO-80 战斗文字边框安全区验证

- 日期：2026-09-02
- 归属：剧情／肉鸽共用战斗 UI 表现层
- 场景：`Assets/Scenes/CombatPrototype.unity`
- Unity 工程：`E:/数据库/OCC_Codex/UnityProject`

## 问题与根因

右侧“接下来”原先每个 38px 行槽都重复套用 6px 厚像素框，24px 中文字形虽然没有触发 RectTransform 裁切，但底部字形与深色框线之间实际净距为 0px，视觉上等同于被边框压住。英雄模块的行动点最右一格也越过 12px 框内安全边界 4px。

## 实装

- `FormalUiKit` 新增边框文字合同：6px 框厚、6px 框内净距、12px 内容内缩；24px 完整框单行高度至少 48px。
- 行动序列保留模块外框，五个条目改为无厚框浅色行面，并用 2px 底部分隔线建立节奏。
- 行动名称和生命／行动状态分列；过长名称在 7 个显示字符后省略，避免侵入右侧摘要。
- “接下来”“刚刚发生”及底部指令组标题统一下移到 12px 顶部安全边。
- 右侧控制台增高至 840px、行动序列模块增高至 270px，现场记录顺延，五行条目完整容纳。
- 行动点三格起点由 342px 左移到 338px，最右端为 404px，等于 416px 模块宽度减 12px 安全内缩。
- 美术合同及学院档案 UI 规范同步记录上述规则。
