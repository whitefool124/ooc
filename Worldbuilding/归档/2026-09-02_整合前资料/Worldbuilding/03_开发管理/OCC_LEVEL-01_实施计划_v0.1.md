# OCC LEVEL-01 首区关卡系统实施计划 v0.1

## 任务合同

- **归属：** 剧情/肉鸽共用战斗关卡运行时；本轮接入肉鸽首区九个战斗节点。
- **目标：** 把“同一场景 Marker + 不同敌人名单”升级为九张数据驱动的 12×9 手工关卡，并让已完成的十敌人扩展包在关卡中以精确位置、地形、目标、AI、能力和正式表现真实运行。
- **涉及系统：** 关卡定义/目录/构建器、战斗 Bootstrap、旧遭遇兼容层、肉鸽节点显示与任务摘要、敌人目录/技能/AI/美术注册、EditMode/PlayMode 与 Funplay 视觉回归。
- **验收标准：** 九关唯一布局和稳定 ID；十敌人全覆盖；地图/目标/出生位合同有效；旧遭遇由关卡派生；活跃内容无现代枪械、狙击、铁路或现代爆破语义；全量测试、编译、Console、1920×1080/960×540、场景 clean。
- **完成后解锁：** 独立选关入口、关卡变体/随机地形层和第二地区关卡包。

## 执行顺序

1. 冻结《OCC 首区关卡系统 v0.1》及九关布局/时代边界。
2. 实现强类型关卡合同、目录校验和 `GridMap/UnitState/CombatObjective` 构建器。
3. 改造 Bootstrap：首区战斗从关卡构建，非目录演练才回退场景 Marker；旧遭遇列表改为关卡派生。
4. 更新玩家可见节点名与任务摘要，保留稳定旧 ID 兼容现有存档。
5. 补目录、布局、目标、十敌人覆盖、动态首领、年代禁词和运行时闭环测试。
6. Funplay 重新编译，跑全量 EditMode/必要 PlayMode、Console、九关运行时巡检及双分辨率实战；确认场景 clean。
7. 更新实现矩阵、验证记录和当前待办，记录真实阻塞（如有）。
