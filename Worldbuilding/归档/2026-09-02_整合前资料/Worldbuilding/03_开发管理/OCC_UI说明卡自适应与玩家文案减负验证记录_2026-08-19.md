# OCC UI 说明卡自适应与玩家文案减负验证记录（2026-08-19）

## 结论

本轮修复通过。共享悬浮说明不再使用统一大尺寸，而是按当前标题与正文自适应；现有地图、战斗和整备说明已删除重复话术并清除已发现的内部 ID。没有改变玩法、数值、节点拓扑、输入、存档或场景资产。

## 问题与根因

- `FormalHoverTooltip` 固定宽度为 `540`、最低高度为 `142`，一句短说明与多行说明占用相同大宽度。
- “完整现场记录”把整个事件列表塞进悬浮层；若信息较多会持续扩大遮挡。
- 肉鸽战术栏直接把 `DefinitionId` 当标题；装备说明直接拼接 `MutableAffixIds`、`FixedEffectIds` 和 `UpgradeBranchIds`，向玩家暴露 `AFF-*`、`turn_start_shield`、`node1:*` 等开发标识。
- 首轮真实运行发现响应字体为 `23px`，旧标题槽只有 `28px`，其实际首选高度为 `31px`；自适应缩小后整行标题会被 Unity 截断。

## 实现结果

- 说明卡参考画布范围固定为宽 `220–480`、高 `100–360`，先测量自然文字宽度，再按最终宽度重新计算换行高度。
- 标题槽提高到 `34px`，正文从 `Y=50` 开始；标题、正文和底部留白共同参与高度计算。
- 地图状态、地图缩放／定位、详情展开、未知节点、回访和结束行动说明改为直接的玩家语言。
- 状态图例不再重复显示“地图节点状态”，而是说明“你现在所在的节点”“可从当前位置前往”等实际含义。
- 现场记录只显示最近 5 条；英雄最近护盾记录只显示 2 条。
- 战术栏使用正式道具名，正文只显示剩余次数和行动点消耗。
- 装备词条使用目录中的 `DisplayName`；固定效果和校准分支通过玩家文案映射显示。未知 ID 只显示“未知词条／特殊效果”，不回退显示内部 ID。

## 测试先行证据

实现前聚焦测试为 `25/27 passed`，两项稳定失败：

- 短说明与长说明宽度均为 `540`；
- 装备说明实际显示 `词条：AFF-ROUND-SHIELD-P`，未显示“紫色回合盾”。

实现后新增合同覆盖：

- 短卡小于长卡且不超过最大宽高；
- 标题实际生成文字顶点，不能因高度不足整行消失；
- 悬浮装备说明不含 `AFF-*`；
- 装备详情的固定效果、词条和校准分支均为中文玩家文案，不含原始 ID。
