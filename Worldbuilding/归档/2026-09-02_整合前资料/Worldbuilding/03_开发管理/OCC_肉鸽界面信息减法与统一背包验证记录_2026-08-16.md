# OCC 肉鸽界面信息减法与统一背包验证记录（2026-08-16）

## 1. 范围与结论

本轮只调整 `rogue11` 的地图、战前、战斗 HUD、战外整备和战斗内背包表现／交互，不改变伤害公式、两货币、阶段结构、装备自由叠盾或剧情模式旧语义。结论：`ROG-UX-DENSITY-01` 完成，无待产品决定的结构性阻塞。

## 2. 信息减法

- 未侦测地图节点只显示 `?` 状态块；完整含义由悬浮提示解释，已识别节点才显示短名、类型、时间和状态。
- 节点详情与战前简报用风险、时间、生命恢复、个人魔力恢复、阈值／奖励图标取代常驻段落，失败后果和完整规则放入悬浮层。
- 战斗 HUD 的主动单位、武器和战术栏使用短名／次数／按钮态；战斗日志常驻只保留最近两条，完整日志悬停可读。
- 背包物品格只显示物品图标；战术道具额外显示剩余次数。名称、占格、品质、重量、以太负载和效果统一在选中详情或悬浮层读取。

## 3. 统一背包合同与交互

- 地图整备与战斗内背包均使用 `RogueInventoryPresentation`，消费同一个 `RogueEquipmentRuntime` 6×10 权威坐标合同。
- 两处界面均展示 11 个装备槽、6×10 网格、选中详情和 4 格战术快捷栏；战斗中装备槽明确锁定，战外允许装备／卸装。
- `MoveBackpack`、`RotateBackpack` 和新增的 `CanMoveBackpack` 共用碰撞／越界判定；非法移动不改原坐标。战斗内拖放预览直接调用同一权威判定，不再仅检查边界。
- 支持鼠标选中／拖放／右键旋转预览，以及方向键选择、`R` 旋转、`1–4` 关联战术栏；成功与拒绝均有明确反馈。
- 正式战斗快捷栏可从 `RogueEquipmentRuntime.ItemQuickbarInstanceIds` 装载 G‑T 战术道具，进入既有合法目标预览／执行链并扣减该肉鸽实例自身次数；不读取旧 8 格快捷栏实例。

## 7. ROG-UX-REGRESSION-02 回归修复补充

### 7.1 整备空快捷栏

- 根因：旧档／缺省 DTO 的四个快捷栏元素可为 `null`，`AssignQuickbar` 在清空语义之前调用 `Dictionary.ContainsKey(null)`。
- 修复：运行时构造时将四格初始化为 `string.Empty`；读取 DTO 时把 null／空值视为清空操作，并保证只有非空实例 ID 才进入装备／道具字典查询。
- 证据：新增 null 快捷栏迁移与主动清空测试；运行态从现有存档进入战外整备，Console 无 `ArgumentNullException`。截图：`Temp/OCC_UX_regression_loadout_recheck.png`。

### 7.2 战斗背包旋转单一预览

- 根因：拖拽时同时绘制了原格半透明物体和鼠标预览，旋转后被感知为两个物体。
- 修复：拖拽实例的源格完全停止绘制；键盘 `R` 和拖拽中右键仅切换 `rogueDragRotated` 预览，放置时才通过 `MoveBackpack` 权威提交，非法位置保持原位。
- 证据：新增拖拽源隐藏表现合同测试；运行态分别复核 1×3 与旋转 3×1，仅出现一个预览轮廓。截图：`Temp/OCC_UX_rotation_single_ghost_verified.png`、`Temp/OCC_UX_rotation_single_rotated_ghost_verified.png`。

### 7.3 术式信息减负与玩家文案

- 8 个 138×40 常驻术式按钮不再塞入长名称、AP、魔力和冷却全文，只保留槽号、图标、成本与按钮状态；选中动作摘要字号提高并增加可用高度。
- 悬浮详情宽度调整为 540，标题／正文分别为 20／16 px；正文限制为可用性、消耗、目标、效果及少量必要风险，通常四行、最多七行。
- 四基础术式与火系术式的目标／效果通过玩家文案映射输出，不再直接展示 `Targeting`／`Rules` 内部 ID。实机“灼触”详情为：`可用`、`1 行动 + 1 个人魔力`、`相邻可见敌人`、`造成 8 点近战伤害`。截图：`Temp/OCC_UX_regression_combat_tooltip_recheck.png`。

- 处理器实现 `PointerDown / Drag / PointerUp` 主链，适配触控板短拖；标准 `BeginDrag / EndDrag` 仍作为兼容路径。拖拽源隐藏，仅显示一个合法性着色预览，松开调用正式宿主的权威移动接口。
