# OCC 学院战场应用环境优先像素重制验证（2026-08-23）

## 1. 产品决定与范围

- 资产尺寸和像素规格先由应用环境决定：先确认实机镜头、逻辑格、最终屏幕像素、角色／物件职责、遮挡关系和一秒阅读距离，再反推源画布、有效轮廓与透明边界。
- OCC 不再使用本地生图工作台、localhost 生图 API 或私有 relay。正式场地物使用批准的直接图像生成渠道；规范化脚本只做去背、整轮廓最近邻定尺寸、硬 Alpha、限色和 QA，不绘制正式结构。
- 风格保持质朴、偏西幻魔法侧，以暖灰石、旧木、锻铁、陶土、羊皮纸、粗绳和少量旧铜为主；冷青只作工作中的细小以太刻痕。
- 本次只改表现和资产，不改变战斗格、碰撞、地图拓扑、出生、数值、输入或存档。
