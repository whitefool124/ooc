## 唯一允许的特效几何

- 图片纸板：真实厚度1/32m，前后图片面与Alpha轮廓侧壁；原生贴图统一32PPU。不靠任意加厚或非等比缩放塑形。
- 长柱：截面1/32m×1/32m；世界UV固定，沿原生高度裁显，不拉伸纹素。
- 正方体粒子：三个边均1/32m，位移与发光可变，尺寸不变。

当前实际清单：4张静态法阵纸板、2个原生Particle System（烟尘Mesh粒子复用一像素厚纸板）、5根长柱、12个立方粒子。烟尘不再由手写位置动画移动固定纸板。场景建筑与角色不属于特效几何；验证记录完整扫描其余渲染器，防止遗漏其他特效形状。

## 生产与运动

完整法阵组件来自独立内置生图套件，位于ArtSource/SkyFurnaceCardsClean_20261015；用户指定以生图指导审美，再制作纸板，保留裁切／网格处理与精修记录，不冒充无损原料解码。外环160×160对应5m，符印128×128对应4m，中心96×96对应3m，施法印64×64对应2m。源内12色、硬Alpha、安全边；Point、无Mip、无压缩。当前需CPU读取Alpha生成厚纸板轮廓，Importer保留readable。

法阵完整轮廓先出现，再按不透明像素的连通距离逐像素通电。原生RFloat计时图使用Point采样，每个源纹素独立进入HDR发光，未激活部分保留暗色完整轮廓；该计时图是技术数据，不是新美术。两盏复用小灯跟随前沿，整层接通后退出。蓄力阶段旋转加速，贯穿前短暂停稳，释放后依次熄灭；无动画缩放。受光、真实场景阴影与局部火光保留，主镜头固定，16秒，无地形破坏、音乐或音效。

## 实现与验证

- SkyFurnaceDirector.cs：三类几何创建、播放控制、真实尺寸与未分类渲染器检查。
- PixelIgnitionMap.cs：逐纹素连通距离、点亮数量与前沿位置。
- SkyFurnaceSmokeParticles.cs：贴地扩散与上升烟缕，原生发射／速度／噪声／透明度生命周期；固定尺寸、固定随机种子、暂停与重置同步。
- PixelEffectCard.cs：固定一像素厚图片，Alpha边界侧壁。
- SkyFurnacePixelLayer.shader：纸板受光、完整图形上的纹素通电和发光；CullBack防止前后面重复叠亮。
- Hd2DVfxVoxelSurface.shader：仅供长柱／立方体的原生世界UV材质使用，不代表仍创建体素炉体。
- SkyFurnaceAuthoring.cs／Verification.cs／PlayerProbe.cs：后台捕获、全段播放与控制、几何合同、无声及资源回收检查。

当前证据位于Worldbuilding/归档/2026-10-15_天穹熔炉光影编排。仅验证独立演出，不证明正式战斗接入、整场景人工审美或性能基线；状态保持QA_PENDING。
