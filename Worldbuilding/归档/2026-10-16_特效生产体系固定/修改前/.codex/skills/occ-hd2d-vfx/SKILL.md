# OCC HD-2D 光影与特效

把像素主体、立体场景、真实受光和有节奏的空间特效组合成华丽且能操作的战棋体验。用户在2026-10-09明确要求提高光影与特效技术水平、追求帅气与华丽；可以采用强烈的局部峰值，不把历史 UI 小细节的弱光参数推广为战斗特效上限。

- 术式、攻击、爆发、轨迹、烟尘、环境反馈：读 [特效制作谱](references/effect-recipes.md)。
- 像素轮廓运动、烟尘序列帧、法阵通电和纸板动画：读 [像素动画与特效美术](references/pixel-animation-art.md)，先判断缺的是形态、节奏还是引擎实现。
- 播放编排、池化、世界坐标、质量档位与验收：读 [接入与验证](references/integration-validation.md)。
- 选技能、核对技术来源和现状证据：读 [来源与技能分工](references/sources.md)。

产品口径来自总案第5章、A.2.2、A.3、A.5–A.8及受影响数据表；具体表现接线同时使用相邻技能 [occ-pixel-vfx](../occ-pixel-vfx/SKILL.md)。技术方案和推荐数值留在技能内；改变玩法、正式资产规格、演出时长或总案制作口径时，按仓库规则先处理母版，不能把技能变成并列产品策划源。

## 决策要点

- 天穹熔炉局部制作修正（2026-10-16）：只有法阵和核心魔法表现使用图片纸板；冲击、喷射、火星、烟尘改用无贴图一像素长柱/立方粒子，烟尘由原生Particle System驱动。Image鼓励用于审美参考。该限制不扩展至环境或角色；旧烟片与纹素材质贴图只留追溯。

- 天穹熔炉样板的最新用户修正（2026-10-15）：移除天空体素炉体；当前特效几何仅允许一像素厚图片、一像素粗长柱、一像素正方体粒子。按场景像素间距核对真实世界厚度、截面和粒子尺寸，不用球、八面体、粗火流或立体火冠替代；这不要求删除环境模型。生图负责审美与分层设计，纸板以完整部件制作和精修，不能硬切符印制造碎边。旧体素生产记录只供追溯。

- HD-2D是3D Universal Renderer中的像素面片，不因为主体是2D就改用Light2D。地面范围／环／水纹水平放置，单位效果跟随视觉足点；可见面片、直立阴影代理及深度修正遵守庭院样板口径。
- 华丽来自明确的主形、轨迹、速度变化、瞬态亮暗和环境响应。起手收束、投递拉长、接触压缩、命中展开、余波稀疏；同一峰值只保留一个主形，不靠全屏白光或无限粒子数量。
- 优先用现有Particle System、网格／带状轨迹、URP HLSL或Shader Graph组合。VFX Graph是可选扩展，先核对已安装包、图形API与目标硬件；不因准备体系自动升级引擎、切HDRP或安装收费资产。
- 新效果只消费真实结算与动作播放时点。保留普通攻击约160ms、普通技能约180ms、火术起手120ms和每段180ms；把特效曲线放进现有窗口，不能为了蓄力演出自行增加等待、全局慢动作或改结算。
- 护盾本体、盾罩、盾边、盾折射及碎盾仍按现有用户约定排除；当前华丽目标不自动撤销具体否决。护盾图标、数值及真实承伤反馈保留。
- 粒子轮廓可以硬Alpha、Point采样和分段颜色；场景光、Bloom、景深与空间烟雾可连续变化。不要把高清输出强制降到320×180，也不要以柔化像素主体换取“高清”。
- Shader程序几何属于运行时技术。新火焰／烟尘／符文／碎屑贴图仍走内置生图、manifest和正式资产审核；不能把程序纹理称为独立生图。

## 交付与后续制作

每轮先做一个真实流程成立的代表样板，再扩展同族。优先从现有可执行的火术中选择“飞行→命中→实际地形或物件结果”的完整链；只有结算真实产生火场才出现持续火场，没有破坏就不播碎墙。光源、粒子、材质、回调、RT和声音随效果或页面正确回收。

汇报分开说明：技术准备、已接入、实机验证、人工审美。2026-10-09这次交付为技能与技术体系准备，参考中的方案与预算未成为运行时实现或实测成绩。后续验收使用正式游戏入口、同一相机、实际结算、连续运动和关闭动画；示例场不能代替实战。


## 2026-10-15 特效尺度例外

特效例外（用户确认，2026-10-15）：像素特效允许不同像素大小，不受本条统一像素密度要求限制，但不得尺寸失调，必须对照角色、技能范围与场景记录单片及整体运动的世界尺寸并在实际镜头复核；该例外不适用于角色、地块、场景物件与功能图标。密度清单中用role: pixel_vfx标识该例外，记录world_scale_basis和actual_motion_bounds；不得给角色或场景资产错误标注该角色来绕过统一密度。当前特效仍以一像素厚图片、一像素粗长柱、一像素立方粒子为几何限制，像素的世界尺寸按所用特效资产登记。
