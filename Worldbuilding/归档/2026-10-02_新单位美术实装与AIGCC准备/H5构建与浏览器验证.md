## 正常浏览器流程

Microsoft Edge／Chromium，通过 Playwright 的独立持久浏览器档案，在 1920×1080、WebGL2 软件渲染下执行真实鼠标操作；不注入游戏状态或调用游戏内部方法。测试存档为该浏览器站点的 03，不写入 Windows／编辑器存档。

1. HTTP 首页 → 点击开始 → Unity 载入 → 品牌阶段 → 首启设置。
2. 应用并确认默认设置 → 45 秒开场视频正常显示并自然结束 → 主界面。
3. 新建档案 → 空白 03 → 确认 → 新主角立绘 → 以此角色开始 → 学院介绍 → 地图。
4. 正常 B1 节点 → 摘要 → 出发 → 战斗。
5. 点击火花及寻迹兽：生命 12→6，魔力 12→10，行动点 3→2；单位和场地正常显示。
6. 暂离保存 → 刷新网页 → 再次点击开始 → 主界面显示档案 03“固定教程／战斗进行中” → 继续该档。
7. 返回 B1 后显示恢复提示，寻迹兽 6/12、主角魔力 10/12、行动点 2/3，与刷新前一致。

证据位于本目录 evidence/web/。首次测试的 favicon 404 已补相对图标；刷新后无新增资源请求错误或 JS pageerror。开启自动存档同步后不再新增手动同步弃用提示。仍有不支持 FSR Upscaling shader 的提示（后处理不执行），以及截图读回导致的软件 GPU 性能警告；本轮没有据此修改整个 URP 配置。实际主流程画面与输入通过。
