# 工坊夹具校准样板

范围：两者共用的学院工坊表现，已接入现有“装备锻造／术式专精”目标位。无新增玩法、费用或装饰文字。下一项为原计划中的医务室热饮蒸汽，本轮未展开。

实际体验：目标位内固定工作台；点击下方目标卡后夹口定位并收拢；`ExecuteFirstRunService` 保存成功后发布的 `ServiceCommitted` 才触发短促回弹，随后停稳。保留目标名称、结果与按钮原布局。再次进入已完成页面不重演成功。动画关闭取消瞬态，静态台身和正常结果保留。

资源：复用已有 `Art/FormalAcademyStructures32/academy_workbench_2x1` 正式 64×32 Sprite，原图、GUID、Importer 未改。运行时拆分原图 UV，目标图标位于台身与夹口之间；夹口移动后露出的区域采样邻近木纹。此为既有资源的表现处理，不是新生成或新审核的资产。

文件：`FormalRogueliteUi.cs` 接线；`WorkshopClampDetail.cs` 绘制与动作状态；`WorkshopClampTests.cs` 状态边界；`WorkshopClampVerification.cs` 局部运行验证。修改前备份同目录。

验证：Unity CLI 导入编译通过。3 个定向测试通过，检查选择刷新、真实完成条件、去重、取消与再次进入。隔离内存旅程通过模型准备工坊，再用实际 Input System 鼠标与顶层射线验证目标卡、确认安装、返回地图、专精页选择；强化动作仅出现一次，离开移除，重开不重播；专精页关闭动画选目标无待播动作。设置仅改内存并恢复。无玩家档案写入。最后 Console 当前采样零错误／零警告；CombatPrototype 场景未变脏。

证据：`empty.png`、`selected.png`、`reopened.png`、`specialization.png`；8 帧选择定位与 18 帧成功回弹，时间保存在 `position-times.txt`／`motion.txt`。GIF依据实测间隔制作，仅首尾静帧增加审阅停顿；局部图为截图2倍最近邻放大，不是新美术或60fps录屏。

失败与修正：首轮装备图标挡住夹口，改为台身／物件／夹口前景三层。夹口移开后曾露出UI纸色，改为邻近原图木纹作为底层。尝试用 `PreviewUiCaptureSaveFailure` 验证失败点击，但它展示全局“重试保存”页，导致测试找不到确认按钮；这属于验证入口不适用，已撤掉该尝试，不算通过。保存失败不发布完成事件为源码边界与状态测试证据，未进行运行时磁盘故障验收。

限制：本轮不是从新档案打完战斗的完整旅程，也不是磁盘保存验收。尚待用户对实际视觉认可，技术通过不替代审美认可。先前已报告的新建档案入口与总案的冲突保持未改。
