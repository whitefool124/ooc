# 统一战场配置与目录覆盖

目标：从逐关特判改为共用配置＋真实物件状态；批量覆盖当前正式目录，保留正常入口流程验证。

本轮范围：仅战场表现配置、水面材质绑定、局部晶光、局部反射，以及验证中发现的事件卡片点击重叠。没有新增玩法、地图格位、正式图片或场景保存。

统一入口Hd2DBattlefieldProfile按正式目录的FloorTheme解析，未知主题／未知正式关卡显式报错；无目录的标记式开发／训练场沿用干燥庭院默认。主光、补光、曝光和晶光参数从共用配置取值。雨后灯庭与雨痕晶庭是明确天气覆盖，不从水格或像素颜色猜测天气。

物件响应：所有真实蓄能晶簇使用相同局部冷光，耐久归零后关闭；任何关卡的真实水格使用相同水材质。相连水域的范围从真实地图搜索，替代第一战固定三格坐标；当前仍以连通水域外接矩形近似岸边，凹形水岸属于待打磨项。现有共用环境包含侧水庭，因此所有战场使用所属场景局部反射，采集仍按变化合并、限频并随world释放。

水域缓存使用逐格布尔数组精确比较，在战斗版本变化时刷新；术式生成浅水或法宝移除水格时重建连通材质，避免沿用旧岸边范围。未用有碰撞概率的散列替代地图状态。普通帧不重新搜索连通块。

目录检查覆盖当前运行目录18关，逐格构建表现数据，检查地面／单位资源、地图越界、环境模块与Shader支持。5个testmap/weak_layout测试地图不属于运行目录；不把它们算成正式关卡完成数。此项不是18关逐一正常入口或人工审美验收，也不证明专属建筑陈设完成。
