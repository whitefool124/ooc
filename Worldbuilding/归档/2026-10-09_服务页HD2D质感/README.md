# 服务页 HD-2D 质感深化

范围：用户要求事件、工坊、医务室、商店等内容页进一步做 HD-2D 质感；保留原布局、纸黄色方向、原有操作和清晰文字。

本轮修改 `Hd2DContentGeometry.cs` 的共用场景表现：正式九宫格纸边保持原图，语义容器和较大按钮增加两个独立受光侧沿面片及一个承载层接触投影。侧沿、正面和文字保持不同深度，所有层复用正面网格；没有生成或重着色新美术原料，没有为每个控件建实体盒模型。接触投影使用已有正式 Shader 与原始 Alpha 剪影。

中性基础光由1.65降至1.1，增加左上低强度中性点光，形成温和的纸面明暗变化。强度3的首轮样板偏亮，最终压低为1.1；没有增加实时阴影灯。正文仍随原承载面布局，镜头角度、节点规则和存档口径不变。被滚动裁切的内部卡片不额外生成可能越界的侧沿/投影；外部容器仍使用新增质感。

## 实机验证

- Unity 主工程路径与干净活动场景检查通过。CLI beta11 目标实例 unreachable，按项目规则用 Editor API 补充；没有操作同机其他工程。
- 导入编译完成，Console 无错误。
- 工坊原生鼠标：术式专精页签、返回装备锻造、装备悬浮提示、选择装备、返回地图通过；选择结果读回 `starter-chest`。
- 商店原生鼠标购买通过，金币由8扣至4。操作处于验收隔离存档，不代表重新完成整轮游戏。
- 同一分辨率、相机和状态的工坊/商店前后截图已检查，事件、医务室、商店、工坊最终1920×1080截图留存。
- 商店新增30个侧沿/投影 Renderer，复用已有网格；当前可见67个 Renderer、37个不同网格、40个不同材质。新增侧沿和投影仅使用每纹理共享的3个材质；没有把物件数量当作已验证帧率收益，也没有新增逐帧网格复制。没有进行独立Player帧率基准。

截图：`UnityProject/ReviewEvidence/MainMenuE/service-depth-final.jpg`；前后对比 `service-depth-comparison.jpg`；单页 `service-depth-{event,workshop,medical,shop}-final.png`。

本轮是场景材质、厚度与接触深化，未新增独立美术资产。正式贴图、Importer、玩法和原布局保持。设置及战斗内IMGUI不在本轮范围。
