# OCC 首区关卡系统验证（2026-08-08）

## 1. 结论

`LEVEL-01` 已完成。首区九个战斗节点不再共享场景 Marker 布局，而是由关卡目录构建九张独立 12×9 地图；十个当前时代敌人全部进入真实关卡运行时，旧遭遇接口由关卡单一数据源派生。

## 2. 内容与年代审计

- 世界观依据：主角 14 岁入学期接近第一次工业革命前，常规战争以冷兵器与弓弩为主，魔法与专用器物只能来自以太素。
- 玩家可见九关为石路巡哨、废弃驿站、野外导能柱、传讯石庭、石闸关口、传讯塔楼、刻阵工坊、塔前石庭、古塔核心。
- 活跃关卡的显示名、目标、敌人摘要、单位原型、武器/技能表面语义均无步枪、狙击、现代枪械、现代爆破兵、铁路或成熟工业军队。
- 旧英文节点/任务模板 ID 仅为存档兼容，不作为显示名、装备或战斗轮廓。
- F-T01 的玩家可见名称从旧工业爆破语义迁为限次火术法宝“炎脉封装筒”；稳定 ID 保留以避免破坏存档。
- 关卡合同没有 Timer/Countdown/Deadline/TimeLimit 字段；剧情探索规则未改变。

## 3. 运行时闭环

- `FirstRegionLevelCatalog`：9 个稳定定义，28 个敌人放置、37 个地形放置、3 个破坏目标关，9 个布局签名互异。
- `FirstRegionLevelBuilder`：直接生成 `GridMap`、英雄、敌人、轻/重掩体、导能目标与歼灭/破坏目标。
- 十敌人覆盖：铭盾卫、火矢术师、钩刃突袭者、刻阵先锋、刻印锤手、屏障修补师、缚环猎兽、石索缚师、显影灯使、重弩手均由真实关卡构建。
- AI/结算抽检：所有放置敌人均可确定性产生命令；首领关中屏障修补师真实选择 `enemy_1`，施放 `UseSkill` 后将其护盾从 1 恢复至 5。
- 正式表现：运行时按注册资源路径加载，`relay_raid` 4 单位与 `core_finale` 5 单位的缺失纹理均为 0；地面不再绘制铁轨或黄黑现代警示带。
