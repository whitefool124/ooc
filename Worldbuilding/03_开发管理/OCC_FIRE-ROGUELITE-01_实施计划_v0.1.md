# FIRE-ROGUELITE-01 实施计划 v0.1

## 目标

把已完成的火元素个人术式 v0.2 与首区 20 节点肉鸽流程接成真实可从开局玩到首领结算的单局闭环，不依赖开发控制台或空术式槽。

## 实施顺序

1. 在正式入口提供近战 M、武器附着 U、远程施法 R 三种确定性开局，并写入独立存档。
2. 升级地图存档为 `map9`，保存当前生命、护盾、个人魔力与快照有效位；`map8` 及更旧版本显式迁移为首次战斗使用完整基础值。
3. 战斗离开前捕获生命/护盾/魔力、库存和搜刮进度；下一战建立后恢复，不提供战后自动补满。
4. 奖励三选一按节点类型固定构成，并按当前武器过滤个人术式；领取不自动装备，工坊继续作为唯一换装入口。
5. 结算与档案展示开局、当前资源以及个人术式五字段中的玩家决策信息。
6. 增加 3 开局 × 2 首领种子的火系全程回归，以及 map8→map9、状态继承、奖励构成/相容、工坊换装测试。
7. 用 Funplay 重新编译、运行全量 EditMode/必要 PlayMode，检查 Console、场景 clean，并完成 1920×1080 与 960×540 回归。

## 验收标准

- 三种开局第一战均有两项可用火术和正确主手武器。
- 当前生命、护盾、个人魔力在战斗、地图、保存、继续、下一战之间一致，无隐式恢复。
- 普通与高阶节点的三选一构成固定，个人术式 100% 与当前主手相容且同 ID 不重复。
- 奖励不会自动替换装备；工坊可完成合法换装并拒绝非法武器/术式组合。
- 3×2 完整流程、全量自动化测试、Unity 编译、Console、双分辨率和场景 clean 全部通过。

## 完成后解锁

在同一肉鸽合同上进行火系数值平衡、事件/消耗品扩容，以及其余七元素的开局与奖励接入。
