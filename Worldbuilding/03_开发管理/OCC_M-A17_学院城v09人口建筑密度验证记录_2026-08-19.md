# OCC M-A17 学院城 v09 人口建筑密度验证记录（2026-08-19）

> 范围：结构图、世界观与工程登记。遵照产品指示，本轮未启动或修改 Unity。

## 1. 数量闭合

- 分区常住人口：`180+900+100+700+1600+1400+700+280+300+80 = 6,240`。
- 分区学期峰值：`700+1300+300+850+1100+1000+900+350+300+80 = 6,880`。
- 分区建筑：`140+620+190+590+1200+520+720+380+480+120 = 4,960`。
- 36 个主街坊：`620+190+590+1200+520+720+380+480 = 4,700`；加中央核心 `140` 与封存区 `120` 后为 `4,960`。
- 功能建筑：`1900+180+520+510+500+90+220+300+520+220 = 4,960`；其中居住／商住与宿舍为 `2,080` 栋，`6,240 / 2,080 = 3.0` 名常住者／居住建筑。
- 层数建筑：`893+2331+1438+248+50 = 4,960`；二至三层为 `2,331+1,438 = 3,769`，占 `76.0%`。

## 2. 低层真实性门槛

- 可使用建筑硬上限为五层；五层只有 `50` 栋（`1%`），四层只有 `248` 栋（`5%`）。
- 普通城市天际线以二至三层、`9–16 m` 屋脊为主体。中央图书馆主厅 `3F / 26 m`，圆厅 `5F 等效 / 穹顶 34 m`；封存塔 `5F / 冠顶 38 m`。穹顶和塔冠不增加可使用楼层。
- 每个主街坊登记 `84–264` 栋独立建筑、`10–24` 个建模替换簇；街坊不得表现为单栋现代大体量。
- 居民、市集、教学、工坊、宿舍、港务和供给区使用不同的平面肌理与覆盖率；普通街 `8–18 m`、服务巷 `3–6 m`。

## 3. 图面与文件验证

- v07 的教学、北庭、工坊、居民、宿舍和市集高度上限已降至 `18–24 m` 范围；图书馆与封存塔的旧高层数字已移除。
- v08 保留街坊、市政和岸线层，并改用精确人口与建筑登记；v09 独立承担逐栋／建模簇密度及天际线控制，避免把全部标注堆回一张图。
- v09 只表达固定底图和规划密度，不含动态节点、路线、状态或点击区，也不表示已经建模或接入 Unity。
- v07、v08、v09 均通过 .NET XML 解析；v09 已用 ImageMagick 栅格化为 `1500×950` 预览并人工确认街坊建筑簇、道路和中心图书馆无几何遮盖。
- 线程内可视化已用 Edge/Playwright 在 `736 px` 与 `360 px` 宽度、light/dark 两种主题共四次真实截图；地图、统计卡与中文标签均保持在容器内，无横向溢出。

## 4. 未完成项与风险

- 产品尚未批准 v09 的城市密度、分区尺度和低层天际线为最终建模基准。
- 3D 模块、运行时投影、双分辨率真实 Unity 截图和测试仍未开始；它们属于结构批准后的阶段，不得从本记录推断为完成。
- `4,960` 是世界观与生产清册数量；运行时将采用 LOD 合批，仍需测试确保建筑最高投影边界不遮挡约 40 个动态节点和路线。
