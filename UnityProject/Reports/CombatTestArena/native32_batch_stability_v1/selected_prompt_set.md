# Selected prompt set · academy maintenance mixed v1

All six selected sources were generated independently with Codex built-in `image_gen`.
The Sephiria screenshot was supplied only as a reference for map readability, view and
coarse pixel density; its object and character designs were not copied.

## Shared invariant used by the successful sources

Authentic very coarse low-resolution pixel art with one single uniform square
macro-pixel lattice across the complete subject; large connected clusters, crisp hard
edges, limited cohesive palette, transparent background, no smaller sub-pixels,
mixed-resolution detail, softened edges, fine texture, checkerboard, gradients,
speckles or dithering.

Map props use the shared oblique top-down tactical view, show top and front faces and
align to the screen axes without diagonal placement. Units use a strict 90-degree pure
side profile facing right; the whole body and equipment share the same orientation.

## Selected subjects

- `heavy_cover`: compact one-cell academy heavy-cover block of old stone with broad
  iron reinforcement, restrained upper-left light, sparse wear, no long-wall shape.
- `archive_cabinet`: compact tall academy archive cabinet of old wood and broad brass
  fittings, only a few book colour blocks, no tiny spines, drawers or dense grain.
- `aether_power_box`: compact forged-iron and copper utility box with one restrained
  cyan active-energy window and no cables, gauges, bloom or dense screws.
- `maintenance_cart`: compact academy service cart with one broad toolbox and one
  folded cloth, old wood and iron with a small safety-yellow accent.
- `maintenance_guard`: practical academy guard with short iron baton, charcoal work
  uniform and restrained ochre service accent; only one visible eye.
- `field_medic`: academy field medic with practical short coat, one compact satchel and
  one restrained green identifier; normal human proportions and only one visible eye.
