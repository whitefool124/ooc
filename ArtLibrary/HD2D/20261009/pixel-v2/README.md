## 生产与复用

- 独立生图，后 7 件引用新像素档案册统一像素轮廓、色簇、材质与光影。原料不覆盖、不直接进入 Unity。
- 透明交付仅做 Alpha 整理、清除透明像素隐藏 RGB、裁空边与加 16px 安全边；没有重画、重着色、量化或缩放主体。
- 交付图保留原始主体分辨率。场景实例等比缩放，中文文字独立排版，主体正面与摄影机平行；纸页、书脊、陈列座和商品可按不同深度组合。
- 本批厚度、包体、绳结和硬件不能直接非等比拉伸或通用九宫格切片。常见内容通过换页、滚动、便笺副本和组合版式适配，避免每个尺寸都新增原料。
- 软中性体积明暗留在材质里，场景投影、灯光变化、接触阴影由实际场景统一处理。打光不要再次覆盖成橙黄色。
- 建议透明 Sprite、Point、FullRect、无压缩；实际大小和性能档位须在应用时核对。此建议尚未写入 Unity Importer。
